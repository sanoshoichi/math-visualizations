# 情報幾何学の教材を編集するとき

## 手元で計算しなくても追える本文

- 読者はスマートフォンで読み、紙とペンが手元にないことがある。定義から結果まで、計算を本文だけで追えるようにする。
- 記号は使う前に定義する。分布そのもの、観測値、座標関数、座標値、確率・密度を区別する。同じ文字を別の役割で使うときは、その場で説明する。
- 式変形では、固定する量と動かす量、代入した式、微分する因子、約分や相殺が起きる項を示す。新しい仮定は使う前に明記する。文章と表示数式を分け、記号は TeX で組む。
- 接ベクトルは、属する接空間と点を明記し、可能なら座標基底を省略せずに書く。曲線の速度、関数に作用させた値、基底の係数を順に結び付ける。
- 主要な計算には、定義から数値まで通した例を添える。図に出る数値は、式のどの値か説明する。測度論を前提にせず、離散なら和、連続なら密度の積分から説明する。

## タブと図

- タブ内では一つの分布の例を順に進める。例をまたぐ比較は、比較の目的と両方のモデルを明記する。章選択には現在のタブの見出しだけを本文順に出す。
- 軸には変数名と意味を直接書く。単位、固定パラメータ、操作するパラメータ、長さや角度が何を表すかを必要に応じて添える。
- 図のすぐそばに凡例を置く。本文で色の名前を説明するだけで済ませず、グラフと同じ色、実線・破線・点線、丸・四角・矢印などの見本と、表す量を並べる。複数の図が並ぶときは、対応する図のそばに付ける。
- モバイルでも読めるよう、凡例は折り返せるようにし、文字・矢印の頭・スライダーは必要以上に大きくしない。スライダーは本文をスクロールしても扱えるようにする。
