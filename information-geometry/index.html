1. ベルヌーイ分布と二項分布

座標値
p\in(0,1)1回あたりの成功確率。

コインを一回投げた結果の集合を Ω = {H, T} とします。H が表、T が裏です。各結果に正の確率を割り当てる関数を集めます。

M = {P : Ω → (0,1) | P(H) + P(T) = 1}.

各 r ∈ (0,1) に対して、Pᵣ ∈ M を次で定義します。

Pᵣ(H) = r, Pᵣ(T) = 1 − r.

表の確率を返す写像 π を座標に取ります。表の確率を一つ決めると裏の確率も決まるので、この写像は全単射です。

π(P) = P(H), π⁻¹(r) = Pᵣ.

この写像を大域座標とする一次元の滑らかな構造を M に入れます。Pᵣ ∈ M が多様体上の点で、π(Pᵣ) = r がその点の座標値です。

この座標で「滑らか」の意味も決まります。分布の関数 f:M\to\mathbb R が滑らかであるとは、実数の関数 r\mapsto f(\pi^{-1}(r))=f(P_r) が開区間 (0,1) で何度でも微分できることです。次節では、分布を通る曲線に沿って、この関数を一度微分します。

P_r の添字 r は、1回投げたときの表の確率です。ここまでは r と書き、二項分布の式では同じ役割の成功確率を p と書きます。二項分布で新たに数えるものは、試した回数 n と、そのうち成功した回数 j です。

成功回数を記録する二項分布

ベルヌーイ分布では試行は1回でした。同じ成功確率 p\in(0,1) で独立に n 回試行し、成功の回数 X だけを記録します。n は固定します。X=j となる並びは \binom nj 通りで、どの並びも確率 p^j(1-p)^{n-j} を持つので、分布 P_p=\mathrm{Bin}(n,p) は

P_p(X=j)=\binom nj p^j(1-p)^{n-j},\qquad j=0,\ldots,n.

n を固定した分布の族を \mathcal B_n=\{P_p:0<p<1\} とします。たとえば P_p(X=n)=p^n から p を復元できるので、成功確率 p がこの族の一次元の座標になります。n=1 がベルヌーイ分布です。下の図は n=2 に固定した例で、棒は順に0回・1回・2回成功する確率です。

\bigl(P_p(X=0),P_p(X=1),P_p(X=2)\bigr)=\bigl((1-p)^2,2p(1-p),p^2\bigr).

たとえば j=1 では「成功・失敗」と「失敗・成功」の二通りを足します。どちらも確率 p(1-p) なので、真ん中の棒は 2p(1-p) です。図の初期値 p=0.35 なら、

\begin{aligned}P_{0.35}(X=0)&=0.65^2=0.4225,\\P_{0.35}(X=1)&=2\cdot0.35\cdot0.65=0.4550,\\P_{0.35}(X=2)&=0.35^2=0.1225.\end{aligned}

2. 接ベクトルと座標の取り替え

分布
P_r\in M曲線の出発点。
曲線
\gamma:I\to M実数 s\in I\subseteq\mathbb R を分布に送る。区間 I は0を含み、曲線が定義できる範囲。
ベクトル
W\in T_{P_r}M出発点における曲線の速度や基底。同じ点の速度と基底は同じ接空間に属する。
実数として読む値
\pi(\gamma(s))\in(0,1),\quad W(\pi)\in\mathbb R曲線上の座標値や、接ベクトルで関数を微分した値。

r\in(0,1) と a\in\mathbb R を固定します。前章では、座標写像 \pi(P)=P(\mathrm H) が分布から表の確率を読み、逆写像 \pi^{-1}(u)=P_u が表の確率 u から分布を作りました。今度は座標値を u=r+as と動かし、その値を逆写像に入れて曲線を定義します。

s=0 の近くで r+as\in(0,1) を満たす範囲を取ります。

\begin{aligned}\gamma(s)&:=\pi^{-1}(r+as)=P_{r+as}\in M,\\ \gamma(0)&=\pi^{-1}(r)=P_r.\end{aligned}

曲線の点から座標を読み直すと、\pi(\gamma(s))=\pi(\pi^{-1}(r+as))=r+as です。この \gamma(s)=\pi^{-1}(r+as) を、以下で関数 f の引数に代入します。

その点での接ベクトル W ∈ T_(Pᵣ)M は、滑らかな関数 f : M → ℝ に作用して、曲線に沿った変化率を返します。

\begin{aligned}W(f)&=\left.\frac{\mathrm d}{\mathrm ds}f(\gamma(s))\right|_{s=0}\\&=\left.\frac{\mathrm d}{\mathrm ds}f\bigl(\pi^{-1}(r+as)\bigr)\right|_{s=0}\\&=\left.\frac{\mathrm d}{\mathrm ds}(f\circ\pi^{-1})(r+as)\right|_{s=0}\\&=a\,(f\circ\pi^{-1})'(r).\end{aligned}

最後の等号では、外側の関数 f\circ\pi^{-1} の導関数に、内側の r+as の導関数 a を掛けました。では、この計算のどこに接空間の基底があるのでしょうか。座標 \pi の基底は、任意の滑らかな f への作用で定義します。

\left(\left.\frac{\partial}{\partial\pi}\right|_{P_r}\right)(f):=\left.\frac{\mathrm d}{\mathrm dh}f(\pi^{-1}(r+h))\right|_{h=0}=(f\circ\pi^{-1})'(r).

これは表の確率を速さ1で増やすときの微分です。上で計算した W(f) は、どの f に対してもちょうどその a 倍です。接ベクトルを関数に作用する微分作用素として扱うので、すべての f で作用が一致すれば、接ベクトルとして等しいといえます。

W = a (∂/∂π)|ᵣ ∈ T_(Pᵣ)M.

この曲線は計算しやすい例です。一般の滑らかな曲線 c でも、c(0)=P_r なら座標で h(s)=\pi(c(s)) とおけます。h(0)=r、c(s)=\pi^{-1}(h(s)) なので、上と同じ連鎖律を使うと、速度の係数は a=h'(0) になります。

今の a は表の確率がパラメータ1単位あたりに変わる速さです。

表の確率を返す関数 π と裏の確率を返す関数 1 − π を入れると、表の変化率と裏の変化率がそれぞれ得られます。

\begin{aligned}W(\pi)&=\left.\frac{\mathrm d}{\mathrm ds}(r+as)\right|_{s=0}=a,\\ W(1-\pi)&=\left.\frac{\mathrm d}{\mathrm ds}(1-r-as)\right|_{s=0}=-a.\end{aligned}

図では出発点の表の確率を r=0.50 に固定します。U を座標近傍として太く描いています。

二項分布の接ベクトル

二項分布でも、曲線 s\mapsto P_{p+as} に沿って成功確率を動かすと、初速度は a\left.\frac{\partial}{\partial p}\right|_{P_p} です。b_j(P)=P(X=j) という関数に作用させると、成功回数が j になる確率の変化率が得られます。第1章の n=2 の例では、

\begin{aligned} \left(\left.\frac{\partial}{\partial p}\right|_{P_p}\right)(b_0)&=-2(1-p),\\ \left(\left.\frac{\partial}{\partial p}\right|_{P_p}\right)(b_1)&=2(1-2p),\\ \left(\left.\frac{\partial}{\partial p}\right|_{P_p}\right)(b_2)&=2p. \end{aligned}

a を掛ければ曲線に沿った速度になります。たとえば p=0.35 で a=1 なら、三つの確率の変化率は (-1.30,0.60,0.70)。すべて一つの p の変化から決まり、足すと0です。

たとえば真ん中の確率は、曲線に沿って b_1(P_{p+as})=2(p+as)(1-p-as) になります。二つの因子それぞれを微分してから s=0 を入れます。

\begin{aligned}\left.\frac{\mathrm d}{\mathrm ds} b_1(P_{p+as})\right|_{s=0} &=2[a(1-p)-pa]\\&=2a(1-2p).\end{aligned}

ここで a が基底に掛かる成分で、2(1-2p) が基底そのものを b_1 に作用させた値です。

ベルヌーイ分布をもう一つの座標で読む

表と裏の確率の差を返す写像 η を座標に取ります。

η : M → (−1,1), η(P) = P(H) − P(T).

すべての P ∈ M で確率の和が 1 なので、座標変換とその逆は

η ∘ π⁻¹(r) = 2r − 1, π ∘ η⁻¹(u) = (u + 1)/2.

逆変換は u=2r-1 を r について解いた式です。どちら向きの変換も滑らかなので、同じ多様体上で二つの座標を使えます。

たとえば、同じ分布 P₀.₂ ∈ M の座標値は、表の確率で 0.2、表と裏の確率の差では −0.6 です。

同じ接ベクトルを二つの座標で表す

2 で取った曲線 γ(s) = π⁻¹(r + as) をそのまま使います。曲線上の分布を、二つの座標で読むと次のようになります。

π(γ(s)) = r + as, η(γ(s)) = 2(r + as) − 1.

図の矢印に表示する数は、曲線に沿って座標を読んでから、出発点 s = 0 で微分した値です。下の計算にスライダーの値が入ります。

成分が2倍になると、なぜ同じベクトルと言えるのでしょうか。任意の滑らかな関数 f を取り、u=2r-1 と置きます。f(P_r) を二つの座標で書いた等式を r で微分します。

\begin{aligned}(f\circ\pi^{-1})(r)&=(f\circ\eta^{-1})(2r-1),\\(f\circ\pi^{-1})'(r)&=(f\circ\eta^{-1})'(u)\cdot 2.\end{aligned}

第2節の座標基底の定義を両辺に使うと、\left.\partial/\partial\pi\right|_{P_r}=2\left.\partial/\partial\eta\right|_{P_r} です。両辺に a を掛ければ、次の二通りの表示が得られます。

W = a (∂/∂π)|ᵣ = 2a (∂/∂η)|ᵣ ∈ T_(Pᵣ)M.

図の数直線は、0 と 1 がそれぞれ同じ横位置に来るように揃えています。点は分布の座標値、矢印の向きと横幅は接ベクトルの成分を表します。

同じ分布 Pᵣ → 上段は表の確率 π(Pᵣ)、下段は表裏の確率差 η(Pᵣ)。各段の矢印は同じ速度の座標成分です。

矢印の成分を計算する

スライダーで選んだ値を r + as に代入し、曲線 γ(s) = π⁻¹(r + as) に沿った変化率を求めます。

W(π) = d/ds [π(γ(s))] at s = 0 = d/ds [0.20 + 0.15s] at s = 0 = +0.15.
W(η) = d/ds [η(γ(s))] at s = 0 = d/ds [2(0.20 + 0.15s) − 1] at s = 0 = +0.30.

r を固定して a を変えると、点は動かず矢印が変わります。横軸の目盛りが共通なので、a ≠ 0 では下の矢印の横幅が上の二倍になります。この二倍は、座標成分 2a と a の比の大きさです。

座標を取り替えたときの数も、初期値で確認できます。曲線に沿う表の確率は 0.20+0.15s。表と裏の差は (0.20+0.15s)-(0.80-0.15s)=-0.60+0.30s です。s=0 の値は図の点の位置、s の係数は矢印に対応します。

3. KLの二階微分からフィッシャー計量を求める

実際の分布と予測分布を分ける

独立な n 回の試行で成功した回数を X とします。n\ge1 は固定です。実際の成功確率は p\in(0,1)、予測に使う成功確率は q\in(0,1)。n=1 がベルヌーイ分布です。

P から観測し、Q で予測します。\mathbb E_P は、観測ごとの値 f に実際の分布の重みを掛けて足す操作です。

\mathbb E_P[f(X)]=\sum_j P(X=j)\,f(j).

一つの観測の損失からKLを作る

予測が観測値 x に割り当てる確率を p_Q(x) と書きます。小さな値を割り当てるほど大きくなる損失として -\log p_Q(x) を使います。自然対数を使うと、独立な観測に付けた確率や密度の積は、損失の和になります。

同じ結果を P 自身で予測したときとの差を取り、観測を出した P で平均します。この平均を D(P,Q)=D_{\rm KL}(P\Vert Q) と書きます。以下、引数を分布の座標値でも表します。

D(P,Q)=\mathbb E_P\!\left[\underbrace{-\log p_Q(X)+\log p_P(X)}_{\text{同じ観測に対する損失の差}}\right].

結果が j\in\{0,\ldots,n\} のとき、二つの確率には同じ二項係数が掛かります。比を取るとこの係数が消え、対数を取ると指数が前に出ます。

\log\frac{P_p(X=j)}{P_q(X=j)}=j\log\frac pq+(n-j)\log\frac{1-p}{1-q}.

各試行の成功を1、失敗を0と数えると、1試行の平均は 1\cdot p+0\cdot(1-p)=p。X はその和なので、\mathbb E_p[X]=np、残りの失敗回数の平均は n-np です。

D(p,q)=np\log\frac pq+n(1-p)\log\frac{1-p}{1-q}.

なぜ二階微分を取るのか

まず1回のコイン投げ（n=1）で計算します。前章の図と同じく、実際の分布 P=P_{0.50} を固定します。予測分布を Q_s=P_{q(s)}、表の予測確率を q(s)=0.50+0.15s とします。s を増やすと、予測は表に確率を足し、裏から同じ量を引きます。

結果実際の確率予測で使う確率
表0.500.50+0.15s
裏0.500.50-0.15s

各結果の「実際の確率 ÷ 予測で使う確率」の対数を取り、実際の確率 0.50 を重みとして掛けます。表と裏を足したものが L(s)=D_{\rm KL}(P\Vert Q_s) です。

\begin{aligned}L(s)&=L_{\rm 表}(s)+L_{\rm 裏}(s),\\ L_{\rm 表}(s)&=0.50\log\frac{0.50}{0.50+0.15s},\\ L_{\rm 裏}(s)&=0.50\log\frac{0.50}{0.50-0.15s}.\end{aligned}

出発点での値を求める

s=0 を代入すると、表も裏も分子と分母が 0.50。対数の中がどちらも 1 になるので、手元の式は次のようになります。

L(0)=0.50\log 1+0.50\log 1=0+0=0.

出発点での傾きを求める

\log(0.50/q(s))=\log(0.50)-\log q(s) と分けます。最初の項は定数なので、微分すると後ろの -q^{\prime}(s)/q(s) だけが残ります。表の分母の微分は +0.15、裏は -0.15 です。

\begin{aligned}L_{\rm 表}'(s)&=-0.50\frac{+0.15}{0.50+0.15s},\\ L_{\rm 裏}'(s)&=-0.50\frac{-0.15}{0.50-0.15s}.\end{aligned}

微分を終えてから s=0 を入れます。どちらも重みと分母の 0.50 が約分されるので、表の損失が減る傾きと、裏の損失が増える傾きの絶対値がそろいます。

L'(0)=\textcolor{#8bc5ff}{\underbrace{-0.15}_{\text{表の傾き}}}+\textcolor{#ffd389}{\underbrace{(+0.15)}_{\text{裏の傾き}}}=0.

一般の n に戻ると、成功確率を p に固定し、予測だけを q=p+as と動かします。上の二項分布のKLにこの q を入れた L(s)=D(p,p+as) でも、高さと傾きは s=0 でゼロです。高さは二つの分布の一致から、傾きは以下の偏微分でも確かめられます。

高さと傾きだけでは、どれほど急に損失が増える方向か読めません。出発点付近をテイラー展開すると、その違いは次の項に初めて現れます。

L(s)=\underbrace{L(0)}_{0}+\underbrace{L'(0)}_{0}s+\textcolor{#ffd389}{\underbrace{\tfrac12L''(0)s^2}_{\text{最初に残る項}}}+o(s^2).

o(s^2) は s^2 で割ると s\to0 で消える残りです。たとえば s を半分にすると、二次の項は4分の1。逆に、非常に小さいずれでKLを測れば、2L(s)/s^2 が L''(0) に近づきます。これをその方向の速さの二乗として使います。

予測側だけを二回微分する

行列の各成分を得るには、予測座標を一つずつ指定して偏微分します。二回の偏微分を並べた行列をヘッセ行列といいます。微分を済ませてから予測を実際の分布と一致させます。先に一致させると、ずっと0の関数を微分してしまいます。

第1項で q を含むのは -\log q。第2項の -\log(1-q) は、中の微分で負号がもう一つ付きます。

\partial_qD=n\left(-\frac pq+\frac{1-p}{1-q}\right).
\partial_q^2D=n\left(\frac p{q^2}+\frac{1-p}{(1-q)^2}\right).

q=p を代入すると一階は n(-1+1)=0。二階は次の一成分です。

g_{pp}=n\left(\frac1p+\frac1{1-p}\right)=\frac{n[(1-p)+p]}{p(1-p)}=\frac n{p(1-p)}.

この行列は何に作用するか

P を固定します。上の行列の行と列は、次式に並べた座標基底の順です。U,V\in T_P M は同じ分布での二本の接ベクトル、u^a,v^a\in\mathbb R はその基底での係数です。ここで M はこのタブの分布族です。

U=u^1\left.\frac{\partial}{\partial p}\right|_P
V=v^1\left.\frac{\partial}{\partial p}\right|_P
g_P(U,V)=\sum_{a=1}^1\sum_{b=1}^1 u^a g_{ab}v^b.

V=U とすると、g_P(U,U) はこの方向に分布を動かしたときの速さの二乗です。第7章では同じ式に数を入れ、実際のKLと比べます。

分布を動かして KL を作る

試行回数 n と実際の成功確率 p を固定します。第2章と同じように、座標を少し動かして予測の分布を作ります。出発点は実際の分布で、座標の変化率はあらかじめ固定します。

P=P_p,\quad Q_s=\gamma(s)=P_{p+as}

s は座標が許される範囲で0の近くに取ります。曲線の初速度 U は次の接ベクトルです。

U=\dot\gamma(0)=a\left.\frac{\partial}{\partial p}\right|_P

観測された結果に予測が小さな確率を与えたときほど、損失を大きくします。独立な観測の尤度は各観測の確率の積です。負の対数を取ると、低い尤度ほど損失が大きくなり、積だった尤度から観測ごとの損失の和が得られます。密度を使う分布でも、尤度の積を損失の和に変える手順は同じです。

実際の分布を固定し、予測をずらした場合の平均損失から、実際の分布そのもので予測した場合の平均損失を引きます。二つの損失は同じ分布で平均するので、平均の中で負の対数の差を取れます。これが KL ダイバージェンスです。

b_j(t)=P_t(X=j) は成功確率が t のときに成功回数 X が j になる確率です。各 j=0,\ldots,nでの実際の分布での値を p_P=b_j(p)、予測側を q_s=b_j(p+as) と書きます。\mathbb E_P は、それぞれの観測値に p_P を重みとして掛けて平均する記号です。

\begin{aligned}L(s)&=\mathbb E_P[-\log q_s]-\mathbb E_P[-\log p_P]\\&=\mathbb E_P[\log(p_P/q_s)]\\&=D_{\rm KL}(P\Vert Q_s).\end{aligned}
L(s)=\sum_{j=0}^n b_j(p)\log\frac{b_j(p)}{b_j(p+as)}.

なぜ二階微分を取るか

まず、何を動かすか。 実際の分布 P は固定し、予測の分布 Q_s だけを少し動かします。s はずらすためのつまみ、L(s) は平均でどれだけ損失が増えたかです。出発点では予測が実際と一致するので L(0)=0 です。

一階微分は、グラフの傾き。 L^\prime(0) は、つまみを動かした直後に、ずらした量に比例する損失が出るかを調べます。出発点では各結果の計算で分母と重みが約分され、残るのは確率の増減を全部足した値のマイナスです。ある結果に確率を足した分は、別の結果から引かれます。足し引きが打ち消し合うので L^\prime(0)=0 です。連続分布でも、同じ理由は「密度の積分がいつも1」と書けます。

二階微分は、その傾きが変わる速さ。 底で傾きが0でも、少し動いた先で傾きが急に立ち上がることはあります。たとえば、同じ点から始まる s^2 と 4s^2 は、どちらも出発点で傾き0です。傾きは順に 2s と 8s なので、後者のほうが4倍の速さで立ち上がります。

損失の式に戻ると、s が小さい範囲で、最初に残る項は次のようになります。

L(s)\approx\textcolor{#8bc5ff}{\underbrace{\tfrac12 L^{\prime\prime}(0)}_{\text{二次の係数}}}s^2.

\tfrac12 が付くのは、s^2 を二度微分すると2になるからです。例えば L^{\prime\prime}(0)=4 なら、二次の部分は 2s^2。その方向に予測を2倍ずらすと、平均損失はおよそ4倍になります。フィッシャー計量は、この二階微分が出発点と曲線の初速度だけで決まることを利用して、初速度の長さの二乗を定めます。

コインの数値とグラフで確かめる

以下では、確率や密度の正の範囲は共通です。和や積分がある場合は、一般論の正則性の条件のもとで微分と和や積分を交換します。

予測側の q_s だけを微分します。点は観測値を固定した s 微分です。負の対数を一度微分すると -\dot q_s/q_s。これをさらに微分してから、q_0=p_P を代入します。

\frac{\mathrm d}{\mathrm ds}(-\dot q_s/q_s)=(\dot q_s/q_s)^2-\ddot q_s/q_s.
\begin{aligned} L^{\prime}(0)&=-\mathbb E_P[\dot q_0/p_P],\\ L^{\prime\prime}(0)&=\mathbb E_P[(\dot q_0/p_P)^2]-\mathbb E_P[\ddot q_0/p_P].\end{aligned}

期待値の重み p_P と分母の p_P が消える項では、残るのは \dot q_0 または \ddot q_0 の和や積分です。正規化の式の一階・二階微分なので、どちらも0です。残った項では、\dot q_0/p_P が s=0 での対数確率または対数密度の変化率になります。これを方向 U のスコア S_U と書くと、

\begin{aligned}S_U&=\left.\frac{\mathrm d}{\mathrm ds}\log q_s\right|_{s=0}=\dot q_0/p_P,\\g_P(U,U)&=L^{\prime\prime}(0)=\mathbb E_P[S_U^2].\end{aligned}

座標基底のスコアを S_p とすると S_U=aS_p です。基底の長さの二乗 g_{pp}=\mathbb E_P[S_p^2] を求めるため、成功回数の平均と分散を先に出します。 一般論で微分の各項を追う

この分布で計量を計算する

1回ごとの成否から成功回数を作る

試行回数 n と1回あたりの成功確率 p は固定します。第 i 回に成功したら Y_i=1、失敗したら Y_i=0 とします。成功した回だけが合計に1を足すので、成功回数は X=\sum_{i=1}^nY_i です。各回の平均は、二つの値をそれぞれの確率で重み付けして求めます。

\begin{aligned}\mathbb E_{P_p}[Y_i]&=1\cdot p+0\cdot(1-p)=p,\\ \mathbb E_{P_p}[X]&=\sum_{i=1}^n\mathbb E_{P_p}[Y_i]=np.\end{aligned}

成功回数の分散を求める

分散は「平均からのずれの二乗」の平均です。まず1回分のずれ Y_i-p は、成功なら 1-p、失敗なら -p。二乗して、それぞれの確率を掛けます。

\begin{aligned}\mathbb E_{P_p}[(Y_i-p)^2] &=p(1-p)^2+(1-p)p^2\\ &=p(1-p)\bigl[(1-p)+p\bigr]\\ &=p(1-p).\end{aligned}

次に、合計のずれは X-np=\sum_i(Y_i-p) です。これを二乗すると、同じ回のずれを掛けた項と、異なる回のずれを掛けた交差項に分かれます。例えば2回なら、二つのずれの積が2回現れます。

\begin{aligned}(X-np)^2 &=\sum_i(Y_i-p)^2\\ &\quad+2\sum_{i<k}(Y_i-p)(Y_k-p).\end{aligned}

i<k の二つの試行は独立なので、交差項の平均は二つの平均の積です。どちらのずれも平均は p-p=0 なので、積の平均も0になります。

\begin{aligned}\mathbb E_{P_p}[(Y_i-p)(Y_k-p)] &=\mathbb E_{P_p}[Y_i-p]\,\mathbb E_{P_p}[Y_k-p]\\ &=(p-p)(p-p)=0.\end{aligned}

したがって分散には、1回分の分散を n 回足したものが残ります。

\begin{aligned}\operatorname{Var}_{P_p}(X) &=\mathbb E_{P_p}[(X-np)^2]\\ &=\sum_{i=1}^n p(1-p)+0\\ &=np(1-p).\end{aligned}

成功回数が j だったときのスコアを計算する

ここでは成功回数を具体的な値 j に固定し、観測結果の確率 b_j(p)=P_p(X=j) の対数を p で微分します。その値がスコア S_p(j) です。組合せの個数 \binom nj は p に依存しません。

\log b_j(p)=\log\binom nj+j\log p+(n-j)\log(1-p).

最後の項では、対数の内側にある 1-p の微分が -1 です。分母をそろえた後、分子で -jp と +jp が消えます。

\begin{aligned}S_p(j)&=\frac{\mathrm d}{\mathrm dp}\log b_j(p)\\ &=\frac jp-\frac{n-j}{1-p}\\ &=\frac{j(1-p)-(n-j)p}{p(1-p)}\\ &=\frac{j-jp-np+jp}{p(1-p)} =\frac{j-np}{p(1-p)}.\end{aligned}

どの接ベクトルの長さを測るか

分布 P_p で、成功確率を速さ1で増やす向きの座標基底を e_p=\left.\frac{\partial}{\partial p}\right|_{P_p} とします。計量の成分 g_{pp}(P_p) は、この同じ基底を二つの引数に入れた値 g_{P_p}(e_p,e_p) です。つまり e_p の長さの二乗を求めます。

成功回数を j に固定し、分布 P_q に「成功が j 回だったときの対数確率」を返す関数 P_q\mapsto\log P_q(X=j) を考えます。e_p をこの関数に作用させるとは、予測側の確率 q で微分し、q=p で評価することです。その値が上で求めた S_p(j) です。

\left.\frac{\mathrm d}{\mathrm dq}\log P_q(X=j)\right|_{q=p}=S_p(j).

フィッシャー内積では、二つの接ベクトルを同じ観測結果の対数確率に作用させ、得られた二つの値の積を平均します。ここでは両方とも e_p なので、積は S_p(j)\cdot S_p(j)=S_p(j)^2 です。第7章では、予測のずれによる平均対数損失を二度微分しても、この長さの二乗が出ることを確かめます。

どの結果にどの重みを掛けるか

S_p(j) は成功回数が j だったときの一つの値です。いっぽう観測前の X は 0,\dots,n のいずれかを取り、X=j となる確率は P_p(X=j) です。したがって S_p(X)^2 も、確率 P_p(X=j) で値 S_p(j)^2 を取ります。平均を求めるには、値にその確率を掛けて足します。

\begin{aligned} g_{pp}(P_p)&=g_{P_p}(e_p,e_p)\\ &=\mathbb E_{P_p}[S_p(X)\cdot S_p(X)]\\ &=\sum_{j=0}^n P_p(X=j)\,S_p(j)^2. \end{aligned}

一般の n,p で分散の式に戻す

今度は各項に S_p(j)=(j-np)/[p(1-p)] を代入します。二乗してから和を取るので、分母も二乗されます。j を変えて足す間、p は固定です。

\begin{aligned} g_{pp}(P_p) &=\sum_{j=0}^n P_p(X=j)\,\frac{(j-np)^2}{p^2(1-p)^2}\\ &=\frac{\displaystyle\sum_{j=0}^n P_p(X=j)(j-np)^2}{p^2(1-p)^2}. \end{aligned}

分子は (X-np)^2 を確率で重み付けして足したものです。np は X の平均なので、この和は先ほど計算した分散 np(1-p) です。これを入れ、分子と分母に共通する p(1-p) を一つ約分します。

\begin{aligned} g_{pp}(P_p) &=\frac{\operatorname{Var}_{P_p}(X)}{p^2(1-p)^2}\\ &=\frac{np(1-p)}{[p(1-p)]^2}\\ &=\frac{n}{p(1-p)}. \end{aligned}

p を速さ a で動かす速度 a\left.\partial/\partial p\right|_{P_p} の長さの二乗は a^2g_{pp} です。内積の二つの引数にそれぞれ a が掛かるためです。

観測値は成功回数 j=0,\ldots,n です。前章の計量で測った二つの速度の内積を、平方根を取った後のふつうの内積として読みます。

各回数の確率の和が1なので、像は半径2の球面上にあります。モデルの中で許された動きは、成功確率を動かす一本の曲線に沿います。

成功回数の確率を b_j(p)=P_p(X=j) と書きます。平方根写像は F(P_p)=(2\sqrt{b_0(p)},\ldots,2\sqrt{b_n(p)}) です。n=1 では半径2の円の一部、n=2 では半径2の球面上の曲線になります。

n=2 で実際に平方根を取ると F(P_p)=2(1-p,\sqrt{2p(1-p)},p)。この3成分には F_1^2=2F_0F_2 という制約があり、球面上でも動けるのは1方向です。

平方根を取っても計量で測る速さが保たれることを、成分で確かめられます。j 番目の成分 2\sqrt{b_j} を p で微分すると b_j'/\sqrt{b_j}。二乗して足すと、

\sum_{j=0}^n\frac{(b'_j)^2}{b_j}=\sum_{j=0}^n b_j\left(\frac{b'_j}{b_j}\right)^2=\mathbb E[S_p(X)^2].

右辺は前章で求めた g_{pp} です。

曲線の速さは計量から \sqrt{n/[p(1-p)]}\,|\dot p| です。u(p)=2\sqrt n\arcsin\sqrt p と置けば u'(p)=\sqrt{n/[p(1-p)]} なので、速さは |\dot u|。よってモデル内の距離は |u(q)-u(p)| です。

u'(p) の計算は、外側の逆正弦と内側の平方根を順に微分します。

u'(p)=2\sqrt n\cdot\frac{1}{\sqrt{1-p}}\cdot\frac{1}{2\sqrt p}=\sqrt{\frac{n}{p(1-p)}}.

たとえば p から q まで途中で逆戻りせずに動けば、u でも同じ向きに進むため、速さ |\dot u| を積分した値は端点の差の絶対値になります。

空間と座標の定義

ここまでのコインでは、表の確率を一つ決めれば分布が決まりました。ここからは、互いに排反で全体を尽くす三つの結果を扱います。

1回の試行で起きる3つの事象の集合を Ω₃ = {A₁, A₂, A₃} とします。各事象に正の確率を割り当てる分布を集めます。

M₃ = {P : Ω₃ → (0,1) | P(A_1) + P(A_2) + P(A_3) = 1}.

青い点 P ∈ M₃ は分布です。事象ごとに、分布を入れるとその事象の確率を返す関数 ρᵢ を定めます。

\rho_i:M_3\to(0,1),\qquad \rho_i(P)=P(A_i)\quad(i=1,2,3).

左の ρᵢ(P) では確率を読む関数に分布を入れ、右の P(Aᵢ) では分布に事象を入れます。返る数は同じです。図では、その数を軸に載せるために xⁱ と書きます。

x^i=\rho_i(P)=P(A_i),\quad\text{例として}\quad x^1=\rho_1(P)=P(A_1)=0.20.

曲線の速度をどう定義するか

図の2本の矢印は、どちらも s = 0 での速度です。曲線 γⱼ : I → M₃ に対して、接ベクトル γ̇ⱼ(0) ∈ TₚM₃ の作用を、任意の滑らかな関数 f : M₃ → ℝ について次の式で定義します。

(\dot\gamma_j(0))(f):=\left.\frac{\mathrm d}{\mathrm ds}(f\circ\gamma_j)(s)\right|_{s=0}=\lim_{h\to0}\frac{f(\gamma_j(h))-f(P)}{h}.

たとえば横座標を返す関数 ρ₁ を入れます。γ₁ では横座標が 0.20 + s、γ₂ では 0.20 です。

\begin{aligned}(\dot\gamma_1(0))(\rho_1)&=\left.\frac{\mathrm d}{\mathrm ds}\rho_1(\gamma_1(s))\right|_{s=0}\\&=\left.\frac{\mathrm d}{\mathrm ds}(0.20+s)\right|_{s=0}=1,\\[.3em](\dot\gamma_2(0))(\rho_1)&=\left.\frac{\mathrm d}{\mathrm ds}\rho_1(\gamma_2(s))\right|_{s=0}\\&=\left.\frac{\mathrm d}{\mathrm ds}(0.20)\right|_{s=0}=0.\end{aligned}

縦座標にも同じ操作をします。第1の曲線は A_2 の確率を固定し、第2の曲線は A_2 の確率を速さ1で増やします。

\begin{aligned}\dot\gamma_1(0)(\rho_2)&=\left.\frac{\mathrm d}{\mathrm ds}(0.30)\right|_{s=0}=0,\\ \dot\gamma_2(0)(\rho_2)&=\left.\frac{\mathrm d}{\mathrm ds}(0.30+s)\right|_{s=0}=1.\end{aligned}

この二つの関数以外にも、曲線の速度は任意の滑らかな関数に作用します。任意の f についても、座標写像 φ = (ρ₁, ρ₂) を使って f̃ = f ∘ φ⁻¹ と書けば、連鎖律から次の式が得られます。

\begin{aligned}(\dot\gamma_1(0))(f)&=\left.\frac{\mathrm d}{\mathrm ds}\tilde f(0.20+s,0.30)\right|_{s=0}\\&=(\partial_1\tilde f)(0.20,0.30),\\[.3em](\dot\gamma_2(0))(f)&=\left.\frac{\mathrm d}{\mathrm ds}\tilde f(0.20,0.30+s)\right|_{s=0}\\&=(\partial_2\tilde f)(0.20,0.30).\end{aligned}

ここで多様体上の微分と、座標平面上で計算する偏微分の対応を書いておきます。\phi=(\rho_1,\rho_2) は分布を二つの実数に写す座標写像でした。\tilde f=f\circ\phi^{-1} はその二つの実数を引数に取ります。点 P での第 j 座標基底を、次の作用で定義します。

\left(\left.\frac{\partial}{\partial\rho_j}\right|_P\right)(f):=\frac{\partial\tilde f}{\partial x^j}\bigl(\phi(P)\bigr),\qquad j=1,2.

左辺は分布の関数に作用し、右辺ではもう一方の座標値を固定して偏微分します。直前に求めた2本の速度は任意の f に対してこの作用と一致するので、図の矢印は接空間の次の元です。

\begin{aligned}e_1&=\dot\gamma_1(0)=\left.\frac{\partial}{\partial\rho_1}\right|_P,\\e_2&=\dot\gamma_2(0)=\left.\frac{\partial}{\partial\rho_2}\right|_P.\end{aligned}

座標関数以外に作用する例も見ておきます。f(P)=\rho_1(P)\rho_2(P) を取ると、第1の曲線に沿う値は (0.20+s)0.30、第2の曲線に沿う値は 0.20(0.30+s) です。s の係数を取れば、e_1(f)=0.30 と e_2(f)=0.20 が得られます。

任意の曲線の速度をこの基底で書く

今度は P を通る任意の滑らかな曲線 \gamma を取り、\gamma(0)=P とします。その座標を x^j(s)=\rho_j(\gamma(s))、初速度の成分を a=(x^1)'(0),\ b=(x^2)'(0) と置きます。どんな f についても二変数の連鎖律により、

\begin{aligned}W(f)&=\left.\frac{\mathrm d}{\mathrm ds}\tilde f(x^1(s),x^2(s))\right|_{s=0}\\&=a\frac{\partial\tilde f}{\partial x^1}(\phi(P))+b\frac{\partial\tilde f}{\partial x^2}(\phi(P)).\end{aligned}

先ほど定義した基底を右辺に戻すと、接ベクトルそのものを書き下せます。

W=\dot\gamma(0)=a\left.\frac{\partial}{\partial\rho_1}\right|_P+b\left.\frac{\partial}{\partial\rho_2}\right|_P\in T_PM_3.

この式に f=\rho_1 を入れると、\tilde f(x^1,x^2)=x^1 の偏微分は順に1と0なので W(\rho_1)=a。f=\rho_2 なら順に0と1なので W(\rho_2)=b です。第3の確率についても計算できます。

W(\rho_3)=W(1-\rho_1-\rho_2)=0-a-b.

したがって (a,b) がこの基底での成分で、(a,b,-a-b) は三つの確率の変化率をすべて並べたものです。\rho_3 の変化率は初めの二つで決まります。

3. KLの二階微分からフィッシャー計量を求める

実際の分布と予測分布を分ける

A_1,\ldots,A_3 は排反で全結果を尽くすカテゴリです。p_i=P(A_i)>0 は固定し、q_i=Q(A_i)>0 を動かします。\rho_i:R\mapsto R(A_i) が座標関数で、p_i,q_i はその値です。独立に選ぶのは先頭の 2 個です。

p_3=1-\sum_{i=1}^2p_i,\qquad q_3=1-\sum_{i=1}^2q_i.

P から観測し、Q で予測します。\mathbb E_P は、観測ごとの値 f に実際の分布の重みを掛けて足す操作です。

\mathbb E_P[f(X)]=\sum_i P(A_i)\,f(A_i).

一つの観測の損失からKLを作る

予測が観測値 x に割り当てる確率を p_Q(x) と書きます。小さな値を割り当てるほど大きくなる損失として -\log p_Q(x) を使います。自然対数を使うと、独立な観測に付けた確率や密度の積は、損失の和になります。

同じ結果を P 自身で予測したときとの差を取り、観測を出した P で平均します。この平均を D(P,Q)=D_{\rm KL}(P\Vert Q) と書きます。以下、引数を分布の座標値でも表します。

D(P,Q)=\mathbb E_P\!\left[\underbrace{-\log p_Q(X)+\log p_P(X)}_{\text{同じ観測に対する損失の差}}\right].

結果 A_i の対数比は \log(p_i/q_i)。これに実際にその結果が出る確率 p_i を掛け、最後の結果も含めて足します。

D(p,q)=\sum_{i=1}^2p_i\log\frac{p_i}{q_i}+p_3\log\frac{p_3}{q_3}.

なぜ二階微分を取るのか

まったく同じ予測から始めます。予測側の座標を、決めた向きに小さく t\in\mathbb R だけ動かした分布を Q_t とし、Q_0=P とします。L(t)=D(P,Q_t) をグラフにすると、横軸はこのずれ、縦軸は余分に払う平均損失です。

出発点では対数比が \log 1=0 なので高さは0。KLはどちらにずれても0以上です（-\log z\ge1-z に z=p_Q/p_P を代入して P で平均すれば、右辺は 1-1=0）。したがって滑らかなグラフの底の傾きも0です。

高さと傾きだけでは、どれほど急に損失が増える方向か読めません。出発点付近をテイラー展開すると、その違いは次の項に初めて現れます。

L(t)=\underbrace{L(0)}_{0}+\underbrace{L'(0)}_{0}t+\textcolor{#ffd389}{\underbrace{\tfrac12L''(0)t^2}_{\text{最初に残る項}}}+o(t^2).

o(t^2) は t^2 で割ると t\to0 で消える残りです。たとえば t を半分にすると、二次の項は4分の1。逆に、非常に小さいずれでKLを測れば、2L(t)/t^2 が L''(0) に近づきます。これをその方向の速さの二乗として使います。

予測側だけを二回微分する

行列の各成分を得るには、予測座標を一つずつ指定して偏微分します。二回の偏微分を並べた行列をヘッセ行列といいます。微分を済ませてから予測を実際の分布と一致させます。先に一致させると、ずっと0の関数を微分してしまいます。

1\le a,b\le 2 とします。q_a を増やすと q_3 は同じ量だけ減ります。したがって一階微分には二つの項が残ります。

\frac{\partial D}{\partial q_a}=-\frac{p_a}{q_a}+\frac{p_3}{q_3}.

さらに q_b で微分します。\delta_{ab} は a=b なら1、異なれば0。最後の確率はどの q_b を変えても動きます。

\frac{\partial^2 D}{\partial q_b\,\partial q_a}=\delta_{ab}\frac{p_a}{q_a^2}+\frac{p_3}{q_3^2}.

q_i=p_i で一階は -1+1=0。二階では分子の確率が一つ約分されます。

g_{ab}=\frac{\delta_{ab}}{p_a}+\frac1{p_3}.

異なる二つの座標方向にも内積が生まれるのは、両方の操作が最後の確率を変えるためです。

この行列は何に作用するか

P を固定します。上の行列の行と列は、次式に並べた座標基底の順です。U,V\in T_P M は同じ分布での二本の接ベクトル、u^a,v^a\in\mathbb R はその基底での係数です。ここで M はこのタブの分布族です。

U=u^1\left.\frac{\partial}{\partial \rho_1}\right|_P+u^2\left.\frac{\partial}{\partial \rho_2}\right|_P
V=v^1\left.\frac{\partial}{\partial \rho_1}\right|_P+v^2\left.\frac{\partial}{\partial \rho_2}\right|_P
g_P(U,V)=\sum_{a=1}^2\sum_{b=1}^2 u^a g_{ab}v^b.

V=U とすると、g_P(U,U) はこの方向に分布を動かしたときの速さの二乗です。第7章では同じ式に数を入れ、実際のKLと比べます。

分布を動かして KL を作る

同じ分布モデル Q で、独立な2回の試行を予測します。実際の結果が1回目は A_1、2回目は A_2 だったとします。モデルがこの並びに与えた確率は、各回に与えた確率の積 Q(A_1)Q(A_2) です。この積が大きいほど、観測された並びに高い確率を与えたことになります。

実際に観測した結果に低い確率を付けたときに大きくなり、試行ごとに足せる量を作ります。そこで、この積に負の対数を取ります。対数は積を和に変え、マイナスを付けると、観測に与えた確率が低いほど損失が大きくなります。

-\log\!\bigl[Q(A_1)Q(A_2)\bigr]=-\log Q(A_1)-\log Q(A_2).

右辺の各項が、1回分の対数損失です。たとえば実際の事象に 0.20 を割り当てた予測では約1.61、0.50 なら約0.69です。以下では自然対数を使います。

ここからは任意の P\in M_3 で考えます。第2章と同じ座標 (\rho_1,\rho_2) を使うと、方向を指定するには独立な二つの成分 u_1,u_2\in\mathbb R を選べば十分です。

U=u_1\left.\frac{\partial}{\partial\rho_1}\right|_P+u_2\left.\frac{\partial}{\partial\rho_2}\right|_P,\qquad u_3=-u_1-u_2.

第2章で確かめたように u_i=U(\rho_i) は事象 A_i の確率の変化率です。この速度をもつ具体的な曲線を一本作ります。各確率に s u_i を加えた分布を Q_s とします。

Q_s(A_i)=P(A_i)+su_i,\qquad Q_0=P.

第2章で見たように \sum_i u_i=0 なので、動かしても確率の和は1です。ここではすべての確率が正になるよう、s を0の近くに取ります。

各モデルの平均損失を計算して、差を取る

ここからは、実際の結果が分布 P に従うとします。予測には任意の分布 R を使います。たとえば A_1 が起きたときの損失は -\log R(A_1) で、それが起きる確率は P(A_1) です。同じ計算を3つの事象について足すと、R を使った1回あたりの平均損失 C_P(R) が求まります。

\begin{aligned}C_P(R)&=P(A_1)[-\log R(A_1)]\\&\quad+P(A_2)[-\log R(A_2)]\\&\quad+P(A_3)[-\log R(A_3)]\\&=-\sum_{i=1}^3 P(A_i)\log R(A_i).\end{aligned}

この式に予測モデルとして R=Q_s と R=P をそれぞれ入れます。実際の分布はどちらも P なので、外側の重み P(A_i) は共通です。予測をずらした後の平均損失から、出発点での平均損失を引いた差を L(s) とします。

\begin{aligned}L(s)&=C_P(Q_s)-C_P(P)\\&=-\sum_i P(A_i)\log Q_s(A_i)\\&\quad+\sum_i P(A_i)\log P(A_i)\\&=\sum_i P(A_i)\bigl[\log P(A_i)-\log Q_s(A_i)\bigr].\end{aligned}

各項に \log a-\log b=\log(a/b) を使い、分母の Q_s(A_i) に、先ほど決めた P(A_i)+su_i を代入します。

\begin{aligned}L(s)&=\sum_i P(A_i)\log\frac{P(A_i)}{Q_s(A_i)}\\&=\sum_i P(A_i)\log\frac{P(A_i)}{P(A_i)+su_i}.\end{aligned}

第2章の e_1 方向を例にします。出発点の確率は (0.20,0.30,0.50) で、s=0.10 のとき予測は (0.30,0.30,0.40) です。2つの平均損失を引くと、予測をずらしたことで1回あたり約0.03048 nat増えたと分かります。

\begin{aligned}C_P(P)&=-0.20\log 0.20-0.30\log 0.30\\&\quad-0.50\log 0.50\approx 1.02965,\\ C_P(Q_{0.10})&=-0.20\log 0.30-0.30\log 0.30\\&\quad-0.50\log 0.40\approx 1.06013,\\L(0.10)&\approx1.06013-1.02965=0.03048.\end{aligned}

図と同じ初期値なら、確率を動かすのは第1・第3事象だけです。3つの項を順に書くと、どこが動いているか確認できます。

\begin{aligned}L(s)&=0.20\log\frac{0.20}{0.20+s}\\&\quad+0.30\log\frac{0.30}{0.30}\\&\quad+0.50\log\frac{0.50}{0.50-s}.\end{aligned}

第2項は常に0です。第1・第3項の外側の重みも固定して、分母だけを動かします。

この損失の差を KL ダイバージェンスと呼びます。いま求めたのは L(s)=D_{\rm KL}(P\Vert Q_s) です。

なぜ二階微分を取るか

まず、何を動かすか。 実際の分布 P は固定し、予測の分布 Q_s だけを少し動かします。s はずらすためのつまみ、L(s) は平均でどれだけ損失が増えたかです。出発点では予測が実際と一致するので L(0)=0 です。

一階微分は、グラフの傾き。 L^\prime(0) は、つまみを動かした直後に、ずらした量に比例する損失が出るかを調べます。出発点では各結果の計算で分母と重みが約分され、残るのは確率の増減を全部足した値のマイナスです。ある結果に確率を足した分は、別の結果から引かれます。足し引きが打ち消し合うので L^\prime(0)=0 です。連続分布でも、同じ理由は「密度の積分がいつも1」と書けます。

二階微分は、その傾きが変わる速さ。 底で傾きが0でも、少し動いた先で傾きが急に立ち上がることはあります。たとえば、同じ点から始まる s^2 と 4s^2 は、どちらも出発点で傾き0です。傾きは順に 2s と 8s なので、後者のほうが4倍の速さで立ち上がります。

損失の式に戻ると、s が小さい範囲で、最初に残る項は次のようになります。

L(s)\approx\textcolor{#8bc5ff}{\underbrace{\tfrac12 L^{\prime\prime}(0)}_{\text{二次の係数}}}s^2.

\tfrac12 が付くのは、s^2 を二度微分すると2になるからです。例えば L^{\prime\prime}(0)=4 なら、二次の部分は 2s^2。その方向に予測を2倍ずらすと、平均損失はおよそ4倍になります。フィッシャー計量は、この二階微分が出発点と曲線の初速度だけで決まることを利用して、初速度の長さの二乗を定めます。

コインの数値とグラフで確かめる

損失を微分して、長さの二乗を求める

予測をどれだけずらしたかを表す s で微分します。まず各項の対数確率を微分すると、ここで元の確率で割る式が出てきます。

\left.\frac{\mathrm d}{\mathrm ds}\log Q_s(A_i)\right|_{s=0}=\left.\frac{u_i}{P(A_i)+su_i}\right|_{s=0}=\frac{u_i}{P(A_i)}.

右辺は、確率の変化率を元の確率に対する割合で読んだ値です。同じ u_i=0.01 でも、元の確率が 0.20 なら 0.05、0.50 なら 0.02 になります。

この微分を平均損失の式に戻します。\log P(A_i) と重み P(A_i) は s によらないので、微分するのは -\log Q_s(A_i) だけです。

L'(s)=-\sum_i P(A_i)\frac{u_i}{P(A_i)+su_i}.

s=0 を代入すると分母と重みが同じになります。その後、確率の和の条件 \sum_i u_i=0 を使います。

L'(0)=-\sum_i P(A_i)\frac{u_i}{P(A_i)}=-\sum_i u_i=0.

二階微分では (P(A_i)+su_i)^{-1} をもう一度微分します。逆数の微分でマイナスが出て、内側の式の微分から u_i がもう1つ掛かります。

L''(s)=\sum_i P(A_i)\frac{u_i^2}{(P(A_i)+su_i)^2}.
\begin{aligned}L''(0)&=\sum_i P(A_i)\left(\frac{u_i}{P(A_i)}\right)^2\\&=\sum_i\frac{u_i^2}{P(A_i)}.\end{aligned}

数値例に戻ると、s=0 では

\begin{aligned}L''(0) &=\frac{0.20\cdot1^2}{0.20^2} +\frac{0.30\cdot0^2}{0.30^2} +\frac{0.50\cdot(-1)^2}{0.50^2}\\ &=\frac1{0.20}+0+\frac1{0.50}=5+2=7. \end{aligned}

ここで分子の 1,0,-1 は第2章の e_1 の三つの確率変化率です。分母は、いずれも出発点の確率の二乗です。

三つの分母は s=0 で正であり、0の十分近くでも正です。この範囲で対数は滑らかなので、以下の二次までのテイラー展開が使えます。O(s^3) は、0の近くで絶対値がある定数倍の |s|^3 以下になる残りの項を表します。

出発点の近くでは、次のようにテイラー展開できます。Q_0=P から L(0)=0、上の計算から L'(0)=0 です。

\begin{aligned}L(s)&=L(0)+sL'(0)+\tfrac12s^2L''(0)+O(s^3)\\&=\tfrac12s^2\sum_i\frac{u_i^2}{P(A_i)}+O(s^3).\end{aligned}

同じ小さな s だけ予測をずらすと、二次の項が大きい方向ほど損失が増えます。その大きさを測るため、L''(0) を接ベクトル U の長さの二乗 g_P(U,U) とします。

曲線の選び方で長さは変わるか

上では計算のために、確率が s の一次式になる曲線を一つ選びました。同じ P を通り、同じ初速度 U をもつ滑らかな曲線 R_s でも確かめます。q_i(s)=R_s(A_i) と書くと q_i(0)=P(A_i),\ q_i'(0)=u_i です。この曲線での平均損失の差を L_R(s)=C_P(R_s)-C_P(P) と置きます。

\begin{aligned}L_R'(s)&=-\sum_i P(A_i)\frac{q_i'(s)}{q_i(s)},\\L_R''(s)&=\sum_i P(A_i)\left[\frac{q_i'(s)^2}{q_i(s)^2}-\frac{q_i''(s)}{q_i(s)}\right],\\L_R''(0)&=\sum_i\frac{u_i^2}{P(A_i)}-\sum_i q_i''(0).\end{aligned}

二つ目の式では商の微分を使い、三つ目の式では出発点の確率と速度を代入しました。すべての s で \sum_i q_i(s)=1 なので、両辺を二度微分すれば \sum_i q_i''(0)=0 です。これで二階微分は点 P と接ベクトル U だけで決まると分かります。

長さの二乗から、2本の内積へ

同じ点 P で二つ目の方向を選びます。

V=v_1\left.\frac{\partial}{\partial\rho_1}\right|_P+v_2\left.\frac{\partial}{\partial\rho_2}\right|_P,\qquad v_3=-v_1-v_2.

各確率に作用させた値は V(\rho_i)=v_i です。U+V の長さの二乗には (u_i+v_i)^2=u_i^2+2u_iv_i+v_i^2 が現れます。そこから U と V それぞれの長さの二乗を引くと交差項だけが残るので、2で割ったものを内積と定めます。

\begin{aligned}g_P(U,V)&=\tfrac12\bigl[g_P(U+V,U+V)\\&\qquad-g_P(U,U)-g_P(V,V)\bigr]\\&=\tfrac12\sum_i\frac{(u_i+v_i)^2-u_i^2-v_i^2}{P(A_i)}\\&=\sum_i\frac{u_iv_i}{P(A_i)}.\end{aligned}

分母 P(A_i) はすべて正です。U\ne0 なら独立な成分の少なくとも一つが0でないため g_P(U,U)>0 です。また右辺は U,V のそれぞれに線形で、入れ替えても同じ値です。このため各接空間で内積として使えます。

この内積を、各分布 P の接空間に入れたものがフィッシャー計量です。第7章ではここで求めた平均損失の差 L(s) を、KLダイバージェンスとして図で確認できます。

基底で計量を行列にする

図では矢印に e_1,e_2 と短く記します。スライダーで分布を選び直すたびに、その点 P での基底を使います。行列の成分は、この二つの基底を順に内積へ入れた値です。

g_{ab}(P)=g_P\!\left(\left.\frac{\partial}{\partial\rho_a}\right|_P,\left.\frac{\partial}{\partial\rho_b}\right|_P\right),\qquad a,b\in\{1,2\}.

g_{ab}=g_P(e_a,e_b) の添字 a,b は、行と列に置く基底の番号です。両方を1と2で動かすと、行列全体になります。

G(P)=(g_{ab})_{a,b=1}^{2}=\begin{pmatrix}g_{11}&g_{12}\\g_{21}&g_{22}\end{pmatrix}=\begin{pmatrix}1/P(A_1)+1/P(A_3)&1/P(A_3)\\1/P(A_3)&1/P(A_2)+1/P(A_3)\end{pmatrix}.

g_{12} は1行2列の成分です。e_1 の変化率 (1,0,-1) と e_2 の変化率 (0,1,-1) を順に掛けると、A₃ の項だけが残ります。

g_{12}=\frac{1\cdot0}{P(A_1)}+\frac{0\cdot1}{P(A_2)}+\frac{(-1)(-1)}{P(A_3)}=\frac{1}{P(A_3)}.

対角成分も同じ式です。同じ基底を二度入れるので、各事象の確率変化率を二乗します。

\begin{aligned}g_P(e_1,e_1)&=\frac{1^2}{P(A_1)}+\frac{0^2}{P(A_2)}+\frac{(-1)^2}{P(A_3)},\\ g_P(e_2,e_2)&=\frac{0^2}{P(A_1)}+\frac{1^2}{P(A_2)}+\frac{(-1)^2}{P(A_3)}.\end{aligned}

ここでは P(A_2)=0.30 を固定し、P(A_3)=0.70-P(A_1) としています。初期値では g_{11}=7,\ g_{22}=16/3,\ g_{12}=2。座標図で横と縦だった基底のなす角 \theta を求めるには、内積を両者の長さで割ります。

\cos\theta=\frac{g_{12}}{\sqrt{g_{11}g_{22}}}.

4. 平方根写像と球面

分布
P\in M_3平方根を取る前の分布。
写した点
F(P)\in \mathbb R^3平方根写像で出る座標の組。

確率を足す範囲は三つの結果 A_1,A_2,A_3 です。前章の計量で測った二つの速度の内積を、平方根を取った後のふつうの内積として読みます。

F(P)_i=2\sqrt{P(A_i)},\qquad \sum_{i=1}^3 F(P)_i^2=4.

和が1になる三つの確率は、半径2の球面の正の部分と一対一に対応します。この例では、球面上の短い弧をたどっても途中の点すべてを分布に戻せます。

第3章で測ったのは、一点での速度の長さです。ここでは区間 [0,1] 上の滑らかな曲線 c を取り、その上を動きます。各時刻の確率を q_i(t)=\rho_i(c(t)) とすれば、第2章の連鎖律を各点 c(t) で使えます。

\dot c(t)=q_1'(t)\left.\frac{\partial}{\partial\rho_1}\right|_{c(t)}+q_2'(t)\left.\frac{\partial}{\partial\rho_2}\right|_{c(t)}.
\begin{aligned}\ell_g(c)&=\int_0^1\sqrt{g_{c(t)}(\dot c(t),\dot c(t))}\,\mathrm dt\\&=\int_0^1\sqrt{\sum_{i=1}^3\frac{q_i'(t)^2}{q_i(t)}}\,\mathrm dt.\end{aligned}

曲線の長さを求めるには、各点でフィッシャー計量を使って速度の長さを測り、それを積分します。同じ計算をユークリッド空間の内積でできるように、各確率 q を実数 f(q) に移すと考えます。

確率が u_i の速さで変化するなら、新しい成分の速さは連鎖律から f'(P(A_i))u_i です。この速さを二乗して足したものを、前節の \sum_i u_i^2/P(A_i) と一致させたいので、f'(q)=1/\sqrt q と取ります。積分して定数を0に選ぶと f(q)=2\sqrt q です。

F(P)=2\bigl(\sqrt{P(A_1)},\sqrt{P(A_2)},\sqrt{P(A_3)}\bigr).

どの関数を使うかを決めた式を、一成分について書くと [f'(q)u]^2=u^2/q です。両辺で u^2 が共通なので f'(q)^2=1/q。確率とともに増える写像を選んで f'(q)=q^{-1/2} とすると、これを積分した値は 2q^{1/2} に定数を足したものです。定数は0にします。

3成分を二乗して足すと、確率の和が1であることから半径2が出ます。

\|F(P)\|^2=4\sum_i P(A_i)=4.

F の像は球面のうち3成分がすべて正の部分です。実際、この部分の点 y=(y_1,y_2,y_3) に対して P(A_i)=y_i^2/4 と置けば、確率の和は1で F(P)=y となります。

接ベクトル U,V の確率の変化率を u_i,v_i とします。たとえば U について、Q_s(A_i)=P(A_i)+su_i と動かすと、写像 F の第 i 成分の速度は次の値です。

(\mathrm dF_P U)_i=\left.\frac{\mathrm d}{\mathrm ds}2\sqrt{P(A_i)+su_i}\right|_{s=0}=\frac{u_i}{\sqrt{P(A_i)}}.

今の計算を基底付きで書きます。y_i を周囲の \mathbb R^3 の直交座標とすると、写した速度は

\mathrm dF_P(U)=\sum_{i=1}^3\frac{u_i}{\sqrt{P(A_i)}}\left.\frac{\partial}{\partial y_i}\right|_{F(P)}.

これが実際に球面に接することも確認できます。半径方向 F(P) との内積は \sum_i 2\sqrt{P(A_i)}\,u_i/\sqrt{P(A_i)}=2\sum_i u_i=0 です。

2本の像のユークリッド内積を取ると、分母の平方根が2つ掛かって、前節の内積に戻ります。

\mathrm dF_P(U)\cdot\mathrm dF_P(V)=\sum_i\frac{u_i}{\sqrt{P(A_i)}}\frac{v_i}{\sqrt{P(A_i)}}=g_P(U,V).

曲線の速度にこの等式を使えば、各点で速度の長さが一致します。したがって曲線に沿って積分して得られる長さも一致します。

出発点を P=(0.20,0.30,0.50)、終点を Q=(0.78,0.02,0.20) とします。以下は分布を確率の組で表した記法です。球面上の最短経路は、球の中心と両端を通る平面で切った大円の短い弧です。

球面上の2点と原点がつくる角を \omega とします。内積を両方の長さの積で割ると、その角度の余弦になります。両方とも半径2の位置にあるので、分母は4です。

\begin{aligned}\cos\omega&=\frac{F(P)\cdot F(Q)}{\|F(P)\|\|F(Q)\|}\\&=\frac{4\sum_i\sqrt{P(A_i)Q(A_i)}}4\\&=\sum_i\sqrt{P(A_i)Q(A_i)}.\end{aligned}

球面全体での最短経路に関する定理を使いました。その弧が分布に対応する部分から出ないことも確認しましょう。球面上の2点を結ぶ弦を v(t)=(1-t)F(P)+tF(Q) と置きます。0\le t\le1 では各成分が正です。それぞれの点を中心から半径2の位置まで伸ばすと

y(t)=2\frac{v(t)}{\|v(t)\|}.

球の中心と両端を含む平面の中で、弦の方向は一方の半径から他方まで小さい角の側を連続的に動きます。したがって y(t) がなぞるのは短い大円弧です。正の数を掛けても各成分は正のままなので、弧全体を F^{-1} で分布に戻せます。ここでの t は弦上の割合です。図のスライダーは弧長の割合を使います。

中心角をラジアンで測ると、弧の長さは半径と中心角の積です。したがって、球面上の短い弧の長さと等しいフィッシャー・ラオ距離は

d_{\rm FR}(P,Q)=2\omega=2\arccos\!\left(\sum_i\sqrt{P(A_i)Q(A_i)}\right).

5. 指数型分布族と双対座標

分布
P\in M_3二つの座標で読み直す分布。
座標値
\theta,\eta\in\mathbb R^2自然パラメータと期待値座標。どちらも分布を指定する実数または実数の組。

\theta^a=\log[P(A_a)/P(A_3)]（a=1,2）と置くと、確率の和が1という条件から P(A_3)=1/(1+e^{\theta^1}+e^{\theta^2}) です。T_a を A_a で1、他では0となる関数とすると、

P(A_i)=\exp[\theta^1T_1(A_i)+\theta^2T_2(A_i)-\psi],\quad\psi=\log(1+e^{\theta^1}+e^{\theta^2}).

分母の対数 \psi を \theta^a で微分すると e^{\theta^a}/(1+e^{\theta^1}+e^{\theta^2})=P(A_a)。自然座標の相手になる期待値座標 \eta_a=\mathbb E_P[T_a] は、三角形の確率座標そのものです。一般の式と基底変換の計算

数値で順にたどります。P=(0.20,0.30,0.50) なら e^{\theta^1}=0.20/0.50=0.4、e^{\theta^2}=0.30/0.50=0.6。分母は 1+0.4+0.6=2 なので、\partial_1\psi=0.4/2=0.20、\partial_2\psi=0.6/2=0.30 と元の座標値が戻ります。

微分中に動く分母の項も明記します。例えば \theta^1 で微分するとき、1 と e^{\theta^2} は固定です。従って

\frac{\partial\psi}{\partial\theta^1} =\frac{1}{1+e^{\theta^1}+e^{\theta^2}}\frac{\partial}{\partial\theta^1}(1+e^{\theta^1}+e^{\theta^2}) =\frac{e^{\theta^1}}{1+e^{\theta^1}+e^{\theta^2}}.

6. 混合接続と指数接続

分布の変化
t\in[0,1],\quad c(t)\in M_3途中の分布を一般に c(t) と書く。t は経路を進むパラメータ。
曲線上の速度
\dot c(t)\in T_{c(t)}M_3今いる分布での接ベクトル。

両端の分布を決め、経路上の位置を t\in[0,1] で表します。比較するのは、自然座標を一定の速さで変える指数接続、期待値座標を一定の速さで変える混合接続、フィッシャー計量の接続です。最後の接続では、速度ベクトルを経路に沿って平行に保つので、その計量で測った速さも一定です。

第4章では長さを最小にする道を求めました。ここでは同じ端点 P,Q に対して、速度を「平行に保つ」規則を二通り選びます。この規則を指定するのが接続です。まず規則を定め、それから途中の分布を計算します。

混合接続では z=(\rho_1,\rho_2) を使います。指数接続では、R\in M_3 の二つの確率比の対数 z=(\theta^1,\theta^2) を使います。

\theta^a(R)=\log\frac{R(A_a)}{R(A_3)},\qquad a=1,2.

確率がすべて正なので対数を取れます。この二つの値から分布も復元できます。R(A_a)=e^{\theta^a(R)}R(A_3) を確率の和の条件に代入すると、

R(A_3)=\frac{1}{1+e^{\theta^1(R)}+e^{\theta^2(R)}}.

どちらの接続でも、それぞれが指定した座標 z の基底を平行に運ぶと定めます。つまり、基底を各点で同じ番号の基底へ移します。曲線 c(t) に沿うベクトルをこの基底で展開すると、共変微分で変化するのは係数 b^a(t) だけです。

\begin{aligned}B(t)&=\sum_{a=1}^2 b^a(t)\left.\frac{\partial}{\partial z^a}\right|_{c(t)},\\\nabla_{\dot c}B&=\sum_{a=1}^2\frac{\mathrm db^a}{\mathrm dt}\left.\frac{\partial}{\partial z^a}\right|_{c(t)}.\end{aligned}

これが、この座標ではクリストッフェル記号がすべて0という意味です。測地線は自分の速度を平行に保つ曲線、すなわち \nabla_{\dot c}\dot c=0 を満たす曲線です。B=\dot c と置くと、係数は b^a(t)=\frac{\mathrm d}{\mathrm dt}z^a(c(t)) です。二つの基底は一次独立なので、共変微分が0となるには各係数の微分が0となることが必要十分です。

\frac{\mathrm d^2}{\mathrm dt^2}z^a(c(t))=0,\qquad a=1,2.

一度積分すると速度は定数 k^a です。もう一度積分して c(0)=P,\ c(1)=Q を使うと、z^a(c(t))=z^a(P)+tk^a と k^a=z^a(Q)-z^a(P) が得られます。つまり、

z^a(c(t))=(1-t)z^a(P)+tz^a(Q),\qquad 0\le t\le1.

二つの座標で途中の分布を求める

混合接続では z^a(R)=\rho_a(R)=R(A_a) なので、各確率は端点での確率の算術的な補間になります。第3の確率も、1から最初の二つを引けば同じ式になります。

P_t^{(m)}(A_i)=(1-t)P(A_i)+tQ(A_i).

指数接続で同じ補間を行う対象は対数確率比です。途中の分布を P_t^{(e)} と書いて、先ほど求めた式に z^a=\theta^a を代入すると、

\theta^a(P_t^{(e)})=(1-t)\theta^a(P)+t\theta^a(Q).

両辺の指数を取ります。対数の係数はべきになり、和は積になるので、求めたい分布の確率比が得られます。

\frac{P_t^{(e)}(A_a)}{P_t^{(e)}(A_3)}=\left(\frac{P(A_a)}{P(A_3)}\right)^{1-t}\left(\frac{Q(A_a)}{Q(A_3)}\right)^t.

w_i=P(A_i)^{1-t}Q(A_i)^t と置くと、右辺は w_a/w_3 です。したがって3つの確率は w_1,w_2,w_3 に比例します。確率の合計が1になるよう、各 w_i を重みの合計で割ります。

P_t^{(e)}(A_i)=\frac{P(A_i)^{1-t}Q(A_i)^t}{\sum_j P(A_j)^{1-t}Q(A_j)^t}.

スライダーで動く2点の速度も書けます。R_m=P_t^{(m)},\ R_e=P_t^{(e)} を、それぞれ時刻 t で通る分布とします。直線補間を微分した係数 k^a を、それぞれの分布での基底に掛けます。

\begin{aligned}\dot P_t^{(m)}&=\sum_{a=1}^2[Q(A_a)-P(A_a)]\left.\frac{\partial}{\partial\rho_a}\right|_{R_m},\\\dot P_t^{(e)}&=\sum_{a=1}^2[\theta^a(Q)-\theta^a(P)]\left.\frac{\partial}{\partial\theta^a}\right|_{R_e}.\end{aligned}

図は両方を確率座標で描きます。指数接続で一定なのは対数確率比の速度なので、その曲線を確率座標に戻すと図の破線のように曲がります。

図の中点では t=1/2 です。混合接続の第1確率は (0.20+0.78)/2=0.49。指数接続では、まず三つの重みがそれぞれ \sqrt{0.20\cdot0.78}\approx0.395、\sqrt{0.30\cdot0.02}\approx0.077、\sqrt{0.50\cdot0.20}\approx0.316 です。重みの和は約 0.789 なので、第1確率は 0.395/0.789\approx0.50 となります。

両端では分布が一致します。途中の t=1/2 では、混合接続は確率の算術平均、指数接続は幾何平均を正規化した分布を通ります。前節の大円弧は、フィッシャー計量のレヴィ＝チヴィタ接続に対応します。

8. 三角形でKLを最小にする

候補と最小点
Q,Q_*\in\{R\in M_3:R(A_1)=r\}最初の確率を固定した分布の中で探す。
動かす座標値
q=Q(A_2)\in(0,1-r)二番目の確率。三番目は和が1になるよう決まる。

三角形で、線分上の最小点を探す

目標を P=(0.20,0.30,0.50) とします。制約は Q(A_1)=r。残りを Q(A_2)=q,\ Q(A_3)=1-r-q と書くと、線分の内部では 0<q<1-r です。今回は動かす分布 Q をKLの第1引数に入れ、D_{\rm KL}(Q\Vert P) を最小にします。

\begin{aligned}D_{\rm KL}(Q\Vert P)&=r\log\frac r{0.20}+q\log\frac q{0.30}\\&\quad+(1-r-q)\log\frac{1-r-q}{0.50}.\end{aligned}

第1項は q に対して定数。第2項の微分は \log(q/0.30)+1、第3項の微分は -\log((1-r-q)/0.50)-1 です。足した式を0とすると、

\log\frac q{0.30}-\log\frac{1-r-q}{0.50}=0\quad\Longleftrightarrow\quad\frac q{0.30}=\frac{1-r-q}{0.50}.

二階微分は 1/q+1/(1-r-q)>0 なので、解が線分上で唯一の最小点です。上の等式は残りの確率の比を 0.30:0.50 に保つことを表します。残りの和が 1-r なので、

Q_*=(r,\,0.375(1-r),\,0.625(1-r)).

最小点での比は Q_*(A_2)/0.30=Q_*(A_3)/0.50 でした。これを c とすると、Q_*(A_2)+Q_*(A_3)=0.80c=1-r。従って Q_*(A_2)=0.30(1-r)/0.80 です。たとえば r=0.45 なら、0.30\times0.55/0.80=0.20625 になります。

同じ制約にある任意の候補について、次の等式が成り立ちます。

D_{\rm KL}(Q\Vert P)=D_{\rm KL}(Q\Vert Q_*)+D_{\rm KL}(Q_*\Vert P).

図では D_{\rm KL}(Q\Vert P) と、右辺の二つの値を表示します。たとえば初期値 r=0.45 なら Q_*=(0.45,0.20625,0.34375) です。制約を動かすつまみと、同じ制約内で候補 Q を動かすつまみを分けています。

図の等式を第2・第3事象で確かめます。三つのKLを差し引くと、各事象の項は (Q(A_i)-Q_*(A_i))\log[Q_*(A_i)/P(A_i)] です。第1事象では Q(A_1)-Q_*(A_1)=r-r=0。第2・第3事象は対数比が同じで、二つの確率差を足すと0なので、合計が0になります。

三角形の例では、Q_*(A_2)/P(A_2)=Q_*(A_3)/P(A_3)=(1-r)/0.80 でした。この二つの対数比が等しいため、第2事象の確率を増やして第3事象の確率を同じだけ減らす方向では、一階微分が打ち消し合います。図で Q を動かしても、D_{\rm KL}(Q_*\Vert P) は同じ値のままです。

3. KLの二階微分からフィッシャー計量を求める

実際の分布と予測分布を分ける

A_1,\ldots,A_4 は排反で全結果を尽くすカテゴリです。p_i=P(A_i)>0 は固定し、q_i=Q(A_i)>0 を動かします。\rho_i:R\mapsto R(A_i) が座標関数で、p_i,q_i はその値です。独立に選ぶのは先頭の 3 個です。

p_4=1-\sum_{i=1}^3p_i,\qquad q_4=1-\sum_{i=1}^3q_i.

P から観測し、Q で予測します。\mathbb E_P は、観測ごとの値 f に実際の分布の重みを掛けて足す操作です。

\mathbb E_P[f(X)]=\sum_i P(A_i)\,f(A_i).

一つの観測の損失からKLを作る

予測が観測値 x に割り当てる確率を p_Q(x) と書きます。小さな値を割り当てるほど大きくなる損失として -\log p_Q(x) を使います。自然対数を使うと、独立な観測に付けた確率や密度の積は、損失の和になります。

同じ結果を P 自身で予測したときとの差を取り、観測を出した P で平均します。この平均を D(P,Q)=D_{\rm KL}(P\Vert Q) と書きます。以下、引数を分布の座標値でも表します。

D(P,Q)=\mathbb E_P\!\left[\underbrace{-\log p_Q(X)+\log p_P(X)}_{\text{同じ観測に対する損失の差}}\right].

結果 A_i の対数比は \log(p_i/q_i)。これに実際にその結果が出る確率 p_i を掛け、最後の結果も含めて足します。

D(p,q)=\sum_{i=1}^3p_i\log\frac{p_i}{q_i}+p_4\log\frac{p_4}{q_4}.

なぜ二階微分を取るのか

まったく同じ予測から始めます。予測側の座標を、決めた向きに小さく t\in\mathbb R だけ動かした分布を Q_t とし、Q_0=P とします。L(t)=D(P,Q_t) をグラフにすると、横軸はこのずれ、縦軸は余分に払う平均損失です。

出発点では対数比が \log 1=0 なので高さは0。KLはどちらにずれても0以上です（-\log z\ge1-z に z=p_Q/p_P を代入して P で平均すれば、右辺は 1-1=0）。したがって滑らかなグラフの底の傾きも0です。

高さと傾きだけでは、どれほど急に損失が増える方向か読めません。出発点付近をテイラー展開すると、その違いは次の項に初めて現れます。

L(t)=\underbrace{L(0)}_{0}+\underbrace{L'(0)}_{0}t+\textcolor{#ffd389}{\underbrace{\tfrac12L''(0)t^2}_{\text{最初に残る項}}}+o(t^2).

o(t^2) は t^2 で割ると t\to0 で消える残りです。たとえば t を半分にすると、二次の項は4分の1。逆に、非常に小さいずれでKLを測れば、2L(t)/t^2 が L''(0) に近づきます。これをその方向の速さの二乗として使います。

予測側だけを二回微分する

行列の各成分を得るには、予測座標を一つずつ指定して偏微分します。二回の偏微分を並べた行列をヘッセ行列といいます。微分を済ませてから予測を実際の分布と一致させます。先に一致させると、ずっと0の関数を微分してしまいます。

1\le a,b\le 3 とします。q_a を増やすと q_4 は同じ量だけ減ります。したがって一階微分には二つの項が残ります。

\frac{\partial D}{\partial q_a}=-\frac{p_a}{q_a}+\frac{p_4}{q_4}.

さらに q_b で微分します。\delta_{ab} は a=b なら1、異なれば0。最後の確率はどの q_b を変えても動きます。

\frac{\partial^2 D}{\partial q_b\,\partial q_a}=\delta_{ab}\frac{p_a}{q_a^2}+\frac{p_4}{q_4^2}.

q_i=p_i で一階は -1+1=0。二階では分子の確率が一つ約分されます。

g_{ab}=\frac{\delta_{ab}}{p_a}+\frac1{p_4}.

異なる二つの座標方向にも内積が生まれるのは、両方の操作が最後の確率を変えるためです。

この行列は何に作用するか

P を固定します。上の行列の行と列は、次式に並べた座標基底の順です。U,V\in T_P M は同じ分布での二本の接ベクトル、u^a,v^a\in\mathbb R はその基底での係数です。ここで M はこのタブの分布族です。

U=u^1\left.\frac{\partial}{\partial \rho_1}\right|_P+u^2\left.\frac{\partial}{\partial \rho_2}\right|_P+u^3\left.\frac{\partial}{\partial \rho_3}\right|_P
V=v^1\left.\frac{\partial}{\partial \rho_1}\right|_P+v^2\left.\frac{\partial}{\partial \rho_2}\right|_P+v^3\left.\frac{\partial}{\partial \rho_3}\right|_P
g_P(U,V)=\sum_{a=1}^3\sum_{b=1}^3 u^a g_{ab}v^b.

V=U とすると、g_P(U,U) はこの方向に分布を動かしたときの速さの二乗です。第7章では同じ式に数を入れ、実際のKLと比べます。

分布を動かして KL を作る

実際の分布 P を固定します。第2章と同じように、座標を少し動かして予測の分布を作ります。出発点は実際の分布で、座標の変化率はあらかじめ固定します。

\begin{aligned} p_i&=P(A_i),\quad Q_0=P,\\ Q_s(A_i)&=p_i+sa_i,\\ a_4&=-a_1-a_2-a_3.\end{aligned}

s は座標が許される範囲で0の近くに取ります。曲線の初速度 U は次の接ベクトルです。

U=\dot Q_0=\sum_{i=1}^3 a_i\left.\frac{\partial}{\partial\rho_i}\right|_P

観測された結果に予測が小さな確率を与えたときほど、損失を大きくします。独立な観測の尤度は各観測の確率の積です。負の対数を取ると、低い尤度ほど損失が大きくなり、積だった尤度から観測ごとの損失の和が得られます。密度を使う分布でも、尤度の積を損失の和に変える手順は同じです。

実際の分布を固定し、予測をずらした場合の平均損失から、実際の分布そのもので予測した場合の平均損失を引きます。二つの損失は同じ分布で平均するので、平均の中で負の対数の差を取れます。これが KL ダイバージェンスです。

事象 A_iでの実際の分布での値を p_P=p_i、予測側を q_s=p_i+sa_i と書きます。\mathbb E_P は、それぞれの観測値に p_P を重みとして掛けて平均する記号です。

\begin{aligned}L(s)&=\mathbb E_P[-\log q_s]-\mathbb E_P[-\log p_P]\\&=\mathbb E_P[\log(p_P/q_s)]\\&=D_{\rm KL}(P\Vert Q_s).\end{aligned}
L(s)=\sum_{i=1}^4 p_i\log\frac{p_i}{p_i+sa_i}.

なぜ二階微分を取るか

まず、何を動かすか。 実際の分布 P は固定し、予測の分布 Q_s だけを少し動かします。s はずらすためのつまみ、L(s) は平均でどれだけ損失が増えたかです。出発点では予測が実際と一致するので L(0)=0 です。

一階微分は、グラフの傾き。 L^\prime(0) は、つまみを動かした直後に、ずらした量に比例する損失が出るかを調べます。出発点では各結果の計算で分母と重みが約分され、残るのは確率の増減を全部足した値のマイナスです。ある結果に確率を足した分は、別の結果から引かれます。足し引きが打ち消し合うので L^\prime(0)=0 です。連続分布でも、同じ理由は「密度の積分がいつも1」と書けます。

二階微分は、その傾きが変わる速さ。 底で傾きが0でも、少し動いた先で傾きが急に立ち上がることはあります。たとえば、同じ点から始まる s^2 と 4s^2 は、どちらも出発点で傾き0です。傾きは順に 2s と 8s なので、後者のほうが4倍の速さで立ち上がります。

損失の式に戻ると、s が小さい範囲で、最初に残る項は次のようになります。

L(s)\approx\textcolor{#8bc5ff}{\underbrace{\tfrac12 L^{\prime\prime}(0)}_{\text{二次の係数}}}s^2.

\tfrac12 が付くのは、s^2 を二度微分すると2になるからです。例えば L^{\prime\prime}(0)=4 なら、二次の部分は 2s^2。その方向に予測を2倍ずらすと、平均損失はおよそ4倍になります。フィッシャー計量は、この二階微分が出発点と曲線の初速度だけで決まることを利用して、初速度の長さの二乗を定めます。

コインの数値とグラフで確かめる

以下では、確率や密度の正の範囲は共通です。和や積分がある場合は、一般論の正則性の条件のもとで微分と和や積分を交換します。

予測側の q_s だけを微分します。点は観測値を固定した s 微分です。負の対数を一度微分すると -\dot q_s/q_s。これをさらに微分してから、q_0=p_P を代入します。

\frac{\mathrm d}{\mathrm ds}(-\dot q_s/q_s)=(\dot q_s/q_s)^2-\ddot q_s/q_s.
\begin{aligned} L^{\prime}(0)&=-\mathbb E_P[\dot q_0/p_P],\\ L^{\prime\prime}(0)&=\mathbb E_P[(\dot q_0/p_P)^2]-\mathbb E_P[\ddot q_0/p_P].\end{aligned}

期待値の重み p_P と分母の p_P が消える項では、残るのは \dot q_0 または \ddot q_0 の和や積分です。正規化の式の一階・二階微分なので、どちらも0です。残った項では、\dot q_0/p_P が s=0 での対数確率または対数密度の変化率になります。これを方向 U のスコア S_U と書くと、

\begin{aligned}S_U&=\left.\frac{\mathrm d}{\mathrm ds}\log q_s\right|_{s=0}=\dot q_0/p_P,\\g_P(U,U)&=L^{\prime\prime}(0)=\mathbb E_P[S_U^2].\end{aligned}

S_U(A_i)=a_i/p_i なので、二乗して p_i を掛けると各項は a_i^2/p_i です。二つの方向 U,V の内積は、スコアの二乗を積 S_U S_V に置き換えた平均です。その式に座標基底を入れます。 一般論で微分の各項を追う

この分布で計量を計算する

p_i=P(A_i) と置きます。前の章で計算した e_a(\rho_i) をフィッシャー内積の4項に入れます。

g_{ab}(P)=\frac{\delta_{ab}}{P(A_a)}+\frac1{P(A_4)},\qquad a,b=1,2,3.

ここで \delta_{ab} は a=b なら1、それ以外なら0です。計算を分けて書くと、初めの3項で両方の基底が同時に変える確率は、a=b のときの p_a だけです。4項目はどの基底の組でも (-1)(-1)/p_4 になります。

\sum_{i=1}^4\frac{e_a(\rho_i)e_b(\rho_i)}{p_i} =\sum_{i=1}^3\frac{\delta_{ai}\delta_{bi}}{p_i}+\frac{(-1)(-1)}{p_4}.

たとえば g_{12}=1/P(A_4) です。最初の3項では二つの基底が同時に変える確率がありません。第4項だけで (-1)(-1)=1 が残ります。

例えば最初の二つの基底では、全4項を書けば g_{12}=1\cdot0/p_1+0\cdot1/p_2+0\cdot0/p_3+(-1)(-1)/p_4。図の初期値なら 1/0.35\approx2.857 です。第1基底を二度入れた場合は 1/0.20+1/0.35\approx7.857 になります。

6. 4つの確率で測地線を比べる

分布の変化
t\in[0,1],\quad c(t)\in M_4途中の分布を一般に c(t) と書く。t は経路を進むパラメータ。

\dot c(t)\in T_{c(t)}M_4今いる分布での接ベクトル。

両端の分布を決め、経路上の位置を t\in[0,1] で表します。比較するのは、自然座標を一定の速さで変える指数接続、期待値座標を一定の速さで変える混合接続、フィッシャー計量の接続です。最後の接続では、速度ベクトルを経路に沿って平行に保つので、その計量で測った速さも一定です。

端点を P=(p_i)、Q=(q_i) とします。混合接続では期待値座標 p_a を線形補間し、第4成分も和が1になるように決めると全成分が (1-t)p_i+tq_i になります。指数接続では \log(p_a/p_4) を線形補間し、指数を取って和を1にそろえると全成分が p_i^{1-t}q_i^t/\sum_jp_j^{1-t}q_j^t になります。

指数接続で補間する値は \log(p_i/p_4) です。途中の分布の確率を r_i(t) とすると、まず第4確率との比が決まります。

\begin{aligned}\log\frac{r_i(t)}{r_4(t)}&=(1-t)\log\frac{p_i}{p_4}+t\log\frac{q_i}{q_4},\\\frac{r_i(t)}{r_4(t)}&=\frac{p_i^{1-t}q_i^t}{p_4^{1-t}q_4^t}.\end{aligned}

この比は i=4 でも両辺が1です。w_i(t)=p_i^{1-t}q_i^t と置けば、各 r_i(t) は w_i(t) に同じ定数を掛けた値です。和を1にする定数は 1/\sum_jw_j(t) なので、上の式になります。

計量の測地線は平方根写像で移した球面上の短い大円弧です。端点の正の線形結合を半径2に正規化すると、その弧を最初から最後までたどれます。全成分は正のままなので、弧を四面体の内部へ戻せます。中心角は \arccos(\sum_i\sqrt{p_iq_i}) で、距離はその2倍です。

三つの経路を同じ割合 t で比較するため、円弧では中心角 \omega=\arccos\!\left(\sum_i\sqrt{p_iq_i}\right) を t\omega だけ進みます。出発点と終点の平方根成分をそれぞれ \sqrt{p_i},\sqrt{q_i} とすると、この角度に対応する中間点の成分は次の通りです。

\sqrt{r_i(t)}=\frac{\sin((1-t)\omega)}{\sin\omega}\sqrt{p_i}+\frac{\sin(t\omega)}{\sin\omega}\sqrt{q_i}.

球の中心と両端を含む平面で、弧に沿って回転した単位ベクトルを両端の単位ベクトルで展開した係数がこの二つの正弦比です。確率に戻すには両辺を二乗します。両端が等しければ \omega=0 で、経路は一定です。

例として P=(0.10,0.20,0.30,0.40)、Q=(0.40,0.20,0.30,0.10) を取ります。混合接続の中点では成分ごとに足して2で割り、(0.25,0.20,0.30,0.25) になります。指数接続では成分ごとの幾何平均が (0.20,0.20,0.30,0.20)。和 0.90 で四つとも割るので、例えば第1確率は 0.20/0.90\approx0.222 です。

座標基底のスコアは、対数確率を直接 λ で微分して得られます。j/\lambda-1 です。次の章では、予測する分布を少し動かしたときの損失から、計量を求めます。このスコアを使う計算は、その結果の検算になります。

例えば j=0 なら p_\lambda(0)=e^{-\lambda} なので、曲線に沿って e^{-(\lambda+as)} を微分すると -ae^{-\lambda} です。上の一般式に j=0 を入れても、括弧が -1 になり同じ結果が得られます。

3. KLの二階微分からフィッシャー計量を求める

実際の分布と予測分布を分ける

一定の観測区間で起きる回数を X とします。実際の平均回数は \lambda>0、予測の平均回数は \kappa>0 です。観測値 j は0以上の整数です。

P から観測し、Q で予測します。\mathbb E_P は、観測ごとの値 f に実際の分布の重みを掛けて足す操作です。

\mathbb E_P[f(X)]=\sum_j P(X=j)\,f(j).

一つの観測の損失からKLを作る

予測が観測値 x に割り当てる確率を p_Q(x) と書きます。小さな値を割り当てるほど大きくなる損失として -\log p_Q(x) を使います。自然対数を使うと、独立な観測に付けた確率や密度の積は、損失の和になります。

同じ結果を P 自身で予測したときとの差を取り、観測を出した P で平均します。この平均を D(P,Q)=D_{\rm KL}(P\Vert Q) と書きます。以下、引数を分布の座標値でも表します。

D(P,Q)=\mathbb E_P\!\left[\underbrace{-\log p_Q(X)+\log p_P(X)}_{\text{同じ観測に対する損失の差}}\right].

確率 e^{-\lambda}\lambda^j/j! と e^{-\kappa}\kappa^j/j! の比では j! が消えます。

\log\frac{P_\lambda(X=j)}{P_\kappa(X=j)}=\kappa-\lambda+j\log(\lambda/\kappa).

結果に依存するのは j だけです。その平均は、和の始点を一つずらして計算できます。

\mathbb E_\lambda[X]=\sum_{j=1}^\infty e^{-\lambda}\frac{j\lambda^j}{j!}=\lambda\sum_{i=0}^\infty e^{-\lambda}\frac{\lambda^i}{i!}=\lambda.
D(\lambda,\kappa)=\kappa-\lambda+\lambda\log(\lambda/\kappa).

なぜ二階微分を取るのか

まったく同じ予測から始めます。予測側の座標を、決めた向きに小さく t\in\mathbb R だけ動かした分布を Q_t とし、Q_0=P とします。L(t)=D(P,Q_t) をグラフにすると、横軸はこのずれ、縦軸は余分に払う平均損失です。

出発点では対数比が \log 1=0 なので高さは0。KLはどちらにずれても0以上です（-\log z\ge1-z に z=p_Q/p_P を代入して P で平均すれば、右辺は 1-1=0）。したがって滑らかなグラフの底の傾きも0です。

高さと傾きだけでは、どれほど急に損失が増える方向か読めません。出発点付近をテイラー展開すると、その違いは次の項に初めて現れます。

L(t)=\underbrace{L(0)}_{0}+\underbrace{L'(0)}_{0}t+\textcolor{#ffd389}{\underbrace{\tfrac12L''(0)t^2}_{\text{最初に残る項}}}+o(t^2).

o(t^2) は t^2 で割ると t\to0 で消える残りです。たとえば t を半分にすると、二次の項は4分の1。逆に、非常に小さいずれでKLを測れば、2L(t)/t^2 が L''(0) に近づきます。これをその方向の速さの二乗として使います。

予測側だけを二回微分する

行列の各成分を得るには、予測座標を一つずつ指定して偏微分します。二回の偏微分を並べた行列をヘッセ行列といいます。微分を済ませてから予測を実際の分布と一致させます。先に一致させると、ずっと0の関数を微分してしまいます。

\lambda\log(\lambda/\kappa)=\lambda\log\lambda-\lambda\log\kappa と分けると、\kappa に依存する項だけが残ります。

\partial_\kappa D=1-\lambda/\kappa,\qquad \partial_\kappa^2D=\lambda/\kappa^2.

\kappa=\lambda なら一階は 1-1=0、二階は次の値です。

g_{\lambda\lambda}=\lambda/\lambda^2=1/\lambda.

この行列は何に作用するか

P を固定します。上の行列の行と列は、次式に並べた座標基底の順です。U,V\in T_P M は同じ分布での二本の接ベクトル、u^a,v^a\in\mathbb R はその基底での係数です。ここで M はこのタブの分布族です。

U=u^1\left.\frac{\partial}{\partial \lambda}\right|_P
V=v^1\left.\frac{\partial}{\partial \lambda}\right|_P
g_P(U,V)=\sum_{a=1}^1\sum_{b=1}^1 u^a g_{ab}v^b.

V=U とすると、g_P(U,U) はこの方向に分布を動かしたときの速さの二乗です。第7章では同じ式に数を入れ、実際のKLと比べます。

分布を動かして KL を作る

実際の平均回数 \lambda を固定します。第2章と同じように、座標を少し動かして予測の分布を作ります。出発点は実際の分布で、座標の変化率はあらかじめ固定します。

P=P_\lambda,\quad Q_s=\gamma(s)=P_{\lambda+as}

s は座標が許される範囲で0の近くに取ります。曲線の初速度 U は次の接ベクトルです。

U=\dot\gamma(0)=a\left.\frac{\partial}{\partial\lambda}\right|_P

観測された結果に予測が小さな確率を与えたときほど、損失を大きくします。独立な観測の尤度は各観測の確率の積です。負の対数を取ると、低い尤度ほど損失が大きくなり、積だった尤度から観測ごとの損失の和が得られます。密度を使う分布でも、尤度の積を損失の和に変える手順は同じです。

実際の分布を固定し、予測をずらした場合の平均損失から、実際の分布そのもので予測した場合の平均損失を引きます。二つの損失は同じ分布で平均するので、平均の中で負の対数の差を取れます。これが KL ダイバージェンスです。

観測回数 j=0,1,\ldotsでの実際の分布での値を p_P=p_\lambda(j)、予測側を q_s=p_{\lambda+as}(j) と書きます。\mathbb E_P は、それぞれの観測値に p_P を重みとして掛けて平均する記号です。

\begin{aligned}L(s)&=\mathbb E_P[-\log q_s]-\mathbb E_P[-\log p_P]\\&=\mathbb E_P[\log(p_P/q_s)]\\&=D_{\rm KL}(P\Vert Q_s).\end{aligned}
L(s)=\sum_{j=0}^\infty p_\lambda(j)\log\frac{p_\lambda(j)}{p_{\lambda+as}(j)}.

なぜ二階微分を取るか

まず、何を動かすか。 実際の分布 P は固定し、予測の分布 Q_s だけを少し動かします。s はずらすためのつまみ、L(s) は平均でどれだけ損失が増えたかです。出発点では予測が実際と一致するので L(0)=0 です。

一階微分は、グラフの傾き。 L^\prime(0) は、つまみを動かした直後に、ずらした量に比例する損失が出るかを調べます。出発点では各結果の計算で分母と重みが約分され、残るのは確率の増減を全部足した値のマイナスです。ある結果に確率を足した分は、別の結果から引かれます。足し引きが打ち消し合うので L^\prime(0)=0 です。連続分布でも、同じ理由は「密度の積分がいつも1」と書けます。

二階微分は、その傾きが変わる速さ。 底で傾きが0でも、少し動いた先で傾きが急に立ち上がることはあります。たとえば、同じ点から始まる s^2 と 4s^2 は、どちらも出発点で傾き0です。傾きは順に 2s と 8s なので、後者のほうが4倍の速さで立ち上がります。

損失の式に戻ると、s が小さい範囲で、最初に残る項は次のようになります。

L(s)\approx\textcolor{#8bc5ff}{\underbrace{\tfrac12 L^{\prime\prime}(0)}_{\text{二次の係数}}}s^2.

\tfrac12 が付くのは、s^2 を二度微分すると2になるからです。例えば L^{\prime\prime}(0)=4 なら、二次の部分は 2s^2。その方向に予測を2倍ずらすと、平均損失はおよそ4倍になります。フィッシャー計量は、この二階微分が出発点と曲線の初速度だけで決まることを利用して、初速度の長さの二乗を定めます。

コインの数値とグラフで確かめる

以下では、確率や密度の正の範囲は共通です。和や積分がある場合は、一般論の正則性の条件のもとで微分と和や積分を交換します。

予測側の q_s だけを微分します。点は観測値を固定した s 微分です。負の対数を一度微分すると -\dot q_s/q_s。これをさらに微分してから、q_0=p_P を代入します。

\frac{\mathrm d}{\mathrm ds}(-\dot q_s/q_s)=(\dot q_s/q_s)^2-\ddot q_s/q_s.
\begin{aligned} L^{\prime}(0)&=-\mathbb E_P[\dot q_0/p_P],\\ L^{\prime\prime}(0)&=\mathbb E_P[(\dot q_0/p_P)^2]-\mathbb E_P[\ddot q_0/p_P].\end{aligned}

期待値の重み p_P と分母の p_P が消える項では、残るのは \dot q_0 または \ddot q_0 の和や積分です。正規化の式の一階・二階微分なので、どちらも0です。残った項では、\dot q_0/p_P が s=0 での対数確率または対数密度の変化率になります。これを方向 U のスコア S_U と書くと、

\begin{aligned}S_U&=\left.\frac{\mathrm d}{\mathrm ds}\log q_s\right|_{s=0}=\dot q_0/p_P,\\g_P(U,U)&=L^{\prime\prime}(0)=\mathbb E_P[S_U^2].\end{aligned}

第2章で出した座標基底のスコア S_\lambda(j)=(j-\lambda)/\lambda を二乗して平均します。(j-\lambda)^2 の平均を計算するために、一乗と二乗の平均を求めます。 一般論で微分の各項を追う

この分布で計量を計算する

平均を計算するとき、j\ge1 なら j/j!=1/(j-1)! なので、

\mathbb E[X]=e^{-\lambda}\lambda\sum_{j=1}^{\infty}\frac{\lambda^{j-1}}{(j-1)!}=\lambda.

二つずつ選ぶ積 j(j-1) が出てくる理由は、階乗の先頭二つと約分できるためです。j=0,1 の項は0なので、j=2 から足します。

\begin{aligned}\mathbb E[X(X-1)] &=e^{-\lambda}\sum_{j=2}^{\infty}\frac{j(j-1)\lambda^j}{j!}\\ &=e^{-\lambda}\lambda^2\sum_{k=0}^{\infty}\frac{\lambda^k}{k!} =\lambda^2.\end{aligned}

同様に j(j-1)/j!=1/(j-2)! から \mathbb E[X(X-1)]=\lambda^2。よって \mathbb E[X^2]=\lambda^2+\lambda で、分散は \lambda です。

\log p_\lambda(j)=-\lambda+j\log\lambda-\log(j!) を微分すると、スコアは (j-\lambda)/\lambda。座標基底 \left.\partial/\partial\lambda\right|_{P_\lambda} の長さの二乗は

g_{\lambda\lambda}(P_\lambda)=\frac{\mathbb E[(X-\lambda)^2]}{\lambda^2}=\frac1\lambda.

最後の等号では \mathbb E[(X-\lambda)^2] を分散と読みます。実際に展開すると (\lambda^2+\lambda)-2\lambda\cdot\lambda+\lambda^2=\lambda。分母 \lambda^2 で割るため g_{\lambda\lambda}=1/\lambda になります。初期値 \lambda=3 なら、図の基底の長さは \sqrt{1/3}\approx0.577 です。

項は無数にあっても、確率をすべて足せば1になります。球面上の角度と、平均回数を変えてたどるモデル内の距離を順に求めます。

座標ごとの平方根 F(P_\lambda)_j=2\sqrt{p_\lambda(j)} を無限に並べます。全成分の二乗和は4です。異なる平均 \lambda,\kappa に対して指数関数の級数を使うと、

3. KLの二階微分からフィッシャー計量を求める

実際の分布と予測分布を分ける

実際の分布は P=\mathcal N(\mu,\sigma^2)、予測分布は Q=\mathcal N(m,r^2)。\mu,m\in\mathbb R は平均、\sigma,r>0 は標準偏差です。x\in\mathbb R は一つの観測値です。

P から観測し、Q で予測します。\mathbb E_P は、観測ごとの値 f に実際の分布の重みを掛けて足す操作です。

\mathbb E_P[f(X)]=\int p_P(x)\,f(x)\,dx.

一つの観測の損失からKLを作る

予測が観測値 x に割り当てる密度を p_Q(x) と書きます。小さな値を割り当てるほど大きくなる損失として -\log p_Q(x) を使います。自然対数を使うと、独立な観測に付けた確率や密度の積は、損失の和になります。

同じ結果を P 自身で予測したときとの差を取り、観測を出した P で平均します。この平均を D(P,Q)=D_{\rm KL}(P\Vert Q) と書きます。以下、引数を分布の座標値でも表します。

D(P,Q)=\mathbb E_P\!\left[\underbrace{-\log p_Q(X)+\log p_P(X)}_{\text{同じ観測に対する損失の差}}\right].

正規密度の比では共通の 1/\sqrt{2\pi} が消えます。対数を取ると、指数にあった二つの平方が外に出ます。

\log\frac{p_P(x)}{p_Q(x)}=\log\frac r\sigma+\frac{(x-m)^2}{2r^2}-\frac{(x-\mu)^2}{2\sigma^2}.

X-m=(X-\mu)+(\mu-m) と分けます。平方を展開して平均を取ると交差項は消えます。以下、A はこの平均を表します。

\begin{aligned}A&=\mathbb E_P[(X-m)^2]\\&=\sigma^2+2(\mu-m)\underbrace{\mathbb E_P[X-\mu]}_{0}+(\mu-m)^2.\end{aligned}
D((\mu,\sigma),(m,r))=\log(r/\sigma)+\frac{A}{2r^2}-\frac12.

なぜ二階微分を取るのか

まったく同じ予測から始めます。予測側の座標を、決めた向きに小さく t\in\mathbb R だけ動かした分布を Q_t とし、Q_0=P とします。L(t)=D(P,Q_t) をグラフにすると、横軸はこのずれ、縦軸は余分に払う平均損失です。

出発点では対数比が \log 1=0 なので高さは0。KLはどちらにずれても0以上です（-\log z\ge1-z に z=p_Q/p_P を代入して P で平均すれば、右辺は 1-1=0）。したがって滑らかなグラフの底の傾きも0です。

高さと傾きだけでは、どれほど急に損失が増える方向か読めません。出発点付近をテイラー展開すると、その違いは次の項に初めて現れます。

L(t)=\underbrace{L(0)}_{0}+\underbrace{L'(0)}_{0}t+\textcolor{#ffd389}{\underbrace{\tfrac12L''(0)t^2}_{\text{最初に残る項}}}+o(t^2).

o(t^2) は t^2 で割ると t\to0 で消える残りです。たとえば t を半分にすると、二次の項は4分の1。逆に、非常に小さいずれでKLを測れば、2L(t)/t^2 が L''(0) に近づきます。これをその方向の速さの二乗として使います。

予測側だけを二回微分する

行列の各成分を得るには、予測座標を一つずつ指定して偏微分します。二回の偏微分を並べた行列をヘッセ行列といいます。微分を済ませてから予測を実際の分布と一致させます。先に一致させると、ずっと0の関数を微分してしまいます。

\partial_m A=2(m-\mu)、\partial_r A=0 を使い、先に一階を二通り書きます。

\partial_mD=(m-\mu)/r^2,\qquad \partial_rD=1/r-A/r^3.

二階では、平均で2回、平均と標準偏差で1回ずつ、標準偏差で2回、の順に計算します。

\begin{aligned}D_{mm}&=1/r^2,\\D_{mr}=D_{rm}&=-2(m-\mu)/r^3,\\D_{rr}&=-1/r^2+3A/r^4.\end{aligned}

m=\mu,\ r=\sigma で A=\sigma^2。一階はどちらも0です。混合成分は0、最後の成分は (-1+3)/\sigma^2 です。

(g_{ab})=\frac1{\sigma^2}\begin{pmatrix}1&0\\0&2\end{pmatrix}.

この行列は何に作用するか

P を固定します。上の行列の行と列は、次式に並べた座標基底の順です。U,V\in T_P M は同じ分布での二本の接ベクトル、u^a,v^a\in\mathbb R はその基底での係数です。ここで M はこのタブの分布族です。

U=u^1\left.\frac{\partial}{\partial \mu}\right|_P+u^2\left.\frac{\partial}{\partial \sigma}\right|_P
V=v^1\left.\frac{\partial}{\partial \mu}\right|_P+v^2\left.\frac{\partial}{\partial \sigma}\right|_P
g_P(U,V)=\sum_{a=1}^2\sum_{b=1}^2 u^a g_{ab}v^b.

V=U とすると、g_P(U,U) はこの方向に分布を動かしたときの速さの二乗です。第7章では同じ式に数を入れ、実際のKLと比べます。

分布を動かして KL を作る

実際の平均 \mu と標準偏差 \sigma を固定します。第2章と同じように、座標を少し動かして予測の分布を作ります。出発点は実際の分布で、座標の変化率はあらかじめ固定します。

\begin{aligned}P&=P_{\mu,\sigma},\\ Q_s&=\gamma(s)=P_{\mu+as,\sigma+bs}.\end{aligned}

s は座標が許される範囲で0の近くに取ります。曲線の初速度 U は次の接ベクトルです。

U=\dot\gamma(0)=a\left.\frac{\partial}{\partial\mu}\right|_P+b\left.\frac{\partial}{\partial\sigma}\right|_P

観測された結果に予測が小さな確率を与えたときほど、損失を大きくします。独立な観測の尤度は各観測の確率の積です。負の対数を取ると、低い尤度ほど損失が大きくなり、積だった尤度から観測ごとの損失の和が得られます。密度を使う分布でも、尤度の積を損失の和に変える手順は同じです。

実際の分布を固定し、予測をずらした場合の平均損失から、実際の分布そのもので予測した場合の平均損失を引きます。二つの損失は同じ分布で平均するので、平均の中で負の対数の差を取れます。これが KL ダイバージェンスです。

観測値 x\in\mathbb Rでの実際の分布での値を p_P=p_{\mu,\sigma}(x)、予測側を q_s=p_{\mu+as,\sigma+bs}(x) と書きます。\mathbb E_P は、それぞれの観測値に p_P を重みとして掛けて平均する記号です。

\begin{aligned}L(s)&=\mathbb E_P[-\log q_s]-\mathbb E_P[-\log p_P]\\&=\mathbb E_P[\log(p_P/q_s)]\\&=D_{\rm KL}(P\Vert Q_s).\end{aligned}
L(s)=\int_{\mathbb R}p_{\mu,\sigma}(x)\log\frac{p_{\mu,\sigma}(x)}{p_{\mu+as,\sigma+bs}(x)}\,\mathrm dx.

なぜ二階微分を取るか

まず、何を動かすか。 実際の分布 P は固定し、予測の分布 Q_s だけを少し動かします。s はずらすためのつまみ、L(s) は平均でどれだけ損失が増えたかです。出発点では予測が実際と一致するので L(0)=0 です。

一階微分は、グラフの傾き。 L^\prime(0) は、つまみを動かした直後に、ずらした量に比例する損失が出るかを調べます。出発点では各結果の計算で分母と重みが約分され、残るのは確率の増減を全部足した値のマイナスです。ある結果に確率を足した分は、別の結果から引かれます。足し引きが打ち消し合うので L^\prime(0)=0 です。連続分布でも、同じ理由は「密度の積分がいつも1」と書けます。

二階微分は、その傾きが変わる速さ。 底で傾きが0でも、少し動いた先で傾きが急に立ち上がることはあります。たとえば、同じ点から始まる s^2 と 4s^2 は、どちらも出発点で傾き0です。傾きは順に 2s と 8s なので、後者のほうが4倍の速さで立ち上がります。

損失の式に戻ると、s が小さい範囲で、最初に残る項は次のようになります。

L(s)\approx\textcolor{#8bc5ff}{\underbrace{\tfrac12 L^{\prime\prime}(0)}_{\text{二次の係数}}}s^2.

\tfrac12 が付くのは、s^2 を二度微分すると2になるからです。例えば L^{\prime\prime}(0)=4 なら、二次の部分は 2s^2。その方向に予測を2倍ずらすと、平均損失はおよそ4倍になります。フィッシャー計量は、この二階微分が出発点と曲線の初速度だけで決まることを利用して、初速度の長さの二乗を定めます。

コインの数値とグラフで確かめる

以下では、確率や密度の正の範囲は共通です。和や積分がある場合は、一般論の正則性の条件のもとで微分と和や積分を交換します。

予測側の q_s だけを微分します。点は観測値を固定した s 微分です。負の対数を一度微分すると -\dot q_s/q_s。これをさらに微分してから、q_0=p_P を代入します。

\frac{\mathrm d}{\mathrm ds}(-\dot q_s/q_s)=(\dot q_s/q_s)^2-\ddot q_s/q_s.
\begin{aligned} L^{\prime}(0)&=-\mathbb E_P[\dot q_0/p_P],\\ L^{\prime\prime}(0)&=\mathbb E_P[(\dot q_0/p_P)^2]-\mathbb E_P[\ddot q_0/p_P].\end{aligned}

期待値の重み p_P と分母の p_P が消える項では、残るのは \dot q_0 または \ddot q_0 の和や積分です。正規化の式の一階・二階微分なので、どちらも0です。残った項では、\dot q_0/p_P が s=0 での対数確率または対数密度の変化率になります。これを方向 U のスコア S_U と書くと、

\begin{aligned}S_U&=\left.\frac{\mathrm d}{\mathrm ds}\log q_s\right|_{s=0}=\dot q_0/p_P,\\g_P(U,U)&=L^{\prime\prime}(0)=\mathbb E_P[S_U^2].\end{aligned}

平均方向と標準偏差方向のスコアを S_\mu,S_\sigma とすると、S_U=aS_\mu+bS_\sigma です。二乗すると a^2S_\mu^2+2abS_\mu S_\sigma+b^2S_\sigma^2。この3種類の積を平均すれば、計量の3成分がそろいます。 一般論で微分の各項を追う

この分布で計量を計算する

前章の二つの座標基底を e_\mu=\left.\frac{\partial}{\partial\mu}\right|_P、e_\sigma=\left.\frac{\partial}{\partial\sigma}\right|_P と書きます。スコアは、各基底を対数密度に作用させた値です。まず対数密度を三項に分けます。

\ell(x)=\log p_{\mu,\sigma}(x)=-\tfrac12\log(2\pi)-\log\sigma-\frac{(x-\mu)^2}{2\sigma^2}.

平均で微分するときは x,\sigma を固定します。最後の項の (x-\mu)^2 だけが動きます。二乗の微分で 2(x-\mu)、内側の微分で -1 が出ます。

\begin{aligned}S_\mu(x)=\partial_\mu\ell(x) &=-\frac{2(x-\mu)(-1)}{2\sigma^2}\\&=\frac{x-\mu}{\sigma^2}. \end{aligned}

幅で微分するときは x,\mu を固定します。-\log\sigma と \sigma^{-2} を含む項の二つが動きます。

\begin{aligned}S_\sigma(x)=\partial_\sigma\ell(x) &=-\frac1\sigma-\tfrac12(x-\mu)^2(-2)\sigma^{-3}\\&=-\frac1\sigma+\frac{(x-\mu)^2}{\sigma^3}. \end{aligned}

何を平均するか

分布を P=P_{\mu,\sigma} に固定します。X はこの分布から得る観測値、x はその具体的な値です。e_\mu は幅を固定して平均を変える方向、e_\sigma は平均を固定して幅を変える方向でした。

ここでの内積は、同じ観測値での二つのスコアを掛け、その積を分布 P で平均した値です。例えば g_P(e_\mu,e_\sigma) では、各 x で S_\mu(x)S_\sigma(x) を作り、確率密度 p_{\mu,\sigma}(x) を掛けて積分します。

\begin{aligned}g_P(e_\mu,e_\sigma) &=\mathbb E_P[S_\mu(X)S_\sigma(X)]\\ &=\int_{-\infty}^{\infty}S_\mu(x)S_\sigma(x)\,p_{\mu,\sigma}(x)\,\mathrm dx. \end{aligned}

平均を計算しやすい変数に移す

Z=(X-\mu)/\sigma と置き、観測値 x に対応する値を z=(x-\mu)/\sigma と書きます。スコアの式に x-\mu=\sigma z を代入すると、

\begin{aligned}S_\mu(x)&=\frac{\sigma z}{\sigma^2}=\frac z\sigma,\\ S_\sigma(x)&=-\frac1\sigma+\frac{\sigma^2 z^2}{\sigma^3}=\frac{z^2-1}{\sigma}. \end{aligned}

期待値の積分も x=\mu+\sigma z で置換できます。指数の (x-\mu)^2/(2\sigma^2) は z^2/2 になり、\mathrm dx=\sigma\,\mathrm dz が密度の分母の \sigma を消します。

\begin{aligned}p_{\mu,\sigma}(x)\,\mathrm dx &=\frac{1}{\sqrt{2\pi}\,\sigma}e^{-z^2/2}\,\sigma\,\mathrm dz\\ &=\underbrace{\frac{1}{\sqrt{2\pi}}e^{-z^2/2}}_{\varphi(z)}\,\mathrm dz. \end{aligned}

したがって \mathbb E[Z^j] は、z^j\varphi(z) を実数全体で積分したものです。\mu,\sigma は固定しているので、積に現れる 1/\sigma^2 は平均の外に出せます。

使う四つの平均を求める

\varphi(-z)=\varphi(z) です。z や z^3 を掛けると、z と -z の値が符号だけ逆になるため、積分が打ち消し合います。よって \mathbb E[Z]=\mathbb E[Z^3]=0 です。

二乗と四乗は部分積分で求めます。\varphi'(z)=-z\varphi(z) なので、一つの z を密度の微分に置き換えます。端の項は、指数の減衰が z,z^3 の増加より速いので0です。

\begin{aligned}\mathbb E[Z^2] &=-\int_{\mathbb R}z\varphi'(z)\,\mathrm dz\\ &=-[z\varphi(z)]_{-\infty}^{\infty}+\int_{\mathbb R}\varphi(z)\,\mathrm dz\\ &=0+1=1. \end{aligned} =\begin{aligned}\mathbb E[Z^4] &=-\int_{\mathbb R}z^3\varphi'(z)\,\mathrm dz\\ &=-[z^3\varphi(z)]_{-\infty}^{\infty}+3\int_{\mathbb R}z^2\varphi(z)\,\mathrm dz\\ &=0+3\mathbb E[Z^2]=3. \end{aligned}

各成分を一つずつ計算する

まず平均方向を二度入れます。掛けるのは Z/\sigma と Z/\sigma です。

\begin{aligned}g_P(e_\mu,e_\mu) &=\mathbb E\!\left[\frac Z\sigma\frac Z\sigma\right]\\ &=\frac{\mathbb E[Z^2]}{\sigma^2} =\frac{1}{\sigma^2}. \end{aligned}

次に平均方向と幅方向を一度ずつ入れます。積 Z(Z^2-1) を開くと Z^3-Z です。平均は引き算の各項に分けられます。

\begin{aligned}g_P(e_\mu,e_\sigma) &=\mathbb E\!\left[\frac Z\sigma\frac{Z^2-1}{\sigma}\right]\\ &=\frac{\mathbb E[Z^3]-\mathbb E[Z]}{\sigma^2}\\ &=\frac{0-0}{\sigma^2}=0. \end{aligned}

最後に幅方向を二度入れます。二乗の中の -2Z^2 は、Z^2 と -1 の積が二度現れる項です。定数 1 の平均はそのまま 1 です。

\begin{aligned}g_P(e_\sigma,e_\sigma) &=\mathbb E\!\left[\frac{(Z^2-1)^2}{\sigma^2}\right]\\ &=\frac{\mathbb E[Z^4]-2\mathbb E[Z^2]+1}{\sigma^2}\\ &=\frac{3-2\cdot1+1}{\sigma^2}=\frac2{\sigma^2}. \end{aligned}

三つの値を行列と図へ戻す

基底の順を (e_\mu,e_\sigma) とします。一行一列が平均の基底を二度入れた値、一行二列が二つを一度ずつ入れた値です。二行一列は掛ける順を逆にした同じ積なので0です。

G(P)=\begin{pmatrix}1/\sigma^2&0\\0&2/\sigma^2\end{pmatrix}.

例えば図の初期値 \sigma=1 では、内積が0で長さはそれぞれ \sqrt1=1、\sqrt2\approx1.414 です。\sigma=2 に動かすと行列の対角は 1/4,1/2 になり、長さは 0.500,0.707 になります。

4. 平方根写像とモデル内の距離

分布
P\in M_{\rm N}平方根を取る前の分布。
写した点
F(P)\in L^2(\mathbb R)二乗の積分が有限な関数。

連続な観測値 x\in\mathbb R に対する密度を p_P(x) と書きます。前章の計量で測った二つの速度の内積を、平方根を取った後のふつうの内積として読みます。

F(P)(x)=2\sqrt{p_P(x)},\qquad \int_{-\infty}^\infty F(P)(x)^2\,\mathrm dx=4.

密度の積分が1なので、関数の二乗を積分して測った半径は2です。平均と標準偏差で指定できる分布だけを通る道と、球面全体で許される道を区別します。

正規分布の密度から F(P)(x)=2\sqrt{p_P(x)} を作ると、二乗の積分は4です。前章の計量は、この写像で移した曲線の速さを測ります。ここでは同じ平均を持つ2点で、モデル内の距離と球面全体の距離を比較します。

曲線 c(t)=P_{\mu(t),\sigma(t)} の速度は \dot\mu(t)\left.\frac{\partial}{\partial\mu}\right|_{c(t)}+\dot\sigma(t)\left.\frac{\partial}{\partial\sigma}\right|_{c(t)} です。上の内積を使えば、

\begin{aligned}\ell_g(c)&=\int_0^1\frac{\sqrt{\dot\mu^2+2\dot\sigma^2}}{\sigma}\,\mathrm dt\\&\ge\sqrt{2}\int_0^1\frac{|\dot\sigma|}{\sigma}\,\mathrm dt\\&\ge\sqrt{2}\left|\log\frac{\sigma(1)}{\sigma(0)}\right|.\end{aligned}

第1の不等号は平方根の中から \dot\mu^2 を外したものです。第2の不等号では、絶対値を付ける前の被積分関数 \dot\sigma/\sigma が \log\sigma の微分であることを使いました。平均が同じ端点なら、\mu を固定し、\log\sigma(t)=(1-t)\log\sigma(0)+t\log\sigma(1) と置くと両方で等号が成り立ちます。これで正規分布の族の中での最短経路が一本求まりました。

長さの式の第1の不等式は、平方根の中の \dot\mu^2\ge0 を外して得ます。第2の不等式では \int |\dot\sigma/\sigma|\,\mathrm dt\ge|\int \dot\sigma/\sigma\,\mathrm dt| を使います。中の積分は \log\sigma の端点での差です。同じ平均を保ち、\sigma を一方向に動かせば、どちらも等号になります。

球面上の距離と比べる

P=\mathcal N(0,1)、Q=\mathcal N(0,2^2) とします。直前の計算でモデル内の距離は \sqrt2\log 2 と決まりました。一方、平方根写像で移した2点の角度を計算するには、密度の幾何平均を積分します。

\begin{aligned}\sqrt{p_P(x)p_Q(x)}&=\frac{1}{2\sqrt\pi}e^{-5x^2/16},\\\int_{\mathbb R}\sqrt{p_Pp_Q}\,\mathrm dx&=\frac{1}{2\sqrt\pi}\sqrt{\frac{16\pi}{5}}=\frac2{\sqrt5}.\end{aligned}

2行目にはガウス積分 \int_{\mathbb R}e^{-ax^2}\,\mathrm dx=\sqrt{\pi/a}（a>0）を使いました。

球面の短い大円弧を正規分布だけでたどれたなら、正規分布の族でもその長さで両端を結べるはずです。この例では距離に差があるので、短い大円弧は途中で F(\mathcal M) から外れます。

計量の測地線の弧はどこから来るか

第3章で得た計量から求めた速度の長さは \sqrt{\dot\mu^2+2\dot\sigma^2}/\sigma です。横軸の座標だけ z=\mu/\sqrt2 に替えると、長さは \sqrt2\int\sqrt{\dot z^2+\dot\sigma^2}/\sigma\,\mathrm dt になります。この長さが定めるのは、上半平面の双曲計量の定数倍です。上半平面の測地線は、境界 \sigma=0 に垂直な直線か、境界に直交する円弧です。この結果を使うと、今回の両端は高さが同じで z が正負対称なので、円の中心は (z,\sigma)=(0,0) です。半径の二乗は端点で z^2+\sigma^2=1/2+1=3/2。元の \mu 座標へ戻して図の式が得られます。

弧の方程式を測地線方程式で確かめる

計量の行列は対角で g_{\mu\mu}=1/\sigma^2,\ g_{\sigma\sigma}=2/\sigma^2 でした。逆行列の対角成分は \sigma^2,\sigma^2/2 です。計量の微分が現れるのは \sigma 方向だけなので、クリストッフェル記号の式から、ゼロでない成分は次の4つです。

\Gamma^k_{ij}=\frac12\sum_\ell g^{k\ell}(\partial_i g_{j\ell}+\partial_j g_{i\ell}-\partial_\ell g_{ij}).
\begin{aligned}\Gamma^\mu_{\mu\sigma}=\Gamma^\mu_{\sigma\mu}&=\tfrac12\sigma^2\partial_\sigma(\sigma^{-2})=-1/\sigma,\\\Gamma^\sigma_{\mu\mu}&=-\tfrac12(\sigma^2/2)\partial_\sigma(\sigma^{-2})=1/(2\sigma),\\\Gamma^\sigma_{\sigma\sigma}&=\tfrac12(\sigma^2/2)\partial_\sigma(2\sigma^{-2})=-1/\sigma.\end{aligned}

統計多様体の一般論の第6節で得た測地線方程式に代入します。t を測地線のアフィンパラメータとすると、

\ddot\mu=2\dot\mu\dot\sigma/\sigma,\qquad \ddot\sigma=(\dot\sigma^2-\dot\mu^2/2)/\sigma.

弧の途中では \mu を横軸として使えるので、\sigma=f(\mu) と置きます。\dot\sigma=f'\dot\mu、\ddot\sigma=f''\dot\mu^2+f'\ddot\mu を代入して、\dot\mu^2 で割ると ff''+(f')^2=-1/2 です。左辺は (ff')' なので二度積分して f^2=-\mu^2/2+C\mu+D となります。端点 f(-1)=f(1)=1 を入れると C=0,\ D=3/2 となり、図の弧が戻ります。

3. KLの二階微分からフィッシャー計量を求める

実際の分布と予測分布を分ける

実際の形状・尺度を (k,\theta)、予測の形状・尺度を (h,r) と書き、すべて正とします。x>0 における密度は p_{k,\theta}(x)=x^{k-1}e^{-x/\theta}/[\Gamma(k)\theta^k]。尺度には長さや時間など観測量と同じ単位を使い、以下の対数は同じ単位での数値に取ります。

P から観測し、Q で予測します。\mathbb E_P は、観測ごとの値 f に実際の分布の重みを掛けて足す操作です。

\mathbb E_P[f(X)]=\int p_P(x)\,f(x)\,dx.

一つの観測の損失からKLを作る

予測が観測値 x に割り当てる密度を p_Q(x) と書きます。小さな値を割り当てるほど大きくなる損失として -\log p_Q(x) を使います。自然対数を使うと、独立な観測に付けた確率や密度の積は、損失の和になります。

同じ結果を P 自身で予測したときとの差を取り、観測を出した P で平均します。この平均を D(P,Q)=D_{\rm KL}(P\Vert Q) と書きます。以下、引数を分布の座標値でも表します。

D(P,Q)=\mathbb E_P\!\left[\underbrace{-\log p_Q(X)+\log p_P(X)}_{\text{同じ観測に対する損失の差}}\right].

分子と分母のべき指数の差は k-h。指数関数と規格化因子も順に対数に移します。

\begin{aligned}\log\frac{p_{k,\theta}(x)}{p_{h,r}(x)}&=(k-h)\log x+x(1/r-1/\theta)\\&\quad+\log\Gamma(h)-\log\Gamma(k)\\&\quad+h\log r-k\log\theta.\end{aligned}

平均が必要なのは X と \log X です。Y=X/\theta と置けば、その密度は y^{k-1}e^{-y}/\Gamma(k)。\Gamma(k)=\int_0^\infty y^{k-1}e^{-y}\,dy を使います。

\mathbb E[Y]=\frac{\Gamma(k+1)}{\Gamma(k)}=k,\qquad \mathbb E[X]=k\theta.

\Gamma(k+1)=k\Gamma(k) は部分積分から得られます。また、y^{k-1} を k で微分すると \log y が掛かります。この積分は k>0 で微分できます。

\mathbb E[\log Y]=\frac{\Gamma'(k)}{\Gamma(k)}=:\psi(k),\qquad \mathbb E[\log X]=\log\theta+\psi(k).

対数比の x,\log x にこの二つの平均を入れ、尺度の対数をまとめます。

\begin{aligned}D((k,\theta),(h,r))&=(k-h)\psi(k)+\log\Gamma(h)-\log\Gamma(k)\\&\quad+h\log(r/\theta)+k(\theta/r-1).\end{aligned}

なぜ二階微分を取るのか

まったく同じ予測から始めます。予測側の座標を、決めた向きに小さく t\in\mathbb R だけ動かした分布を Q_t とし、Q_0=P とします。L(t)=D(P,Q_t) をグラフにすると、横軸はこのずれ、縦軸は余分に払う平均損失です。

出発点では対数比が \log 1=0 なので高さは0。KLはどちらにずれても0以上です（-\log z\ge1-z に z=p_Q/p_P を代入して P で平均すれば、右辺は 1-1=0）。したがって滑らかなグラフの底の傾きも0です。

高さと傾きだけでは、どれほど急に損失が増える方向か読めません。出発点付近をテイラー展開すると、その違いは次の項に初めて現れます。

L(t)=\underbrace{L(0)}_{0}+\underbrace{L'(0)}_{0}t+\textcolor{#ffd389}{\underbrace{\tfrac12L''(0)t^2}_{\text{最初に残る項}}}+o(t^2).

o(t^2) は t^2 で割ると t\to0 で消える残りです。たとえば t を半分にすると、二次の項は4分の1。逆に、非常に小さいずれでKLを測れば、2L(t)/t^2 が L''(0) に近づきます。これをその方向の速さの二乗として使います。

V=v^1\left.\frac{\partial}{\partial k}\right|_P+v^2\left.\frac{\partial}{\partial \theta}\right|_P
g_P(U,V)=\sum_{a=1}^2\sum_{b=1}^2 u^a g_{ab}v^b.

V=U とすると、g_P(U,U) はこの方向に分布を動かしたときの速さの二乗です。第7章では同じ式に数を入れ、実際のKLと比べます。

分布を動かして KL を作る

実際の形状 k と尺度 \theta を固定します。第2章と同じように、座標を少し動かして予測の分布を作ります。出発点は実際の分布で、座標の変化率はあらかじめ固定します。

\begin{aligned}P&=P_{k,\theta},\\ Q_s&=\gamma(s)=P_{k+as,\theta+bs}.\end{aligned}

s は座標が許される範囲で0の近くに取ります。曲線の初速度 U は次の接ベクトルです。

U=\dot\gamma(0)=a\left.\frac{\partial}{\partial k}\right|_P+b\left.\frac{\partial}{\partial\theta}\right|_P

観測された結果に予測が小さな確率を与えたときほど、損失を大きくします。独立な観測の尤度は各観測の確率の積です。負の対数を取ると、低い尤度ほど損失が大きくなり、積だった尤度から観測ごとの損失の和が得られます。密度を使う分布でも、尤度の積を損失の和に変える手順は同じです。

実際の分布を固定し、予測をずらした場合の平均損失から、実際の分布そのもので予測した場合の平均損失を引きます。二つの損失は同じ分布で平均するので、平均の中で負の対数の差を取れます。これが KL ダイバージェンスです。

観測値 x>0での実際の分布での値を p_P=p_{k,\theta}(x)、予測側を q_s=p_{k+as,\theta+bs}(x) と書きます。\mathbb E_P は、それぞれの観測値に p_P を重みとして掛けて平均する記号です。

\begin{aligned}L(s)&=\mathbb E_P[-\log q_s]-\mathbb E_P[-\log p_P]\\&=\mathbb E_P[\log(p_P/q_s)]\\&=D_{\rm KL}(P\Vert Q_s).\end{aligned}
L(s)=\int_0^\infty p_{k,\theta}(x)\log\frac{p_{k,\theta}(x)}{p_{k+as,\theta+bs}(x)}\,\mathrm dx.

なぜ二階微分を取るか

まず、何を動かすか。 実際の分布 P は固定し、予測の分布 Q_s だけを少し動かします。s はずらすためのつまみ、L(s) は平均でどれだけ損失が増えたかです。出発点では予測が実際と一致するので L(0)=0 です。

一階微分は、グラフの傾き。 L^\prime(0) は、つまみを動かした直後に、ずらした量に比例する損失が出るかを調べます。出発点では各結果の計算で分母と重みが約分され、残るのは確率の増減を全部足した値のマイナスです。ある結果に確率を足した分は、別の結果から引かれます。足し引きが打ち消し合うので L^\prime(0)=0 です。連続分布でも、同じ理由は「密度の積分がいつも1」と書けます。

二階微分は、その傾きが変わる速さ。 底で傾きが0でも、少し動いた先で傾きが急に立ち上がることはあります。たとえば、同じ点から始まる s^2 と 4s^2 は、どちらも出発点で傾き0です。傾きは順に 2s と 8s なので、後者のほうが4倍の速さで立ち上がります。

損失の式に戻ると、s が小さい範囲で、最初に残る項は次のようになります。

L(s)\approx\textcolor{#8bc5ff}{\underbrace{\tfrac12 L^{\prime\prime}(0)}_{\text{二次の係数}}}s^2.

\tfrac12 が付くのは、s^2 を二度微分すると2になるからです。例えば L^{\prime\prime}(0)=4 なら、二次の部分は 2s^2。その方向に予測を2倍ずらすと、平均損失はおよそ4倍になります。フィッシャー計量は、この二階微分が出発点と曲線の初速度だけで決まることを利用して、初速度の長さの二乗を定めます。

コインの数値とグラフで確かめる

以下では、確率や密度の正の範囲は共通です。和や積分がある場合は、一般論の正則性の条件のもとで微分と和や積分を交換します。

予測側の q_s だけを微分します。点は観測値を固定した s 微分です。負の対数を一度微分すると -\dot q_s/q_s。これをさらに微分してから、q_0=p_P を代入します。

\frac{\mathrm d}{\mathrm ds}(-\dot q_s/q_s)=(\dot q_s/q_s)^2-\ddot q_s/q_s.
\begin{aligned} L^{\prime}(0)&=-\mathbb E_P[\dot q_0/p_P],\\ L^{\prime\prime}(0)&=\mathbb E_P[(\dot q_0/p_P)^2]-\mathbb E_P[\ddot q_0/p_P].\end{aligned}

期待値の重み p_P と分母の p_P が消える項では、残るのは \dot q_0 または \ddot q_0 の和や積分です。正規化の式の一階・二階微分なので、どちらも0です。残った項では、\dot q_0/p_P が s=0 での対数確率または対数密度の変化率になります。これを方向 U のスコア S_U と書くと、

\begin{aligned}S_U&=\left.\frac{\mathrm d}{\mathrm ds}\log q_s\right|_{s=0}=\dot q_0/p_P,\\g_P(U,U)&=L^{\prime\prime}(0)=\mathbb E_P[S_U^2].\end{aligned}

形状と尺度の二つのスコアから計量の3成分が決まります。この例では二つのスコアの積を直接積分する代わりに、KLの定義で s に依存する -\log q_s を二度微分した形を使うと計算しやすくなります。下で両者が一致する理由も確認します。 一般論で微分の各項を追う

この分布で計量を計算する

e_k=\left.\partial/\partial k\right|_P と e_\theta=\left.\partial/\partial\theta\right|_P を、同じ点 P=P_{k,\theta} で取ります。密度の対数を \ell=(k-1)\log x-x/\theta-\log\Gamma(k)-k\log\theta と置きます。フィッシャー行列は、スコアの積を平均するほかに、次の形でも計算できます。

0=\int_0^\infty\partial_a\partial_b p\,\mathrm dx=\mathbb E_P[(\partial_a\ell)(\partial_b\ell)+\partial_a\partial_b\ell].

最初の等号は \int p\,\mathrm dx=1 を二度微分した結果です。次の等号では \partial_b p=p\partial_b\ell を積の微分で展開しました。従って g_{ab}=-\mathbb E_P[\partial_a\partial_b\ell] です。

尺度のスコアは \partial_\theta\ell=x/\theta^2-k/\theta。これを k で微分すれば -1/\theta で、x によらないので

g_P(e_k,e_\theta)=-\mathbb E_P[-1/\theta]=1/\theta.

k で二回微分した項は -(\log\Gamma)''(k)。尺度で二回微分した項は -2x/\theta^3+k/\theta^2 です。尺度のスコアの平均が0なので \mathbb E[X]=k\theta。この値を入れて行列をまとめます。

(g_{ab})_{a,b\in\{k,\theta\}}=\begin{pmatrix}(\log\Gamma)''(k)&1/\theta\\1/\theta&k/\theta^2\end{pmatrix}.

尺度側の対角成分では、-2x/\theta^3+k/\theta^2 の平均にマイナスを付けます。平均を取るのは x の項だけです。

\begin{aligned}g_{\theta\theta} &=-\mathbb E_P[-2X/\theta^3+k/\theta^2]\\ &=\frac{2}{\theta^3}\mathbb E_P[X]-\frac{k}{\theta^2}\\ &=\frac{2k\theta}{\theta^3}-\frac{k}{\theta^2}=\frac{k}{\theta^2}. \end{aligned}

4. 密度の平方根と球面上の角度

分布
P\in M_{\Gamma}平方根を取る前の分布。
写した点
F(P)\in L^2((0,\infty))二乗の積分が有限な関数。

観測値の範囲は x>0、そこでの密度は p_P(x) です。前章の計量で測った二つの速度の内積を、平方根を取った後のふつうの内積として読みます。

F(P)(x)=2\sqrt{p_P(x)},\qquad \int_0^\infty F(P)(x)^2\,\mathrm dx=4.

密度の積分が1なので、平方根を取った関数は半径2の球面上にあります。ガンマ分布の像は球面の一部です。球面全体で測った距離はモデル内の距離の下限を与えます。

平方根写像は F(P)(x)=2\sqrt{p_P(x)}。二乗の積分は4です。微分した関数は \mathrm dF_P(U)=\sqrt{p_P}\,U\ell なので、二つの速度の積を積分すれば、スコアの積を P で平均した量 g_P(U,V) が戻ります。

写した点の半径を確認します。密度 p_P(x) を積分した値は1なので、写した関数を二乗して積分すると、

\|F(P)\|_{L^2}^2=\int_0^\infty (2\sqrt{p_P(x)})^2\,\mathrm dx=4\int_0^\infty p_P(x)\,\mathrm dx=4.

半径はこのノルムの正の平方根なので2です。

形状 k が同じで尺度だけ \theta,\tau が違う二つの分布では、密度の幾何平均を積分すると

\int_0^\infty\sqrt{p_{k,\theta}(x)p_{k,\tau}(x)}\,\mathrm dx=\left(\frac{2\sqrt{\theta\tau}}{\theta+\tau}\right)^k.

分子の指数を足すと減衰率は (1/\theta+1/\tau)/2 です。第1章と同じ置換で積分すると上式になります。この値は球面上の角の余弦です。

積分で使った尺度を式にしておきます。b=2\theta\tau/(\theta+\tau) とすると、幾何平均は x^{k-1}e^{-x/b}/[\Gamma(k)(\theta\tau)^{k/2}] です。x=bt と置けば積分は b^k\Gamma(k)/[\Gamma(k)(\theta\tau)^{k/2}]。b の式を入れて約分すると上式になります。

例えば k=2,\theta=1,\tau=2 なら、括弧の中は 2\sqrt{2}/3 です。二乗して 8/9 が角度の余弦になります。半径は2なので、大円弧の長さは 2\arccos(8/9) です。モデル内部での曲線長との関係は、一般論の平方根写像で確認できます。

対数密度で \log x,x の係数を取ると、自然座標は \alpha^1=k-1,\ \alpha^2=-1/\theta。期待値座標は \eta_1=\mathbb E[\log X],\ \eta_2=\mathbb E[X] です。第2章の各スコアの平均を0と置いて解くと、

形状を k=2 にそろえ、尺度が1と4の分布を結びます。指数接続では \alpha^1 を固定し、\alpha^2 を線形補間します。中点で \alpha^2=(-1-1/4)/2=-5/8、したがって \theta=8/5 です。

同じ端点を結ぶ、計量の測地線

上の二本と同じ P_{2,1} から P_{2,4} に達する曲線を求めます。計量の接続での時刻 t はフィッシャー計量で測った速さが一定になるように取ります。尺度の対数 y=\log\theta を使うと \dot\theta=\theta\dot y。第3章の内積の式に代入して、速さの二乗を次の形にします。

\begin{aligned}A(k)&=(\log\Gamma)^{\prime\prime}(k),\\ 2E&=A(k)\dot k^2+2\dot k\dot y+k\dot y^2.\end{aligned}

E は速さの二乗の半分です。端点を固定したとき、エネルギー \int_0^1 E\,\mathrm dt の停留条件から、計量の測地線を求められます。ここで停留とは、曲線を微小に変えたときの一次の変化が0という意味です。座標 z=k,y それぞれで、条件は \frac{\mathrm d}{\mathrm dt}(\partial_{\dot z} E)=\partial_z E です。

\begin{aligned}\partial_{\dot k}E&=A(k)\dot k+\dot y, &\partial_k E&=\tfrac12 A^{\prime}(k)\dot k^2+\tfrac12\dot y^2,\\\partial_{\dot y}E&=\dot k+k\dot y,&\partial_y E&=0.\end{aligned}

上の左列を t で微分して右列と結び、二階微分を左へ集めます。

\begin{aligned}A(k)\ddot k+\ddot y &=\tfrac12[\dot y^2-A^{\prime}(k)\dot k^2],\\ \ddot k+k\ddot y &=-\dot k\dot y.\end{aligned}

境界条件は (k(0),y(0))=(2,0)、(k(1),y(1))=(2,\log 4)。この二式と両端の四つの値を同時に満たす数値解では、中点が k(1/2)\approx1.42727, y(1/2)\approx1.03053 になります。元の尺度は \theta(1/2)=\exp(y(1/2))\approx2.80256 です。次の図ではこの解をほかの二本と同じ時刻で比較します。

確率分布の族を滑らかな多様体として扱い、ここではそのモデルを統計多様体と呼びます。点は分布です。そこにフィッシャー計量と接続を入れ、分布の変化を幾何学として調べます。

3カテゴリの第1章で扱った三角形では、点 P を選ぶと3つの確率が決まりました。今度は、観測できる値の集合を \Omega とし、その上の分布を集めます。たとえば身長を正規分布でモデル化するなら、観測値は実数で、分布を指定する座標は平均と標準偏差です。

観測値・分布・座標を区別する

観測値の種類に応じて、分布の書き方を二通り用意します。結果が有限個または数え上げられる場合、p_P(x) は結果 x の確率です。観測値が実数で密度を持つ場合、p_P(x) は密度で、区間 [a,b] に入る確率は \int_a^b p_P(x)\,\mathrm dx です。以下で同じ計算を両方に使えるよう、関数 h を観測範囲全体で足す操作を \mathcal I[h] と書きます。

\begin{aligned}\mathcal I[h]&=\sum_{x\in\Omega}h(x) &\quad&\text{（離散分布）},\\\mathcal I[h]&=\int_\Omega h(x)\,\mathrm dx &\quad&\text{（連続分布）}.\end{aligned}

たとえば3結果なら \mathcal I[p_P]=P(A_1)+P(A_2)+P(A_3)=1、実数全体の密度なら \mathcal I[p_P]=\int_{-\infty}^{\infty}p_P(x)\,\mathrm dx=1 です。本文の \mathcal I はこのどちらかを表す略記です。

d 個の実数を並べた \vartheta=(\vartheta^1,\ldots,\vartheta^d) を使って、分布の族を指定します。\Theta\subset\mathbb R^d を開集合として、

\begin{aligned}\Theta&\longrightarrow \mathcal M,\\\vartheta&\longmapsto P_\vartheta,\\\mathcal M&=\{P_\vartheta\mid\vartheta\in\Theta\}.\end{aligned}

ここでは二つの異なる \vartheta が同じ分布を表さないと仮定します。このとき逆写像 \theta:\mathcal M\to\Theta を座標に取れます。\theta^a は第 a 座標を返す関数で、\theta^a(P_\vartheta)=\vartheta^a です。この座標で \mathcal M に滑らかな構造を入れます。一つの座標で全体を覆えない場合は、座標を局所的に取り、重なりでの座標変換が滑らかだとします。

これからの計算に使う仮定

以下では、どの分布でも結果の範囲を同じ \Omega に取り、その範囲で確率または密度が正だとします。p_\vartheta(x)=p_{P_\vartheta}(x) は座標について滑らかとします。ここで扱うKLは有限とします。和や積分を微分するときは、その中に微分を入れてよい場合を扱います。有限個の結果では、各項を微分してから足せます。無限の和や積分では追加の条件がいります。たとえば、座標を少し動かしても各導関数の絶対値を一つの関数で上から抑えられ、その関数の和や積分が有限なら、交換できます。フィッシャー行列が有限かつ正定値で、座標に滑らかに依存することも仮定し、これらの条件を満たす正則なモデルを扱います。

異なる座標値が異なる分布を表すという条件は、有限のずれを区別する条件です。正定値性は、どの非零方向にも一次の密度変化があるという、各点での条件です。この意味は第3節で計算します。

座標の向きは、正規分布で具体的に区別できます。たとえば実数の組 (0,1) を入れると分布 P_{0,1} が得られます。逆向きの座標写像 \theta に P_{0,1} を入れると、平均と標準偏差を読んで (0,1) が戻ります。観測値 x を入れて密度を読む関数は、これらとは別に p_{P_{0,1}}(x) と書きます。

実数として読む値
\vartheta^a(s),u^a,U(f)\in\mathbb R曲線上の座標値や、接ベクトルで関数を微分した値。

滑らかな曲線 \gamma:(-\varepsilon,\varepsilon)\to\mathcal M を取り、P=\gamma(0) とします。曲線に沿う座標値を \vartheta^a(s)=\theta^a(\gamma(s))、その初速度を u^a=(\vartheta^a)'(0) と置きます。

\mathcal M 上の滑らかな関数 f を座標空間の関数に直すと、\widetilde f=f\circ\theta^{-1} です。そこで P での座標基底を次のように定義します。

\left(\left.\frac{\partial}{\partial\theta^a}\right|_P\right)(f):=\frac{\partial\widetilde f}{\partial\vartheta^a}(\theta(P)).

曲線の速度 U=\dot\gamma(0) を f に作用させ、実数の関数 s\mapsto\widetilde f(\vartheta(s)) に連鎖律を使います。

\begin{aligned}U(f)&=\left.\frac{\mathrm d}{\mathrm ds}f(\gamma(s))\right|_{0}\\&=\left.\frac{\mathrm d}{\mathrm ds}\widetilde f(\vartheta(s))\right|_0\\&=\sum_{a=1}^{d}u^a\frac{\partial\widetilde f}{\partial\vartheta^a}(\theta(P)).\end{aligned}

これは任意の f で成り立つので、接ベクトルを基底付きで書けます。

U=\sum_{a=1}^{d}u^a\left.\frac{\partial}{\partial\theta^a}\right|_P\in T_P\mathcal M.

とくに f=\theta^b を入れると、座標上では \widetilde f(\vartheta)=\vartheta^b。その \vartheta^a による偏微分は a=b なら1、異なれば0です。従って U(\theta^b)=u^b で、各係数は座標関数を接ベクトルに渡して取り出せます。

たとえばコインで、分布の多様体を M とし、P_r を表の確率が r の分布とし、r=0.40 から表の確率を毎単位 s あたり 0.10 ずつ増やします。分布から表の確率を読む関数を \pi:M\to(0,1) とします。曲線を定義できる区間 I は、たとえば I=(-1,1) です。

\begin{aligned}s&\in I\subseteq\mathbb R,\\\gamma(s)&=\pi^{-1}(0.40+0.10s)=P_{0.40+0.10s}\in M,\\U&=\dot\gamma(0)=0.10\left.\frac{\partial}{\partial\pi}\right|_{P_{0.40}}\in T_{P_{0.40}}M.\end{aligned}

次は速度 U に、表の確率を読む関数 \pi:M\to(0,1) を渡します。

\begin{aligned}U(\pi)&=\left.\frac{\mathrm d}{\mathrm ds}(\pi\circ\gamma)(s)\right|_{s=0}\\&=\left.\frac{\mathrm d}{\mathrm ds}(0.40+0.10s)\right|_{s=0}=0.10\in\mathbb R.\end{aligned}

U は接ベクトルで、U(\pi) はそのベクトルで表の確率の変化率を読んだ実数です。

密度や対数密度を微分する

ここからの計算では観測値 x を一つ固定します。R\mapsto p_R(x) を関数として U に渡すと、その x での密度が曲線に沿って変わる速さが得られます。これを Up(x) と略します。ここでは、座標を動かしたとき滑らかに変化する式で確率や密度を表します。

Up(x)=\sum_a u^a\frac{\partial p_\vartheta(x)}{\partial\vartheta^a}\bigg|_{\vartheta=\theta(P)}.

\mathcal I\!\left[p_{\gamma(s)}\right]=1 を s で微分すると \mathcal I\!\left[Up\right]=0 です。三角形で3つの確率の変化率を足すと0になることに対応します。

正規化の微分は、各確率や密度を動かしても全体が1である、という事実の微分です。先ほどの記号で書くと、

0=\left.\frac{\mathrm d}{\mathrm ds}\mathcal I[p_{\gamma(s)}]\right|_{0} =\mathcal I\!\left[\left.\frac{\mathrm d}{\mathrm ds}p_{\gamma(s)}\right|_0\right] =\mathcal I[Up].

中央の等号で、第1節の「和や積分の中で微分できる」という仮定を使いました。

今度は R\mapsto\log p_R(x) を U に渡します。連鎖律を使うと、x での対数密度の変化率は

U\log p(x)=\frac{Up(x)}{p_P(x)}.

座標基底ごとの対数密度の変化率 S_a(x)=\partial_a\log p_\vartheta(x) をスコアと呼びます。以降、\partial_a は座標値 \vartheta^a での偏微分です。したがって U\log p(x)=\sum_a u^a S_a(x) です。

3. KLの二階微分からフィッシャー計量へ

六つの具体例と同じ微分を記号で書く

座標の次元を d、座標写像を \pi、固定する分布を P\in\mathcal M とします。予測側の座標値 z=(z^1,\ldots,z^d) から分布 Q=\pi^{-1}(z) に戻します。この二つの分布で平均予測損失の差（KL）を作り、右側だけを動かします。損失の定義とこの微分を選ぶ理由はすぐ下で導きます。

F(z)=D_{\rm KL}\!\left(P\Vert\pi^{-1}(z)\right),\qquad g_{ab}(P)=\left.\frac{\partial^2F}{\partial z^a\partial z^b}\right|_{z=\pi(P)}.

座標の方向成分を u=(u^1,\ldots,u^d)\in\mathbb R^d とし、Q_t=\pi^{-1}(\pi(P)+tu) と置きます。その初速度は U=\sum_a u^a\left.\partial/\partial z^a\right|_P\in T_P\mathcal M。直線に沿った二階微分は上の行列の値を組み合わせたものです。

\left.\frac{d^2}{dt^2}D_{\rm KL}(P\Vert Q_t)\right|_{0}=\sum_{a,b=1}^d u^a g_{ab}(P)u^b=g_P(U,U).

ここでは、各確率・密度が共通の台の上で正であり、必要な和・積分と二階までの微分を交換できる滑らかなモデルを扱います。異なる接方向を識別でき、この行列が正定値になる範囲で計量が定まります。

P,Q_s\in\mathcal M実際の分布を固定し、予測に使う分布を動かす。
接空間
U,V\in T_P\mathcal M同じ出発点で速度を測る。

分布を動かして KL を作る

観測された結果に予測が小さな確率を与えたときほど、損失を大きくします。独立な観測の尤度は各観測の確率の積です。負の対数を取ると、低い尤度ほど損失が大きくなり、積だった尤度から観測ごとの損失の和が得られます。密度を使う分布でも、尤度の積を損失の和に変える手順は同じです。

実際の分布を固定し、予測をずらした場合の平均損失から、実際の分布そのもので予測した場合の平均損失を引きます。二つの損失は同じ分布で平均するので、平均の中で負の対数の差を取れます。これが KL ダイバージェンスです。

P を実際の分布として固定し、予測に使う分布を Q_s=\gamma(s) とします。q_s(x)=p_{Q_s}(x) と置くと、q_0(x)=p_P(x)、\dot q_0(x)=Up(x) です。3カテゴリの第3章と同様、予測を P から Q_s に変えたときの平均対数損失の差を取ります。

\begin{aligned}L(s)&=D_{\mathrm{KL}}(P\Vert Q_s)\\&=\mathcal I\!\left[p_P(x)\bigl[\log p_P(x)-\log q_s(x)\bigr]\right].\end{aligned}

この式の出発点を分けて書くと、実際の分布が P のときにモデル R を使う平均損失は C_P(R)=\mathcal I[p_P(-\log p_R)] です。R に Q_s と P を入れ、差を取ります。

\begin{aligned}L(s)&=C_P(Q_s)-C_P(P)\\ &=-\mathcal I[p_P\log q_s]+\mathcal I[p_P\log p_P]\\ &=\mathcal I[p_P\,\log(p_P/q_s)].\end{aligned}

この割り算は、二つの予測の対数を引いた結果です。微分で出てくる 1/p_P とは、この後の計算でつながります。

なぜ二階微分を取るか

まず、何を動かすか。 実際の分布 P は固定し、予測の分布 Q_s だけを少し動かします。s はずらすためのつまみ、L(s) は平均でどれだけ損失が増えたかです。出発点では予測が実際と一致するので L(0)=0 です。

一階微分は、グラフの傾き。 L^\prime(0) は、つまみを動かした直後に、ずらした量に比例する損失が出るかを調べます。出発点では各結果の計算で分母と重みが約分され、残るのは確率の増減を全部足した値のマイナスです。ある結果に確率を足した分は、別の結果から引かれます。足し引きが打ち消し合うので L^\prime(0)=0 です。連続分布でも、同じ理由は「密度の積分がいつも1」と書けます。

二階微分は、その傾きが変わる速さ。 底で傾きが0でも、少し動いた先で傾きが急に立ち上がることはあります。たとえば、同じ点から始まる s^2 と 4s^2 は、どちらも出発点で傾き0です。傾きは順に 2s と 8s なので、後者のほうが4倍の速さで立ち上がります。

損失の式に戻ると、s が小さい範囲で、最初に残る項は次のようになります。

L(s)\approx\textcolor{#8bc5ff}{\underbrace{\tfrac12 L^{\prime\prime}(0)}_{\text{二次の係数}}}s^2.

\tfrac12 が付くのは、s^2 を二度微分すると2になるからです。例えば L^{\prime\prime}(0)=4 なら、二次の部分は 2s^2。その方向に予測を2倍ずらすと、平均損失はおよそ4倍になります。フィッシャー計量は、この二階微分が出発点と曲線の初速度だけで決まることを利用して、初速度の長さの二乗を定めます。

コインで、傾きがゼロになるところを計算する

本当は表も裏も \tfrac12 のコインを考えます。予測では表の確率を s 増やし、裏から同じ s を引きます。s>0 なら表寄り、s<0 なら裏寄りです。|s|<\tfrac12 とし、平均を取る重みは、表も裏も実際の確率 \tfrac12 のままにします。

\begin{aligned}L(s)&=\tfrac12\log\frac{1/2}{1/2+s}+\tfrac12\log\frac{1/2}{1/2-s}\\&=-\tfrac12\log(1+2s)-\tfrac12\log(1-2s)\\&=-\tfrac12\log(1-4s^2).\end{aligned}

二行目では各分数の分子と分母を2倍し、三行目では対数の和を積にまとめました。微分は、表と裏で起きることが見えるように、二行目を使います。

\begin{aligned}L^\prime(s)&=-\frac1{1+2s}+\frac1{1-2s}\\L^\prime(0)&=\textcolor{#8bc5ff}{\underbrace{-1}_{\text{表の損失が減る}}}+\textcolor{#ffd479}{\underbrace{1}_{\text{裏の損失が増える}}}=0.\end{aligned}

表と裏の増減は出発点で同じ大きさです。ところが、すでに表寄りにずれたところでは、裏の確率が下がっています。裏をさらに予測しにくくするほうの影響が大きくなり、傾きが正になります。実際、L^\prime(s) の二つの分数を通分すると、分子は -(1-2s)+(1+2s)=4s です。

\begin{aligned}L^\prime(s)&=\frac{4s}{1-4s^2}\\L^{\prime\prime}(0)&=\lim_{s\to0}\frac{L^\prime(s)-L^\prime(0)}{s}\\&=\lim_{s\to0}\frac{4}{1-4s^2}=4.\end{aligned}

つまり、底での傾きは0でも、底からずれると傾きは 4s くらいになります。このコインでの二次近似は L(s)\approx2s^2。例えば s=0.01 と s=0.02 で実際の損失を比べます。

以下では、コインで表と裏の二項を足した計算を、観測値全体について行います。

外側の重み p_P は実際の分布なので固定です。予測の密度だけを微分すると、

\begin{aligned}L'(s)&=-\mathcal I\!\left[p_P\frac{\dot q_s}{q_s}\right],\\L'(0)&=-\mathcal I\!\left[Up\right]=0.\end{aligned}

一項ずつ見ると、最初の微分では \log p_P が定数なので消えます。残る -\log q_s の微分は -\dot q_s/q_s。この式に q_0=p_P を入れると、外側の p_P と分母が約分されます。

-p_P\left.\frac{\dot q_s}{q_s}\right|_{s=0}=-p_P\frac{Up}{p_P}=-Up.

さらに商を微分し、s=0 を代入します。

\begin{aligned}L''(s)&=\mathcal I\!\left[p_P\left(\frac{\dot q_s^2}{q_s^2}-\frac{\ddot q_s}{q_s}\right)\right],\\L''(0)&=\mathcal I\!\left[\frac{(Up)^2}{p_P}\right]-\mathcal I\!\left[\ddot q_0\right].\end{aligned}

二階微分では -\dot q_s/q_s を積 -\dot q_s(q_s^{-1}) と見ます。最初の因子から -\ddot q_s/q_s、後ろの因子から +\dot q_s^2/q_s^2 が出ます。出発点で外側の重みを掛けると、二つの分母のうち一方だけが残ります。

\begin{aligned}p_P\frac{(Up)^2}{p_P^2}&=\frac{(Up)^2}{p_P},\\p_P\frac{\ddot q_0}{p_P}&=\ddot q_0.\end{aligned}

最後の積分は、\mathcal I\!\left[q_s\right]=1 を二度微分すると0です。したがってこの二階微分は、通った道の加速度によらず、点 P と速度 U で決まります。これを g_P(U,U) とします。

ここで L(0)=0、L'(0)=0 ですから、テイラー展開では L(s)=\tfrac12s^2L''(0)+o(s^2) です。o(s^2) は、s^2 で割ると0に近づく残りの項です。したがって、同じ小さな s で別の方向に動かすと、L''(0) が大きい方向ほど二次の損失が大きくなります。

同じ点で V=\sum_a v^a\left.\frac{\partial}{\partial\theta^a}\right|_P を取ります。3カテゴリの第3章と同様、U+V の二乗から U,V それぞれの二乗を引けば、2(Up)(Vp) の項が残ります。この残りを2で割った値を内積とします。

\begin{aligned}2g_P(U,V)={}&g_P(U+V,U+V)\\&-g_P(U,U)-g_P(V,V)\\={}&\mathcal I\!\left[\frac{(Up+Vp)^2-(Up)^2-(Vp)^2}{p_P}\right]\\={}&2\mathcal I\!\left[\frac{(Up)(Vp)}{p_P}\right].\end{aligned}
\begin{aligned}g_P(U,V)&=\mathcal I\!\left[\frac{(Up)(Vp)}{p_P}\right]\\&=\mathcal I\!\left[p_P(U\log p)(V\log p)\right].\end{aligned}

P による期待値を \mathbb E_P[h]=\mathcal I\!\left[p_P h\right] と書けば、行列の成分は座標基底を代入して得られます。

\begin{aligned}g_{ab}(P)&=g_P\left(\left.\frac{\partial}{\partial\theta^a}\right|_P,\left.\frac{\partial}{\partial\theta^b}\right|_P\right)\\&=\mathbb E_P[S_aS_b],\\g_P(U,V)&=\sum_{a,b=1}^d u^a g_{ab}(P)v^b.\end{aligned}

\mathbb E_P[S_a]=\mathcal I\!\left[\partial_a p_\vartheta\right]=0 なので、行列はスコアの共分散行列です。内積の候補である g は対称で、各引数について線形です。g_P(U,U)=0 なら、離散の場合すべての結果で変化率が0です。連続の場合は、変化率の二乗を密度で割って積分した値が0です。非零の U についてこれが起きないという正則性の条件のもとで、各点で内積になります。三角形なら積分が3項の和に置き換わり、g_P(U,V)=\sum_i U(\rho_i)V(\rho_i)/P(A_i) が戻ります。

期待値の記号には、どの分布で平均するかが含まれています。例えば二つの密度変化率の積を平均する形では、

\begin{aligned}\mathbb E_P[(U\log p)(V\log p)] &=\mathcal I\!\left[p_P\frac{Up}{p_P}\frac{Vp}{p_P}\right]\\ &=\mathcal I\!\left[\frac{(Up)(Vp)}{p_P}\right]. \end{aligned}

掛けた分母は二つ、平均の重みは一つなので、分母に p_P が一つ残ります。

計量は一点を固定すると、二つの接ベクトルを受け取って実数を返します。基底の組を入力した結果を表にしたものが、フィッシャー行列です。

\begin{aligned}g_P &: T_P\mathcal M\times T_P\mathcal M\to\mathbb R,\\(U,V)&\longmapsto g_P(U,V),\\\left(\left.\frac{\partial}{\partial\theta^a}\right|_P,\left.\frac{\partial}{\partial\theta^b}\right|_P\right)&\longmapsto g_{ab}(P).\end{aligned}

座標を変えても内積は同じ

別の座標値 \xi^i を使うとき、p は合成関数 p_{\vartheta(\xi)} として表されます。連鎖律から、新しい座標でのスコアは S_i^{\mathrm{new}}=\sum_a(\partial\vartheta^a/\partial\xi^i)S_a です。これを成分の定義 g_{ij}^{\mathrm{new}}=\mathbb E_P[S_i^{\mathrm{new}}S_j^{\mathrm{new}}] に代入すると

g_{ij}^{\mathrm{new}}=\sum_{a,b}\frac{\partial\vartheta^a}{\partial\xi^i}\frac{\partial\vartheta^b}{\partial\xi^j}g_{ab}.

これは計量の座標変換則です。基底を取り替えると行列の成分が変わります。接ベクトルそのものを引数とした g_P(U,V) は、最初に得た積分で同じ値を返します。

4. 平方根写像と球面

出発点

3カテゴリの第4章では3個の確率の平方根を並べて \mathbb R^3 に移しました。一般の場合は、密度の平方根を関数のまま移します。二乗の和または積分が有限な関数の空間 L^2 では、内積を \langle h,k\rangle=\mathcal I\!\left[hk\right] とします。

\begin{aligned}F(P)&=2\sqrt{p_P}\in L^2,\\\|F(P)\|^2&=\mathcal I\!\left[4p_P\right]=4.\end{aligned}

たとえば三角形なら h は (h(A_1),h(A_2),h(A_3)) で、内積はふつうの3成分の積の和です。連続の場合、\|h-k\|^2=\int(h-k)^2\,\mathrm dx=0 となる関数は、内積で区別できないので同じ点とみなします。その約束で、L^2 はふつうのベクトルのように内積で長さと角度を測れる空間になります。

したがって像は半径2の球面上にあります。ここでは平方根写像を L^2 のノルムで微分でき、曲線に沿う差分商が次式の右辺に L^2 で収束すると仮定します。点ごとの計算では、2\sqrt{q_s(x)} を微分すると 2 と平方根の微分の 1/2 が消えます。

\begin{aligned}\mathrm dF_P(U)&=\frac{Up}{\sqrt{p_P}},\\\langle F(P),\mathrm dF_P(U)\rangle&=2\mathcal I\!\left[Up\right]=0,\\\langle\mathrm dF_P(U),\mathrm dF_P(V)\rangle&=\mathcal I\!\left[\frac{(Up)(Vp)}{p_P}\right]=g_P(U,V).\end{aligned}

式の右辺を点ごとに確かめると、q_0=p_P、\dot q_0=Up だったので、

\left.\frac{\mathrm d}{\mathrm ds}\bigl[2\sqrt{q_s(x)}\bigr]\right|_{s=0} =\left.\frac{\dot q_s(x)}{\sqrt{q_s(x)}}\right|_{s=0} =\frac{Up(x)}{\sqrt{p_P(x)}}.

U,V の像の積を取ると、分母で \sqrt{p_P}\sqrt{p_P}=p_P。全体を足すと、第3節のフィッシャー内積に戻ります。

半径と速度の内積が0なので、移した速度は球面に接しています。フィッシャー内積が保たれるので、移す前後で速度の長さも同じです。したがって速度の長さを積分して得られる曲線長も同じです。

どの大円弧がモデルの中にあるか

フィッシャー・ラオ距離 d_{\mathcal M}(P,Q) は、モデル内で両端を結ぶ曲線の長さの下限です。球面全体での短い大円弧の長さは、その候補をすべて含む球面上で測るので、モデル内の距離の下界になります。角度の余弦は \langle F(P),F(Q)\rangle/4 です。

d_{\mathcal M}(P,Q)\ \ge\ 2\arccos\!\left(\mathcal I\!\left[\sqrt{p_Pp_Q}\right]\right).

角度の余弦で分母が4になる段階を明示すると、\|F(P)\|=\|F(Q)\|=2 だからです。分子の内積では各写像の先頭の2を掛けます。

\cos\omega =\frac{\langle F(P),F(Q)\rangle}{2\cdot2} =\frac{4\mathcal I[\sqrt{p_Pp_Q}]}4 =\mathcal I[\sqrt{p_Pp_Q}].

この角度をラジアンで測った値に、球面の半径2を掛けて大円弧の長さを得ます。

6. 接続を選ぶと測地線が決まる

ベクトル場
e_a\in\mathfrak X(\mathcal M),\quad e_a|_P\in T_P\mathcal M各点で基底ベクトルを指定する場と、その一点での値。
共変微分
(\nabla_{e_a}e_b)|_P\in T_P\mathcal M場の変化率を点 P で読む。
係数
\Gamma^d_{ab}(P),\,g_{dc}(P)\in\mathbb R接ベクトルの基底成分と計量の行列成分。

3カテゴリの第6章では、三角形のどの座標基底を平行に運ぶかで、混合接続と指数接続を区別しました。一般のモデルでは、平行な基底が取れるとは限りません。各点での基底の共変微分を、内積を使って指定します。

e_a=\partial/\partial\theta^a を座標基底のベクトル場とし、\ell=\log p_\vartheta(x) と書きます。ここでは下の積が可積分で、これらの期待値が座標に滑らかに依存すると仮定します。指数接続 \nabla^{(e)}、混合接続 \nabla^{(m)} は次の規則で定義します。

\begin{aligned}g_P(\nabla^{(e)}_{e_a} e_b,e_c)&=\mathbb E_P[(\partial_a\partial_b\ell)S_c],\\g_P(\nabla^{(m)}_{e_a} e_b,e_c)&=\mathbb E_P[(\partial_a\partial_b\ell+S_aS_b)S_c].\end{aligned}

左辺では、共変微分を基底 e_c と内積に入れています。\nabla_{e_a}e_b=\sum_d\Gamma^d_{ab}e_d と置いて左辺を展開すると \sum_d\Gamma^d_{ab}g_{dc} になります。g_{dc} は正定値で逆行列を持つので、これを解けば \Gamma^d_{ab} が決まります。

具体的には、右辺の期待値を C_{ab,c} と置きます。g^{cd} を計量の逆行列の成分とすると、\sum_c g_{ec}g^{cd} は e=d のとき1、異なれば0です。

\sum_c C_{ab,c}g^{cd} =\sum_e\Gamma^e_{ab}\sum_c g_{ec}g^{cd} =\Gamma^d_{ab}.

同じ式に、指数接続または混合接続の期待値を入れます。固定した a,b に対し、c を振って求めた内積から、ベクトルの全成分を復元する計算です。

三角形で平行だった基底を確かめる

混合接続の括弧内は、密度の二階微分を密度で割った量です。\partial_b p_\vartheta=p_\vartheta S_b を \vartheta^a で微分し、積の微分を使うと

\partial_a\partial_b p_\vartheta=p_\vartheta S_aS_b+p_\vartheta\partial_a\partial_b\ell.

三角形の確率座標では3つの確率がすべて座標の一次式なので、この二階微分は0です。これにより混合接続の係数はすべて0になります。一方、対数確率比を \theta^a=\log(P(A_a)/P(A_3))\ (a=1,2) と置くと、\log P(A_i)=\theta^i-\psi(\theta) と書けます。ここで \theta^3=0、\psi=\log(1+e^{\theta^1}+e^{\theta^2}) です。二階微分 -\partial_a\partial_b\psi は事象 A_i によらないので、指数接続の右辺では期待値の外へ出せます。残る \mathbb E_P[S_c] は0です。これで三角形での二通りの平行な基底が戻ります。

一般の接続では曲線に沿った速度の基底も変わります。w^a(t)=\theta^a(c(t)) と書き、\dot c=\sum_a\dot w^a e_a を共変微分します。係数の微分と基底の共変微分を足し、各基底の係数を0にすると、測地線方程式が得られます。

\begin{aligned}\nabla_{\dot c}\dot c&=\sum_d\left(\ddot w^d+\sum_{a,b}\Gamma^d_{ab}\dot w^a\dot w^b\right)e_d,\\\nabla_{\dot c}\dot c&=0\quad\Longleftrightarrow\quad\ddot w^d+\sum_{a,b}\Gamma^d_{ab}\dot w^a\dot w^b=0.\end{aligned}

測地線方程式の二種類の項は、積の微分で分かれます。

\nabla_{\dot c}(\dot w^b e_b)=\ddot w^b e_b+\dot w^b\sum_a\dot w^a\nabla_{e_a}e_b.

これは b を一つ固定した式です。全ての b について足し、\nabla_{e_a}e_b=\sum_d\Gamma^d_{ab}e_d を入れると、上の測地線方程式になります。

フィッシャー計量との関係

計量を微分すると、g_{bc}=\mathcal I\!\left[p_\vartheta S_b S_c\right] の3つの因子それぞれから項が出ます。ここでも積分と微分を交換できると仮定します。\partial_a p_\vartheta=p_\vartheta S_a を使えば、

\begin{aligned}\partial_a g_{bc}&=\mathbb E_P[(\partial_a S_b)S_c]+\mathbb E_P[S_b(\partial_a S_c+S_aS_c)]\\&=g_P(\nabla^{(e)}_{e_a}e_b,e_c)+g_P(e_b,\nabla^{(m)}_{e_a}e_c).\end{aligned}

双対な二つの式から計量を保つ式を作るには、今の式と、添字 b,c を交換した式を足して2で割ります。左辺は g_{bc}=g_{cb} なのでそのままです。右辺は各箇所で \nabla^{(e)} と \nabla^{(m)} が一度ずつ現れます。平均を \bar\nabla=(\nabla^{(e)}+\nabla^{(m)})/2 と書けば、

\partial_a g_{bc}=g_P(\bar\nabla_{e_a}e_b,e_c)+g_P(e_b,\bar\nabla_{e_a}e_c).

この関係を、二つの接続がフィッシャー計量に関して双対であるといいます。b,c を入れ替えた式と平均すると、接続の平均 (\nabla^{(e)}+\nabla^{(m)})/2 は計量を保ちます。両接続の係数は a,b について対称なので平均も捩率ゼロです。これら二条件で一意に定まるのが計量のレヴィ＝チヴィタ接続です。第4・5節で長さから求めた経路は、弧長に比例するパラメータを取ると、この接続の測地線になります。

7. 指数型分布族

観測と分布
x\in\Omega,\quad P_\theta\in\mathcal M観測される値と、自然パラメータで指定した分布。
パラメータ・統計量
\theta\in\Theta_{\rm nat}\subseteq\mathbb R^d,\quad T:\Omega\to\mathbb R^d実数の組同士を掛け合わせ、指数の中の実数を作る。
実数を返す関数
h:\Omega\to(0,\infty),\quad\psi:\Theta_{\rm nat}\to\mathbb R観測値ごとの固定因子と、分布を正規化する項。ここでは共通の正の範囲を扱う。

三角形の確率を対数確率比で書く

三角形の分布 P について、\theta^1=\log(P(A_1)/P(A_3))、\theta^2=\log(P(A_2)/P(A_3)) と置きます。指数を取ると P(A_a)=e^{\theta^a}P(A_3)（a=1,2）。これを確率の和が1という条件に代入します。

\begin{aligned}1&=(1+e^{\theta^1}+e^{\theta^2})P(A_3),\\P(A_1)&=\frac{e^{\theta^1}}{1+e^{\theta^1}+e^{\theta^2}},\\P(A_2)&=\frac{e^{\theta^2}}{1+e^{\theta^1}+e^{\theta^2}},\\P(A_3)&=\frac{1}{1+e^{\theta^1}+e^{\theta^2}}.\end{aligned}

3式の分母が共通なので、その対数を \psi(\theta)=\log(1+e^{\theta^1}+e^{\theta^2}) と置きます。分子の指数を一つの式で書くため、観測値から作る2成分の関数 T を T(A_1)=(1,0)、T(A_2)=(0,1)、T(A_3)=(0,0) と定めます。

P(A_i)=\exp\!\bigl[\theta^1T_1(A_i)+\theta^2T_2(A_i)-\psi(\theta)\bigr].

たとえば A_1 なら、指数は \theta^1\cdot1+\theta^2\cdot0-\psi(\theta) です。指数を開けば上の分数に戻ります。

同じ形を一般のモデルで定義する

固定した関数 T_1,\dots,T_d と正の関数 h を使い、観測値 x での確率または密度が次の形になるモデルを指数型分布族と呼びます。以下の第7〜10節で、\theta は自然パラメータの座標値を表し、\theta\cdot T(x)=\sum_a\theta^aT_a(x) とします。

p_\theta(x)=h(x)\exp[\theta\cdot T(x)-\psi(\theta)].

全確率を1にするには、\theta だけで決まる因子 e^{-\psi(\theta)} を、全体の和または積分の外に出してから解きます。

\begin{aligned}1&=\mathcal I[p_\theta]=e^{-\psi(\theta)}\mathcal I[h\,e^{\theta\cdot T}],\\\psi(\theta)&=\log\mathcal I[h\,e^{\theta\cdot T}].\end{aligned}

ここで \mathcal I[\cdot] は第1節で定めた和または積分です。以下では自然パラメータの範囲を開凸集合とし、上の量が有限で、\psi の微分を和や積分の中で計算でき、フィッシャー行列が正定値だとします。

式を読む順に整理すると、まず x を選んで T_a(x) の値を求めます。それに自然座標 \theta^a を掛けて足します。その指数を取った値だけでは確率の和や密度の積分が1になるとは限らないので、全体の和または積分 e^{\psi(\theta)} で割ります。

正規分布にも同じ形が現れる

(x-\mu)^2=x^2-2\mu x+\mu^2 を密度の対数に代入し、x にかかる項、x^2 にかかる項、それ以外に分けます。

\log p_{\mu,\sigma}(x)=\frac{\mu}{\sigma^2}x-\frac1{2\sigma^2}x^2-\left(\frac{\mu^2}{2\sigma^2}+\log(\sqrt{2\pi}\,\sigma)\right).

したがって h(x)=1、T(x)=(x,x^2)、\theta=(\mu/\sigma^2,-1/(2\sigma^2)) です。丸括弧の部分が \psi(\theta) です。元の座標へは \sigma^2=-1/(2\theta^2)、\mu=\theta^1\sigma^2 で戻れます。

正規分布の例で、例えば \mu=1,\sigma=1 なら \theta=(1,-1/2) です。T(x)=(x,x^2) と内積を取ると x-x^2/2、正規化関数は 1/2+\log\sqrt{2\pi}。これを引いて指数を取ると、指数部分が x-x^2/2-1/2=-(x-1)^2/2 に戻ります。

8. 自然パラメータと期待値座標

第7節で得た \psi(\theta)=\log(1+e^{\theta^1}+e^{\theta^2}) に、対数の微分を使います。

\begin{aligned}\partial_1\psi&=\frac{e^{\theta^1}}{1+e^{\theta^1}+e^{\theta^2}}=P(A_1),\\\partial_2\psi&=\frac{e^{\theta^2}}{1+e^{\theta^1}+e^{\theta^2}}=P(A_2).\end{aligned}

左辺は自然パラメータでの微分です。右辺には、確率座標そのものが現れました。

一般のモデルでは期待値になる

Z(\theta)=\mathcal I[h\,e^{\theta\cdot T}] と置きます。\psi=\log Z なので \partial_a\psi=(\partial_a Z)/Z。指数を微分したときに T_a が出て、1/Z=e^{-\psi} を掛けると指数型分布の式が戻ります。

\begin{aligned}\eta_a:=\partial_a\psi&=\frac{\mathcal I[T_a h\,e^{\theta\cdot T}]}{Z}\\&=\mathcal I[T_a p_\theta]=\mathbb E_{P_\theta}[T_a].\end{aligned}

三角形では T_a が A_a でだけ1になるため、期待値は P(A_a) です。正規分布では T=(X,X^2) なので、\eta=(\mu,\mu^2+\sigma^2) です。\mathbb E[X^2] は分散の定義 \sigma^2=\mathbb E[X^2]-\mu^2 から求まります。

もう一度微分すると計量が出る

対数密度を微分すると、スコアは S_b=T_b-\partial_b\psi=T_b-\eta_b です。したがって \partial_b p_\theta=p_\theta(T_b-\eta_b)。この式を期待値の微分に代入します。

\begin{aligned}\partial_b\eta_a&=\mathcal I[T_a\,\partial_b p_\theta]\\&=\mathbb E_{P_\theta}[T_aT_b]-\eta_a\eta_b\\&=\mathbb E_{P_\theta}[(T_a-\eta_a)(T_b-\eta_b)]\\&=g_P\!\left(\left.\frac{\partial}{\partial\theta^a}\right|_P,\left.\frac{\partial}{\partial\theta^b}\right|_P\right).\end{aligned}

第2行から第3行で使った共分散の展開を確認します。積を開くと T_aT_b-T_a\eta_b-\eta_aT_b+\eta_a\eta_b。平均では \eta_a,\eta_b は固定なので、二つの引き算はそれぞれ -\eta_a\eta_b。最後の足し算と合わせて -\eta_a\eta_b が一つ残ります。

つまりヤコビ行列 (\partial_b\eta_a) はフィッシャー行列です。正定値で逆行列があるので、逆関数定理により \eta も局所座標になります。自然パラメータの範囲を凸としたので、離れた2点でも \eta の値が同じにはなりません。実際、2点の差を v とすると、線分に沿った v\cdot\eta の微分は v^{\mathsf T}gv>0 です。そのため \theta を \eta の関数として書けます。

異なる2点で値が異なることも式にできます。v=\theta_1-\theta_0 とし、\theta(t)=\theta_0+tv を使うと、

\begin{aligned} v\cdot[\eta(\theta_1)-\eta(\theta_0)] &=\int_0^1\frac{\mathrm d}{\mathrm dt}[v\cdot\eta(\theta(t))]\,\mathrm dt\\ &=\int_0^1v^{\mathsf T}g(\theta(t))v\,\mathrm dt>0. \end{aligned}

最初の等号は端点での差を積分にしたものです。線分が座標範囲にあるため、各点で計量が正定値であることを使えます。

三角形で同じ接ベクトルを確かめる

\partial P(A_1)/\partial\theta^1 は P(A_1)(1-P(A_1))、\partial P(A_2)/\partial\theta^1 は -P(A_1)P(A_2) です。たとえば三角形の確率が (0.20,0.30,0.50) の点では、自然座標の第1基底は

\left.\frac{\partial}{\partial\theta^1}\right|_P=0.16\left.\frac{\partial}{\partial\rho_1}\right|_P-0.06\left.\frac{\partial}{\partial\rho_2}\right|_P.

確率座標で求めたフィッシャー行列は g_{11}=7,\ g_{12}=2,\ g_{22}=16/3 でした。上の係数を両方の引数に入れると 7(0.16)^2+2\cdot2(0.16)(-0.06)+(16/3)(-0.06)^2=0.16。自然座標での \partial_1^2\psi=0.20(1-0.20)=0.16 と一致します。

どの座標が各接続で平行になるか

指数型分布では \partial_a\partial_b\log p_\theta=-\partial_a\partial_b\psi で、観測値に依存しません。第6節の指数接続の式に入れると、その定数に \mathbb E_P[S_c]=0 が掛かるので \nabla^{(e)}_{e_a}e_b=0 です。したがって e 測地線では自然座標 \theta が一次式になります。

期待値座標の基底を m^b=\partial/\partial\eta_b と書くと、連鎖律で m^b=\sum_c(\partial\theta^c/\partial\eta_b)e_c です。\partial\eta/\partial\theta=g なので、内積は g(e_a,m^b)=\delta_a^b（同じ添字で1、異なれば0）になります。この定数を e_c 方向に微分して、接続の双対性を使います。

0=e_c[g(e_a,m^b)]=g(\nabla^{(e)}_{e_c}e_a,m^b)+g(e_a,\nabla^{(m)}_{e_c}m^b).

内積が \delta_a^b になるところは、座標変換の成分を一つずつ書くと確認できます。

\begin{aligned}g(e_a,m^b) &=\sum_c g_{ac}\frac{\partial\theta^c}{\partial\eta_b}\\ &=\sum_c\frac{\partial\eta_a}{\partial\theta^c}\frac{\partial\theta^c}{\partial\eta_b} =\frac{\partial\eta_a}{\partial\eta_b}=\delta_a^b. \end{aligned}

中央は \eta から \theta へ戻し、また \eta を読む合成写像の連鎖律です。

最初の項は0なので、最後の共変微分はすべての e_a と内積が0です。したがってそのベクトル自体が0になります。e_c はどの方向も張るので、期待値座標の基底は混合接続で平行です。よって m 測地線では \eta が一次式になります。端点をつなぐ座標線分がモデルの座標範囲に収まる場合、この補間で全区間の曲線が求まります。

クリストッフェル記号が0の座標を z と書くと、基底に掛かる測地線方程式は各成分で \ddot z^a=0 です。1回積分して \dot z^a が定数、2回目で z^a(t)=z^a(0)+t\,\dot z^a。z^a(1) を入れて \dot z^a=z^a(1)-z^a(0) と決めると、座標での直線補間が出ます。

正規分布タブでは、同じ端点を結ぶ2本の接続の測地線と、計量の測地線を重ねて比べられます。

どの接続の曲率を測るか

第9節の最初に確かめたように、指数型分布族では、指数接続は自然座標で、混合接続は期待値座標で、それぞれクリストッフェル記号がすべて0です。曲率を計算する式には、これらの係数の微分と積しか現れないので、両接続の曲率は0です。

フィッシャー計量のレヴィ＝チヴィタ接続は別の規則で決まります。三角形のモデルでは計量を保つ平方根写像で半径2の球面に移せるので、この接続のガウス曲率は 1/4 です。三角形の同じ点でも、どの接続を使って曲率を計算したかで値が決まります。

D_{\rm KL}(Q\Vert P)\in[0,\infty)ここで扱う、KLが有限な組での損失差。

離れた2点のKLを式にする

P=P_\theta、Q=P_\xi とします。対数密度の差では共通の \log h が消えます。KLはその差を P で平均した量なので、

\begin{aligned}\log p_\theta-\log p_\xi&=(\theta-\xi)\cdot T-\psi(\theta)+\psi(\xi),\\D_{\rm KL}(P\Vert Q)&=(\theta-\xi)\cdot\eta(P)-\psi(\theta)+\psi(\xi)\\&=\psi(\xi)-\psi(\theta)-\eta(P)\cdot(\xi-\theta).\end{aligned}

最後の式は、\xi での \psi の値から、\theta での接平面を \xi まで伸ばした高さを引いた量です。これを \psi のブレグマンダイバージェンスと呼びます。この順番では接平面を取る点が P です。

次の一般式の例として、3カテゴリタブで確率を一つ固定し、KLを最小にする分布を求めます。

一般のモデルで等式が出る条件

第8節で \theta を \eta の関数として書けることを確認しました。\varphi(\eta)=\theta(\eta)\cdot\eta-\psi(\theta(\eta)) と定めます。微分すると、\theta の変化に掛かる \eta-\nabla\psi が0になり、\mathrm d\varphi=\theta\cdot\mathrm d\eta です。上のKLの式を書き替えると、

たとえば期待値座標の第 b 成分だけを変えると、積の微分から三項が出ます。

\begin{aligned}\frac{\partial\varphi}{\partial\eta_b}&=\theta^b+\sum_a\eta_a\frac{\partial\theta^a}{\partial\eta_b}-\sum_a\frac{\partial\psi}{\partial\theta^a}\frac{\partial\theta^a}{\partial\eta_b}\\&=\theta^b+\sum_a\left(\eta_a-\frac{\partial\psi}{\partial\theta^a}\right)\frac{\partial\theta^a}{\partial\eta_b}=\theta^b.\end{aligned}

最後は期待値座標の定義 \eta_a=\partial\psi/\partial\theta^a を使いました。

D_{\rm KL}(Q\Vert P)=\varphi(\eta(Q))-\varphi(\eta(P))-\theta(P)\cdot[\eta(Q)-\eta(P)].

\eta 座標で取りうる候補がアフィン部分空間とモデルの像の共通部分だとします。最小点 Q_* がその制約の中で相対的な内部にあるとき、制約に沿う方向では一階微分が0です。Q_* から同じ制約にある Q への差 \eta(Q)-\eta(Q_*) はその方向の一つなので、

[\theta(Q_*)-\theta(P)]\cdot[\eta(Q)-\eta(Q_*)]=0.

この一階微分を取っている曲線は、期待値座標で \eta(s)=\eta(Q_*)+s[\eta(Q)-\eta(Q_*)] です。s=0 の近くなら制約を満たします。\varphi(\eta(s)) から \theta(Q_*)\cdot\eta'(0) が、KLの線形項から -\theta(P)\cdot\eta'(0) が出るので、上の内積になります。

三つのKLを上の \varphi の式で展開し、共通項を消すと、この内積が残ります。

\begin{aligned}&D_{\rm KL}(Q\Vert P)-D_{\rm KL}(Q\Vert Q_*)-D_{\rm KL}(Q_*\Vert P)\\&\qquad=[\theta(Q_*)-\theta(P)]\cdot[\eta(Q)-\eta(Q_*)]=0.\end{aligned}

D(Q\Vert P) から引く二つのうち、D(Q\Vert Q_*) では接平面を Q_* で取り、D(Q_*\Vert P) では P で取ります。どちらの引数が接平面を決めるかをそろえると、次の整理で符号を追えます。

三つの項を展開する際、x=\eta(Q),\ y=\eta(Q_*),\ z=\eta(P) と略します。\varphi の値は +\varphi(x) と -\varphi(x) のように打ち消し合い、線形項だけ残ります。

\begin{aligned} &-\theta(P)\cdot(x-z)+\theta(Q_*)\cdot(x-y)\\ &\qquad+\theta(P)\cdot(y-z)\\ &=[\theta(Q_*)-\theta(P)]\cdot(x-y). \end{aligned}
