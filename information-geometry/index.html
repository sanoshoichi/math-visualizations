数学の可視化一覧 微分幾何学の座標基底

情報幾何学

コインの分布で座標と接ベクトルを定め、結果を3つに増やして接平面を描きます。そこで測った長さが、分布の間の最短経路や予測の損失とどう結びつくかを考えます。

1. 確率分布 Pₚ と多様体 M

コインを一回投げた結果の集合を Ω = {H, T} とします。H が表、T が裏です。各結果に正の確率を割り当てる関数を集めます。

M = {P : Ω → (0,1) | P(H) + P(T) = 1}.

各 p ∈ (0,1) に対して、Pₚ ∈ M を次で定義します。

Pₚ(H) = p, Pₚ(T) = 1 − p.

表の確率を返す写像 π を座標に取ります。表の確率を一つ決めると裏の確率も決まるので、この写像は全単射です。

π(P) = P(H), π⁻¹(p) = Pₚ.

この写像を大域座標とする一次元の滑らかな構造を M に入れます。Pₚ ∈ M が多様体上の点で、π(Pₚ) = p がその点の座標値です。

2. 分布 Pₚ での接ベクトル

p ∈ (0,1) と a ∈ ℝ を固定します。p + as ∈ (0,1) を満たす s = 0 の近くで、曲線 γ を取ります。

γ(s) = Pₚ₊ₐₛ ∈ M, γ(0) = Pₚ.

その点での接ベクトル W ∈ TₚM は、滑らかな関数 f : M → ℝ に作用して、曲線に沿った変化率を返します。

W(f) = a(f ∘ π⁻¹)′(p).

最後の等号は連鎖律です。 (f ∘ π⁻¹)′(p) は座標基底を f に作用させた値なので、

W = a (∂/∂π)|ₚ ∈ TₚM.

表の確率を返す関数 π と裏の確率を返す関数 1 − π を入れると、表の変化率と裏の変化率がそれぞれ得られます。

W(π) = a, W(1 − π) = −a.

3. 同じ分布に、もう一つの座標を入れる

表と裏の確率の差を返す写像 η を座標に取ります。

η : M → (−1,1), η(P) = P(H) − P(T).

すべての P ∈ M で確率の和が 1 なので、座標変換とその逆は

η ∘ π⁻¹(p) = 2p − 1, π ∘ η⁻¹(u) = (u + 1)/2.

たとえば、同じ分布 P₀.₂ ∈ M の座標値は、表の確率で 0.2、表と裏の確率の差では −0.6 です。

4. 同じ接ベクトルを二つの座標で表す

2 で取った曲線 γ(s) = Pₚ₊ₐₛ をそのまま使います。曲線上の分布を、二つの座標で読むと次のようになります。

π(γ(s)) = p + as, η(γ(s)) = 2(p + as) − 1.

それぞれを s で微分して s = 0 で評価すると、W(π) = a と W(η) = 2a が得られます。

W = a (∂/∂π)|ₚ = 2a (∂/∂η)|ₚ ∈ TₚM.

図の数直線は、0 と 1 がそれぞれ同じ横位置に来るように揃えています。点は分布の座標値、矢印の向きと横幅は接ベクトルの成分を表します。

● 分布 Pp → 接ベクトル W の表示

p を固定して a を変えると、点は動かず矢印が変わります。横軸の目盛りが共通なので、a ≠ 0 では下の矢印の横幅が上の二倍になります。この二倍は、座標成分 2a と a の比の大きさです。

空間と座標の定義

結果の集合を Ω₃ = {1, 2, 3} とします。各結果に正の確率を割り当てる分布を集めます。

M₃ = {P : Ω₃ → (0,1) | P(1) + P(2) + P(3) = 1}.

青い点 P ∈ M₃ を入れると、写像 pᵢ は結果 i の確率を返します。

pᵢ : M₃ → (0,1), pᵢ(P) = P(i) (i = 1, 2, 3).
p₃(P) = 1 − p₁(P) − p₂(P).

2次元表示で青く塗られた三角形の内部が、座標写像 (p₁, p₂) の像です。

(p₁, p₂)(M₃) = {(u,v) ∈ ℝ² | u > 0, v > 0, u + v < 1}.

辺や頂点では少なくとも1つの確率が0になります。図では境界の位置として描き、操作できる範囲は各確率が 0.01 以上の分布にしています。

6. 曲線の速度と座標基底

分布 P\in M_3 を (P(1),P(2),P(3))=(0.20,0.30,0.50) に固定します。結果3の確率を結果1へ移す曲線を \gamma_1、結果2へ移す曲線を \gamma_2 とします。両方に同じ実数 s を入れます。

\begin{aligned}(p_i(\gamma_1(s)))_{i=1}^3&=(0.20+s,0.30,0.50-s),\\(p_i(\gamma_2(s)))_{i=1}^3&=(0.20,0.30+s,0.50-s).\end{aligned}

s=0 では2点が P で重なります。この瞬間の速度を、それぞれ同じ接空間 T_PM_3 の矢印として描いたものが下の接平面です。

e_1=\dot\gamma_1(0)=\left.\frac{\partial}{\partial p_1}\right|_P,\qquad e_2=\dot\gamma_2(0)=\left.\frac{\partial}{\partial p_2}\right|_P.

接ベクトル W=\dot\gamma(0) に関数 p_i を渡すと、結果 i の確率の変化率が得られます。W=ae_1+be_2 と書いたとき、a,b がそのまま初めの2つの変化率になります。

W(p_i)=\left.\frac{\mathrm d}{\mathrm ds}p_i(\gamma(s))\right|_{s=0},\qquad (W(p_1),W(p_2),W(p_3))=(a,b,-a-b).

最後の成分は p_3=1-p_1-p_2 を微分して得られます。

7. 基底の長さとフィッシャー計量

同じ確率の増分でも、もとの確率が小さいほど相対変化は大きくなります。点 P で接ベクトル U,V\in T_PM_3 を取り、確率の変化率を u_i=U(p_i),\ v_i=V(p_i) と書きます。対数確率の変化率は U(\log p_i)=u_i/P(i) です。この変化率の積を分布 P で平均すると、フィッシャー計量が得られます。

g_P:T_PM_3\times T_PM_3\longrightarrow\mathbb R
g_P(U,V)=\sum_{i=1}^3P(i)\frac{u_i}{P(i)}\frac{v_i}{P(i)}=\sum_{i=1}^3\frac{u_iv_i}{P(i)}.

以下、p_i=P(i) と略記します。e_1 の3つの変化率は (1,0,-1)、e_2 では (0,1,-1) でした。したがって内積 g_{12}=g_P(e_1,e_2) に寄与するのは、どちらでも減る結果3です。

(g_{ab})=\begin{pmatrix}1/p_1+1/p_3&1/p_3\\1/p_3&1/p_2+1/p_3\end{pmatrix}.

ここでは p_2=0.30 を固定し、p_3=0.70-p_1 としています。初期値では g_{11}=7,\ g_{22}=16/3,\ g_{12}=2。座標図で横と縦だった基底のなす角 \theta を求めるには、内積を両者の長さで割ります。

\cos\theta=\frac{g_{12}}{\sqrt{g_{11}g_{22}}}.

8. 球面で見る最短経路

接ベクトルの長さが決まると、曲線に沿って速さを積分して道のりを測れます。その計算を球面上の問題に移す写像が F です。

F(P)=2\bigl(\sqrt{p_1},\sqrt{p_2},\sqrt{p_3}\bigr),\qquad \|F(P)\|^2=4.

半径2の球面のうち、3成分がすべて正の部分に分布が移ります。各成分を微分すると (\mathrm dF_P U)_i=u_i/\sqrt{p_i} なので、球面での通常の内積が前節の g_P(U,V) と一致します。

\mathrm dF_P(U)\cdot\mathrm dF_P(V)=g_P(U,V).

出発点を P=(0.20,0.30,0.50)、終点を Q=(0.78,0.02,0.20) とします。以下は分布を確率の組で表した記法です。球面上の最短経路は、球の中心と両端を通る平面で切った大円の短い弧です。

中心角を \omega とすると、半径が2なので弧の全長は次の値です。

d_{\rm FR}(P,Q)=2\omega=2\arccos\!\left(\sum_{i=1}^3\sqrt{P(i)Q(i)}\right).

9. 混合接続と指数接続

同じ P,Q の間を、今度は「どの座標を一定の速さで変えるか」で結びます。混合接続（m 接続）では、確率そのものが線形に変わります。

P_t^{(m)}(i)=(1-t)P(i)+tQ(i).

指数接続（e 接続）では、結果3を基準とする対数比 \theta^a(P)=\log(P(a)/P(3))（a=1,2）が線形に変わります。指数を取って確率の和を1に戻すと、次の曲線になります。

P_t^{(e)}(i)=\frac{P(i)^{1-t}Q(i)^t}{\sum_j P(j)^{1-t}Q(j)^t}.

ここで使う接続は、それぞれの座標でクリストッフェル記号がゼロになる接続です。その座標では測地線方程式は次の形になり、両端の座標値を直線で結べば解が得られます。

\frac{\mathrm d^2 x^a}{\mathrm dt^2}=0,\qquad x^a(t)=(1-t)x^a(0)+t x^a(1).

両端では分布が一致します。途中の t=1/2 では、混合接続は確率の算術平均、指数接続は幾何平均を正規化した分布を通ります。前節の大円弧は、フィッシャー計量のレヴィ＝チヴィタ接続に対応します。

10. KLダイバージェンスと計量の関係

データが分布 P から出るとします。結果 i をモデル Q で予測したときの対数損失を -\log Q(i) とすると、P 自身で予測した場合からの平均損失の増加がKLダイバージェンスです。自然対数を使います。

D_{\rm KL}(P\Vert Q)=\sum_i P(i)\log\frac{P(i)}{Q(i)}.

第6節の曲線 Q=\gamma_1(s) を使うと、結果2の項はゼロになります。

D(s)=0.20\log\frac{0.20}{0.20+s}+0.50\log\frac{0.50}{0.50-s}.

s=0 で値と一階微分がともにゼロです。二階微分には、第7節で求めた基底の長さの二乗が現れます。

D^{\prime\prime}(0)=\frac{1}{0.20}+\frac{1}{0.50}=g_P(e_1,e_1)=7,\qquad D(s)=\frac{7}{2}s^2+O(s^3).

スライダーを0に近づけると2つの値が近づきます。離れた2点のKLは順序にも依存し、一般に D_{\rm KL}(P\Vert Q)\ne D_{\rm KL}(Q\Vert P) です。
