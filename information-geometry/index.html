数学の可視化一覧 微分幾何学の座標基底

情報幾何学

分布をタブで選び、座標・接ベクトル・フィッシャー計量を図と式で調べます。分布に共通する定義と導出は「統計多様体の一般論」にあります。

1. 確率分布 Pᵣ と多様体 M

コインを一回投げた結果の集合を Ω = {H, T} とします。H が表、T が裏です。各結果に正の確率を割り当てる関数を集めます。

M = {P : Ω → (0,1) | P(H) + P(T) = 1}.

各 r ∈ (0,1) に対して、Pᵣ ∈ M を次で定義します。

Pᵣ(H) = r, Pᵣ(T) = 1 − r.

表の確率を返す写像 π を座標に取ります。表の確率を一つ決めると裏の確率も決まるので、この写像は全単射です。

π(P) = P(H), π⁻¹(r) = Pᵣ.

この写像を大域座標とする一次元の滑らかな構造を M に入れます。Pᵣ ∈ M が多様体上の点で、π(Pᵣ) = r がその点の座標値です。

この座標で「滑らか」の意味も決まります。分布の関数 f:M\to\mathbb R が滑らかであるとは、実数の関数 r\mapsto f(\pi^{-1}(r))=f(P_r) が開区間 (0,1) で何度でも微分できることです。次節では、分布を通る曲線に沿って、この関数を一度微分します。

2. 分布 Pᵣ での接ベクトル

r ∈ (0,1) と a ∈ ℝ を固定します。r + as ∈ (0,1) を満たす s = 0 の近くで、曲線 γ を取ります。

γ(s) = Pᵣ₊ₐₛ ∈ M, γ(0) = Pᵣ.

その点での接ベクトル W ∈ T_(Pᵣ)M は、滑らかな関数 f : M → ℝ に作用して、曲線に沿った変化率を返します。

W(f) = a(f ∘ π⁻¹)′(r).

最後の等号では、外側の関数 f\circ\pi^{-1} の導関数に、内側の r+as の導関数 a を掛けました。では、この計算のどこに接空間の基底があるのでしょうか。座標 \pi の基底は、任意の滑らかな f への作用で定義します。

\left(\left.\frac{\partial}{\partial\pi}\right|_{P_r}\right)(f):=\left.\frac{\mathrm d}{\mathrm dh}f(P_{r+h})\right|_{h=0}=(f\circ\pi^{-1})'(r).

これは表の確率を速さ1で増やすときの微分です。上で計算した W(f) は、どの f に対してもちょうどその a 倍です。接ベクトルを関数に作用する微分作用素として扱うので、すべての f で作用が一致すれば、接ベクトルとして等しいといえます。

W = a (∂/∂π)|ᵣ ∈ T_(Pᵣ)M.

この曲線は計算しやすい例です。一般の滑らかな曲線 c でも、c(0)=P_r なら座標で h(s)=\pi(c(s)) とおけます。h(0)=r、c(s)=\pi^{-1}(h(s)) なので、上と同じ連鎖律を使うと、速度の係数は a=h'(0) になります。

今の a は表の確率がパラメータ1単位あたりに変わる速さです。

表の確率を返す関数 π と裏の確率を返す関数 1 − π を入れると、表の変化率と裏の変化率がそれぞれ得られます。

\begin{aligned}W(\pi)&=\left.\frac{\mathrm d}{\mathrm ds}(r+as)\right|_{s=0}=a,\\ W(1-\pi)&=\left.\frac{\mathrm d}{\mathrm ds}(1-r-as)\right|_{s=0}=-a.\end{aligned}

3. 同じ分布に、もう一つの座標を入れる

表と裏の確率の差を返す写像 η を座標に取ります。

η : M → (−1,1), η(P) = P(H) − P(T).

すべての P ∈ M で確率の和が 1 なので、座標変換とその逆は

η ∘ π⁻¹(r) = 2r − 1, π ∘ η⁻¹(u) = (u + 1)/2.

逆変換は u=2r-1 を r について解いた式です。どちら向きの変換も滑らかなので、同じ多様体上で二つの座標を使えます。

たとえば、同じ分布 P₀.₂ ∈ M の座標値は、表の確率で 0.2、表と裏の確率の差では −0.6 です。

4. 同じ接ベクトルを二つの座標で表す

2 で取った曲線 γ(s) = Pᵣ₊ₐₛ をそのまま使います。曲線上の分布を、二つの座標で読むと次のようになります。

π(γ(s)) = r + as, η(γ(s)) = 2(r + as) − 1.

図の矢印に表示する数は、曲線に沿って座標を読んでから、出発点 s = 0 で微分した値です。下の計算にスライダーの値が入ります。

成分が2倍になると、なぜ同じベクトルと言えるのでしょうか。任意の滑らかな関数 f を取り、u=2r-1 と置きます。f(P_r) を二つの座標で書いた等式を r で微分します。

\begin{aligned}(f\circ\pi^{-1})(r)&=(f\circ\eta^{-1})(2r-1),\\(f\circ\pi^{-1})'(r)&=(f\circ\eta^{-1})'(u)\cdot 2.\end{aligned}

第2節の座標基底の定義を両辺に使うと、\left.\partial/\partial\pi\right|_{P_r}=2\left.\partial/\partial\eta\right|_{P_r} です。両辺に a を掛ければ、次の二通りの表示が得られます。

W = a (∂/∂π)|ᵣ = 2a (∂/∂η)|ᵣ ∈ T_(Pᵣ)M.

図の数直線は、0 と 1 がそれぞれ同じ横位置に来るように揃えています。点は分布の座標値、矢印の向きと横幅は接ベクトルの成分を表します。

同じ分布 Pᵣ → 上段は表の確率 π(Pᵣ)、下段は表裏の確率差 η(Pᵣ)。各段の矢印は同じ速度の座標成分です。

矢印の成分を計算する

スライダーで選んだ値を r + as に代入し、曲線 γ(s) = Pᵣ₊ₐₛ に沿った変化率を求めます。

W(π) = d/ds [π(γ(s))] at s = 0 = d/ds [0.20 + 0.15s] at s = 0 = +0.15.
W(η) = d/ds [η(γ(s))] at s = 0 = d/ds [2(0.20 + 0.15s) − 1] at s = 0 = +0.30.

5. 二項分布を三角形に重ねる

ベルヌーイ分布では試行は1回でした。同じ成功確率 p\in(0,1) で独立に n 回試行し、成功の回数 X だけを記録します。n は固定します。X=j となる並びは \binom nj 通りで、どの並びも確率 p^j(1-p)^{n-j} を持つので、分布 P_p=\mathrm{Bin}(n,p) は

P_p(X=j)=\binom nj p^j(1-p)^{n-j},\qquad j=0,\ldots,n.

n=2 なら、結果 0,1,2 を3カテゴリの A_1,A_2,A_3 にそれぞれ対応させられます。確率の組は ((1-p)^2,\,2p(1-p),\,p^2) です。三角形では、この組の最初の二つを横軸と縦軸に取ります。p を変えると図の曲線を動きます。3カテゴリで三角形全体を見る

同じ点で動ける方向を比べる

3カテゴリ側で \rho_1(P)=P(X=0)、\rho_2(P)=P(X=1) とします。二項モデルの点を三角形に入れる写像を \iota と書きます。p を速さ1で増やしたときの速度を三角形の基底で書くには、\rho_1,\rho_2 の変化率を計算します。

\begin{aligned}\frac{\mathrm d}{\mathrm dp}(1-p)^2&=-2(1-p),\\\frac{\mathrm d}{\mathrm dp}[2p(1-p)]&=2(1-2p).\end{aligned}
\begin{aligned}\mathrm d\iota_{P_p}\left(\left.\frac{\partial}{\partial p}\right|_{P_p}\right)&=-2(1-p)\left.\frac{\partial}{\partial\rho_1}\right|_{\iota(P_p)}\\&\quad+2(1-2p)\left.\frac{\partial}{\partial\rho_2}\right|_{\iota(P_p)}.\end{aligned}

二項モデルではこの1本の方向と、その実数倍が接空間を作ります。三角形のモデルでは2本の座標基底の係数を独立に選べます。

フィッシャー計量を計算する

対数確率を p で微分すると S_p(j)=j/p-(n-j)/(1-p)=(j-np)/[p(1-p)] です。成功回数は独立な0・1変数の和なので、平均は np、分散は np(1-p)。したがって

g_{pp}(P_p)=\mathbb E_{P_p}[S_p^2]=\frac{np(1-p)}{p^2(1-p)^2}=\frac{n}{p(1-p)}.

空間と座標の定義

ここまでのコインでは、表の確率を一つ決めれば分布が決まりました。ここからは、互いに排反で全体を尽くす三つの結果を扱います。

1回の試行で起きる3つの事象の集合を Ω₃ = {A₁, A₂, A₃} とします。各事象に正の確率を割り当てる分布を集めます。

M₃ = {P : Ω₃ → (0,1) | P(A_1) + P(A_2) + P(A_3) = 1}.

青い点 P ∈ M₃ は分布です。事象ごとに、分布を入れるとその事象の確率を返す関数 ρᵢ を定めます。

\rho_i:M_3\to(0,1),\qquad \rho_i(P)=P(A_i)\quad(i=1,2,3).

左の ρᵢ(P) では確率を読む関数に分布を入れ、右の P(Aᵢ) では分布に事象を入れます。返る数は同じです。図では、その数を軸に載せるために xⁱ と書きます。

x^i=\rho_i(P)=P(A_i),\quad\text{例として}\quad x^1=\rho_1(P)=P(A_1)=0.20.

(x¹, x²) で分布の位置が決まり、3つ目の値は x³ = 1 − x¹ − x² と決まります。2次元表示で塗られた三角形の内部が、座標写像 φ = (ρ₁, ρ₂) の像です。

\phi(M_3)=\{(x^1,x^2)\in\mathbb R^2\mid x^1>0,\ x^2>0,\ x^1+x^2<1\}.

この開三角形の点 (x^1,x^2) から、三つの確率が (x^1,x^2,1-x^1-x^2) の分布を作る操作が \phi^{-1} です。第1節と同じく \phi を大域座標とする滑らかな構造を入れます。こうして M_3 は二次元多様体になります。

辺や頂点では少なくとも1つの確率が0になります。図では境界の位置として描き、操作できる範囲は各確率が 0.01 以上の分布にしています。

結果が3つあると、分布を決めるのに2つの確率が必要です。スライダーの x¹, x² は、分布 P における A₁, A₂ の確率です。図で ρ₁(P) を動かすと、ρ₂(P) は固定され、確率の和が1になるように ρ₃(P) が変わります。3次元表示に切り替えると、同じ分布を3つの確率の組として読めます。

曲線の速度をどう定義するか

図の2本の矢印は、どちらも s = 0 での速度です。曲線 γⱼ : I → M₃ に対して、接ベクトル γ̇ⱼ(0) ∈ TₚM₃ の作用を、任意の滑らかな関数 f : M₃ → ℝ について次の式で定義します。

(\dot\gamma_j(0))(f):=\left.\frac{\mathrm d}{\mathrm ds}(f\circ\gamma_j)(s)\right|_{s=0}=\lim_{h\to0}\frac{f(\gamma_j(h))-f(P)}{h}.

たとえば横座標を返す関数 ρ₁ を入れます。青い曲線では横座標が 0.20 + s、金色の曲線では 0.20 です。

\begin{aligned}(\dot\gamma_1(0))(\rho_1)&=\left.\frac{\mathrm d}{\mathrm ds}\rho_1(\gamma_1(s))\right|_{s=0}\\&=\left.\frac{\mathrm d}{\mathrm ds}(0.20+s)\right|_{s=0}=1,\\[.3em](\dot\gamma_2(0))(\rho_1)&=\left.\frac{\mathrm d}{\mathrm ds}\rho_1(\gamma_2(s))\right|_{s=0}\\&=\left.\frac{\mathrm d}{\mathrm ds}(0.20)\right|_{s=0}=0.\end{aligned}

同様に縦座標を返す関数 ρ₂ を入れると、青は 0、金色は 1 です。任意の f についても、座標写像 φ = (ρ₁, ρ₂) を使って f̃ = f ∘ φ⁻¹ と書けば、連鎖律から次の式が得られます。

\begin{aligned}(\dot\gamma_1(0))(f)&=\left.\frac{\mathrm d}{\mathrm ds}\tilde f(0.20+s,0.30)\right|_{s=0}\\&=(\partial_1\tilde f)(0.20,0.30),\\[.3em](\dot\gamma_2(0))(f)&=\left.\frac{\mathrm d}{\mathrm ds}\tilde f(0.20,0.30+s)\right|_{s=0}\\&=(\partial_2\tilde f)(0.20,0.30).\end{aligned}

ここで多様体上の微分と、座標平面上で計算する偏微分の対応を書いておきます。\phi=(\rho_1,\rho_2) は分布を二つの実数に写す座標写像でした。\tilde f=f\circ\phi^{-1} はその二つの実数を引数に取ります。点 P での第 j 座標基底を、次の作用で定義します。

\left(\left.\frac{\partial}{\partial\rho_j}\right|_P\right)(f):=\frac{\partial\tilde f}{\partial x^j}\bigl(\phi(P)\bigr),\qquad j=1,2.

左辺は分布の関数に作用し、右辺ではもう一方の座標値を固定して偏微分します。直前に求めた2本の速度は任意の f に対してこの作用と一致するので、図の矢印は接空間の次の元です。

\begin{aligned}e_1&=\dot\gamma_1(0)=\left.\frac{\partial}{\partial\rho_1}\right|_P,\\e_2&=\dot\gamma_2(0)=\left.\frac{\partial}{\partial\rho_2}\right|_P.\end{aligned}

任意の曲線の速度をこの基底で書く

今度は P を通る任意の滑らかな曲線 \gamma を取り、\gamma(0)=P とします。その座標を x^j(s)=\rho_j(\gamma(s))、初速度の成分を a=(x^1)'(0),\ b=(x^2)'(0) と置きます。どんな f についても二変数の連鎖律により、

\begin{aligned}W(f)&=\left.\frac{\mathrm d}{\mathrm ds}\tilde f(x^1(s),x^2(s))\right|_{s=0}\\&=a\frac{\partial\tilde f}{\partial x^1}(\phi(P))+b\frac{\partial\tilde f}{\partial x^2}(\phi(P)).\end{aligned}

先ほど定義した基底を右辺に戻すと、接ベクトルそのものを書き下せます。

W=\dot\gamma(0)=a\left.\frac{\partial}{\partial\rho_1}\right|_P+b\left.\frac{\partial}{\partial\rho_2}\right|_P\in T_PM_3.

この式に f=\rho_1 を入れると、\tilde f(x^1,x^2)=x^1 の偏微分は順に1と0なので W(\rho_1)=a。f=\rho_2 なら順に0と1なので W(\rho_2)=b です。第3の確率についても計算できます。

W(\rho_3)=W(1-\rho_1-\rho_2)=0-a-b.

したがって (a,b) がこの基底での成分で、(a,b,-a-b) は三つの確率の変化率をすべて並べたものです。\rho_3 の変化率は初めの二つで決まります。

7. 基底の長さとフィッシャー計量

第6節では、確率の変化を接ベクトルで表しました。ここでは、その変化が予測の正確さにどれだけ影響するかを使って、接ベクトルの長さを決めます。分布 P を実際の分布として固定し、予測に使う分布だけを P から少しずらします。

予測を少しずらしたときの損失

同じ分布モデル Q で、独立な2回の試行を予測します。実際の結果が1回目は A_1、2回目は A_2 だったとします。モデルがこの並びに与えた確率は、各回に与えた確率の積 Q(A_1)Q(A_2) です。この積が大きいほど、観測された並びに高い確率を与えたことになります。

実際に観測した結果に低い確率を付けたときに大きくなり、試行ごとに足せる量を作ります。そこで、この積に負の対数を取ります。対数は積を和に変え、マイナスを付けると、観測に与えた確率が低いほど損失が大きくなります。

-\log\!\bigl[Q(A_1)Q(A_2)\bigr]=-\log Q(A_1)-\log Q(A_2).

右辺の各項が、1回分の対数損失です。たとえば実際の事象に 0.20 を割り当てた予測では約1.61、0.50 なら約0.69です。以下では自然対数を使います。

ここからは任意の P\in M_3 で考えます。第6節と同じ座標 (\rho_1,\rho_2) を使うと、方向を指定するには独立な二つの成分 u_1,u_2\in\mathbb R を選べば十分です。

U=u_1\left.\frac{\partial}{\partial\rho_1}\right|_P+u_2\left.\frac{\partial}{\partial\rho_2}\right|_P,\qquad u_3=-u_1-u_2.

第6節で確かめたように u_i=U(\rho_i) は事象 A_i の確率の変化率です。この速度をもつ具体的な曲線を一本作ります。各確率に s u_i を加えた分布を Q_s とします。

Q_s(A_i)=P(A_i)+su_i,\qquad Q_0=P.

第6節で見たように \sum_i u_i=0 なので、動かしても確率の和は1です。ここではすべての確率が正になるよう、s を0の近くに取ります。

各モデルの平均損失を計算して、差を取る

ここからは、実際の結果が分布 P に従うとします。予測には任意の分布 R を使います。たとえば A_1 が起きたときの損失は -\log R(A_1) で、それが起きる確率は P(A_1) です。同じ計算を3つの事象について足すと、R を使った1回あたりの平均損失 C_P(R) が求まります。

\begin{aligned}C_P(R)&=P(A_1)[-\log R(A_1)]\\&\quad+P(A_2)[-\log R(A_2)]\\&\quad+P(A_3)[-\log R(A_3)]\\&=-\sum_{i=1}^3 P(A_i)\log R(A_i).\end{aligned}

この式に予測モデルとして R=Q_s と R=P をそれぞれ入れます。実際の分布はどちらも P なので、外側の重み P(A_i) は共通です。予測をずらした後の平均損失から、出発点での平均損失を引いた差を L(s) とします。

\begin{aligned}L(s)&=C_P(Q_s)-C_P(P)\\&=-\sum_i P(A_i)\log Q_s(A_i)\\&\quad+\sum_i P(A_i)\log P(A_i)\\&=\sum_i P(A_i)\bigl[\log P(A_i)-\log Q_s(A_i)\bigr].\end{aligned}

各項に \log a-\log b=\log(a/b) を使い、分母の Q_s(A_i) に、先ほど決めた P(A_i)+su_i を代入します。

\begin{aligned}L(s)&=\sum_i P(A_i)\log\frac{P(A_i)}{Q_s(A_i)}\\&=\sum_i P(A_i)\log\frac{P(A_i)}{P(A_i)+su_i}.\end{aligned}

第6節の e_1 方向を例にします。出発点の確率は (0.20,0.30,0.50) で、s=0.10 のとき予測は (0.30,0.30,0.40) です。2つの平均損失を引くと、予測をずらしたことで1回あたり約0.03048 nat増えたと分かります。

\begin{aligned}C_P(P)&=-0.20\log 0.20-0.30\log 0.30\\&\quad-0.50\log 0.50\approx 1.02965,\\ C_P(Q_{0.10})&=-0.20\log 0.30-0.30\log 0.30\\&\quad-0.50\log 0.40\approx 1.06013,\\L(0.10)&\approx1.06013-1.02965=0.03048.\end{aligned}

損失を微分して、長さの二乗を求める

予測をどれだけずらしたかを表す s で微分します。まず各項の対数確率を微分すると、ここで元の確率で割る式が出てきます。

\left.\frac{\mathrm d}{\mathrm ds}\log Q_s(A_i)\right|_{s=0}=\left.\frac{u_i}{P(A_i)+su_i}\right|_{s=0}=\frac{u_i}{P(A_i)}.

右辺は、確率の変化率を元の確率に対する割合で読んだ値です。同じ u_i=0.01 でも、元の確率が 0.20 なら 0.05、0.50 なら 0.02 になります。

この微分を平均損失の式に戻します。\log P(A_i) と重み P(A_i) は s によらないので、微分するのは -\log Q_s(A_i) だけです。

L'(s)=-\sum_i P(A_i)\frac{u_i}{P(A_i)+su_i}.

s=0 を代入すると分母と重みが同じになります。その後、確率の和の条件 \sum_i u_i=0 を使います。

L'(0)=-\sum_i P(A_i)\frac{u_i}{P(A_i)}=-\sum_i u_i=0.

二階微分では (P(A_i)+su_i)^{-1} をもう一度微分します。逆数の微分でマイナスが出て、内側の式の微分から u_i がもう1つ掛かります。

L''(s)=\sum_i P(A_i)\frac{u_i^2}{(P(A_i)+su_i)^2}.
\begin{aligned}L''(0)&=\sum_i P(A_i)\left(\frac{u_i}{P(A_i)}\right)^2\\&=\sum_i\frac{u_i^2}{P(A_i)}.\end{aligned}

三つの分母は s=0 で正であり、0の十分近くでも正です。この範囲で対数は滑らかなので、以下の二次までのテイラー展開が使えます。O(s^3) は、0の近くで絶対値がある定数倍の |s|^3 以下になる残りの項を表します。

出発点の近くでは、次のようにテイラー展開できます。Q_0=P から L(0)=0、上の計算から L'(0)=0 です。

\begin{aligned}L(s)&=L(0)+sL'(0)+\tfrac12s^2L''(0)+O(s^3)\\&=\tfrac12s^2\sum_i\frac{u_i^2}{P(A_i)}+O(s^3).\end{aligned}

同じ小さな s だけ予測をずらすと、二次の項が大きい方向ほど損失が増えます。その大きさを測るため、L''(0) を接ベクトル U の長さの二乗 g_P(U,U) とします。

曲線の選び方で長さは変わるか

上では計算のために、確率が s の一次式になる曲線を一つ選びました。同じ P を通り、同じ初速度 U をもつ滑らかな曲線 R_s でも確かめます。q_i(s)=R_s(A_i) と書くと q_i(0)=P(A_i),\ q_i'(0)=u_i です。この曲線での平均損失の差を L_R(s)=C_P(R_s)-C_P(P) と置きます。

\begin{aligned}L_R'(s)&=-\sum_i P(A_i)\frac{q_i'(s)}{q_i(s)},\\L_R''(s)&=\sum_i P(A_i)\left[\frac{q_i'(s)^2}{q_i(s)^2}-\frac{q_i''(s)}{q_i(s)}\right],\\L_R''(0)&=\sum_i\frac{u_i^2}{P(A_i)}-\sum_i q_i''(0).\end{aligned}

二つ目の式では商の微分を使い、三つ目の式では出発点の確率と速度を代入しました。すべての s で \sum_i q_i(s)=1 なので、両辺を二度微分すれば \sum_i q_i''(0)=0 です。これで二階微分は点 P と接ベクトル U だけで決まると分かります。

長さの二乗から、2本の内積へ

同じ点 P で二つ目の方向を選びます。

V=v_1\left.\frac{\partial}{\partial\rho_1}\right|_P+v_2\left.\frac{\partial}{\partial\rho_2}\right|_P,\qquad v_3=-v_1-v_2.

各確率に作用させた値は V(\rho_i)=v_i です。U+V の長さの二乗には (u_i+v_i)^2=u_i^2+2u_iv_i+v_i^2 が現れます。そこから U と V それぞれの長さの二乗を引くと交差項だけが残るので、2で割ったものを内積と定めます。

\begin{aligned}g_P(U,V)&=\tfrac12\bigl[g_P(U+V,U+V)\\&\qquad-g_P(U,U)-g_P(V,V)\bigr]\\&=\tfrac12\sum_i\frac{(u_i+v_i)^2-u_i^2-v_i^2}{P(A_i)}\\&=\sum_i\frac{u_iv_i}{P(A_i)}.\end{aligned}

分母 P(A_i) はすべて正です。U\ne0 なら独立な成分の少なくとも一つが0でないため g_P(U,U)>0 です。また右辺は U,V のそれぞれに線形で、入れ替えても同じ値です。このため各接空間で内積として使えます。

この内積を、各分布 P の接空間に入れたものがフィッシャー計量です。第10節ではここで求めた平均損失の差 L(s) を、KLダイバージェンスとして図で確認できます。

基底で計量を行列にする

図では矢印に e_1,e_2 と短く記します。スライダーで分布を選び直すたびに、その点 P での基底を使います。行列の成分は、この二つの基底を順に内積へ入れた値です。

g_{ab}(P)=g_P\!\left(\left.\frac{\partial}{\partial\rho_a}\right|_P,\left.\frac{\partial}{\partial\rho_b}\right|_P\right),\qquad a,b\in\{1,2\}.

g_{ab}=g_P(e_a,e_b) の添字 a,b は、行と列に置く基底の番号です。両方を1と2で動かすと、行列全体になります。

G(P)=(g_{ab})_{a,b=1}^{2}=\begin{pmatrix}g_{11}&g_{12}\\g_{21}&g_{22}\end{pmatrix}=\begin{pmatrix}1/P(A_1)+1/P(A_3)&1/P(A_3)\\1/P(A_3)&1/P(A_2)+1/P(A_3)\end{pmatrix}.

g_{12} は1行2列の成分です。e_1 の変化率 (1,0,-1) と e_2 の変化率 (0,1,-1) を順に掛けると、A₃ の項だけが残ります。

g_{12}=\frac{1\cdot0}{P(A_1)}+\frac{0\cdot1}{P(A_2)}+\frac{(-1)(-1)}{P(A_3)}=\frac{1}{P(A_3)}.

ここでは P(A_2)=0.30 を固定し、P(A_3)=0.70-P(A_1) としています。初期値では g_{11}=7,\ g_{22}=16/3,\ g_{12}=2。座標図で横と縦だった基底のなす角 \theta を求めるには、内積を両者の長さで割ります。

\cos\theta=\frac{g_{12}}{\sqrt{g_{11}g_{22}}}.

8. 球面で見る最短経路

第7節で測ったのは、一点での速度の長さです。ここでは区間 [0,1] 上の滑らかな曲線 c を取り、その上を動きます。各時刻の確率を q_i(t)=\rho_i(c(t)) とすれば、第6節の連鎖律を各点 c(t) で使えます。

\dot c(t)=q_1'(t)\left.\frac{\partial}{\partial\rho_1}\right|_{c(t)}+q_2'(t)\left.\frac{\partial}{\partial\rho_2}\right|_{c(t)}.
\begin{aligned}\ell_g(c)&=\int_0^1\sqrt{g_{c(t)}(\dot c(t),\dot c(t))}\,\mathrm dt\\&=\int_0^1\sqrt{\sum_{i=1}^3\frac{q_i'(t)^2}{q_i(t)}}\,\mathrm dt.\end{aligned}

曲線の長さを求めるには、各点でフィッシャー計量を使って速度の長さを測り、それを積分します。同じ計算をユークリッド空間の内積でできるように、各確率 q を実数 f(q) に移すと考えます。

確率が u_i の速さで変化するなら、新しい成分の速さは連鎖律から f'(P(A_i))u_i です。この速さを二乗して足したものを、前節の \sum_i u_i^2/P(A_i) と一致させたいので、f'(q)=1/\sqrt q と取ります。積分して定数を0に選ぶと f(q)=2\sqrt q です。

F(P)=2\bigl(\sqrt{P(A_1)},\sqrt{P(A_2)},\sqrt{P(A_3)}\bigr).

3成分を二乗して足すと、確率の和が1であることから半径2が出ます。

\|F(P)\|^2=4\sum_i P(A_i)=4.

F の像は球面のうち3成分がすべて正の部分です。実際、この部分の点 y=(y_1,y_2,y_3) に対して P(A_i)=y_i^2/4 と置けば、確率の和は1で F(P)=y となります。

接ベクトル U,V の確率の変化率を u_i,v_i とします。たとえば U について、Q_s(A_i)=P(A_i)+su_i と動かすと、写像 F の第 i 成分の速度は次の値です。

(\mathrm dF_P U)_i=\left.\frac{\mathrm d}{\mathrm ds}2\sqrt{P(A_i)+su_i}\right|_{s=0}=\frac{u_i}{\sqrt{P(A_i)}}.

今の計算を基底付きで書きます。y_i を周囲の \mathbb R^3 の直交座標とすると、写した速度は

\mathrm dF_P(U)=\sum_{i=1}^3\frac{u_i}{\sqrt{P(A_i)}}\left.\frac{\partial}{\partial y_i}\right|_{F(P)}.

これが実際に球面に接することも確認できます。半径方向 F(P) との内積は \sum_i 2\sqrt{P(A_i)}\,u_i/\sqrt{P(A_i)}=2\sum_i u_i=0 です。

2本の像のユークリッド内積を取ると、分母の平方根が2つ掛かって、前節の内積に戻ります。

\mathrm dF_P(U)\cdot\mathrm dF_P(V)=\sum_i\frac{u_i}{\sqrt{P(A_i)}}\frac{v_i}{\sqrt{P(A_i)}}=g_P(U,V).

曲線の速度にこの等式を使えば、各点で速度の長さが一致します。したがって曲線に沿って積分して得られる長さも一致します。

出発点を P=(0.20,0.30,0.50)、終点を Q=(0.78,0.02,0.20) とします。以下は分布を確率の組で表した記法です。球面上の最短経路は、球の中心と両端を通る平面で切った大円の短い弧です。

球面上の2点と原点がつくる角を \omega とします。内積を両方の長さの積で割ると、その角度の余弦になります。両方とも半径2の位置にあるので、分母は4です。

\begin{aligned}\cos\omega&=\frac{F(P)\cdot F(Q)}{\|F(P)\|\|F(Q)\|}\\&=\frac{4\sum_i\sqrt{P(A_i)Q(A_i)}}4\\&=\sum_i\sqrt{P(A_i)Q(A_i)}.\end{aligned}

球面全体での最短経路に関する定理を使いました。その弧が分布に対応する部分から出ないことも確認しましょう。球面上の2点を結ぶ弦を v(t)=(1-t)F(P)+tF(Q) と置きます。0\le t\le1 では各成分が正です。それぞれの点を中心から半径2の位置まで伸ばすと

y(t)=2\frac{v(t)}{\|v(t)\|}.

球の中心と両端を含む平面の中で、弦の方向は一方の半径から他方まで小さい角の側を連続的に動きます。したがって y(t) がなぞるのは短い大円弧です。正の数を掛けても各成分は正のままなので、弧全体を F^{-1} で分布に戻せます。ここでの t は弦上の割合です。図のスライダーは弧長の割合を使います。

中心角をラジアンで測ると、弧の長さは半径と中心角の積です。したがって、球面上の短い弧の長さと等しいフィッシャー・ラオ距離は

d_{\rm FR}(P,Q)=2\omega=2\arccos\!\left(\sum_i\sqrt{P(A_i)Q(A_i)}\right).

9. 混合接続と指数接続

第8節では長さを最小にする道を求めました。ここでは同じ端点 P,Q に対して、速度を「平行に保つ」規則を二通り選びます。この規則を指定するのが接続です。まず規則を定め、それから途中の分布を計算します。

混合接続では z=(\rho_1,\rho_2) を使います。指数接続では、R\in M_3 の二つの確率比の対数 z=(\theta^1,\theta^2) を使います。

\theta^a(R)=\log\frac{R(A_a)}{R(A_3)},\qquad a=1,2.

確率がすべて正なので対数を取れます。この二つの値から分布も復元できます。R(A_a)=e^{\theta^a(R)}R(A_3) を確率の和の条件に代入すると、

R(A_3)=\frac{1}{1+e^{\theta^1(R)}+e^{\theta^2(R)}}.

どちらの接続でも、それぞれが指定した座標 z の基底を平行に運ぶと定めます。つまり、基底を各点で同じ番号の基底へ移します。曲線 c(t) に沿うベクトルをこの基底で展開すると、共変微分で変化するのは係数 b^a(t) だけです。

\begin{aligned}B(t)&=\sum_{a=1}^2 b^a(t)\left.\frac{\partial}{\partial z^a}\right|_{c(t)},\\\nabla_{\dot c}B&=\sum_{a=1}^2\frac{\mathrm db^a}{\mathrm dt}\left.\frac{\partial}{\partial z^a}\right|_{c(t)}.\end{aligned}

これが、この座標ではクリストッフェル記号がすべて0という意味です。測地線は自分の速度を平行に保つ曲線、すなわち \nabla_{\dot c}\dot c=0 を満たす曲線です。B=\dot c と置くと、係数は b^a(t)=\frac{\mathrm d}{\mathrm dt}z^a(c(t)) です。二つの基底は一次独立なので、共変微分が0となるには各係数の微分が0となることが必要十分です。

\frac{\mathrm d^2}{\mathrm dt^2}z^a(c(t))=0,\qquad a=1,2.

一度積分すると速度は定数 k^a です。もう一度積分して c(0)=P,\ c(1)=Q を使うと、z^a(c(t))=z^a(P)+tk^a と k^a=z^a(Q)-z^a(P) が得られます。つまり、

z^a(c(t))=(1-t)z^a(P)+tz^a(Q),\qquad 0\le t\le1.

二つの座標で途中の分布を求める

混合接続では z^a(R)=\rho_a(R)=R(A_a) なので、各確率は端点での確率の算術的な補間になります。第3の確率も、1から最初の二つを引けば同じ式になります。

P_t^{(m)}(A_i)=(1-t)P(A_i)+tQ(A_i).

指数接続で同じ補間を行う対象は対数確率比です。途中の分布を P_t^{(e)} と書いて、先ほど求めた式に z^a=\theta^a を代入すると、

\theta^a(P_t^{(e)})=(1-t)\theta^a(P)+t\theta^a(Q).

両辺の指数を取ります。対数の係数はべきになり、和は積になるので、求めたい分布の確率比が得られます。

\frac{P_t^{(e)}(A_a)}{P_t^{(e)}(A_3)}=\left(\frac{P(A_a)}{P(A_3)}\right)^{1-t}\left(\frac{Q(A_a)}{Q(A_3)}\right)^t.

w_i=P(A_i)^{1-t}Q(A_i)^t と置くと、右辺は w_a/w_3 です。したがって3つの確率は w_1,w_2,w_3 に比例します。確率の合計が1になるよう、各 w_i を重みの合計で割ります。

P_t^{(e)}(A_i)=\frac{P(A_i)^{1-t}Q(A_i)^t}{\sum_j P(A_j)^{1-t}Q(A_j)^t}.

スライダーで動く2点の速度も書けます。R_m=P_t^{(m)},\ R_e=P_t^{(e)} を、それぞれ時刻 t で通る分布とします。直線補間を微分した係数 k^a を、それぞれの分布での基底に掛けます。

\begin{aligned}\dot P_t^{(m)}&=\sum_{a=1}^2[Q(A_a)-P(A_a)]\left.\frac{\partial}{\partial\rho_a}\right|_{R_m},\\\dot P_t^{(e)}&=\sum_{a=1}^2[\theta^a(Q)-\theta^a(P)]\left.\frac{\partial}{\partial\theta^a}\right|_{R_e}.\end{aligned}

図は両方を確率座標で描きます。指数接続で一定なのは対数確率比の速度なので、その曲線を確率座標に戻すと図の破線のように曲がります。

両端では分布が一致します。途中の t=1/2 では、混合接続は確率の算術平均、指数接続は幾何平均を正規化した分布を通ります。前節の大円弧は、フィッシャー計量のレヴィ＝チヴィタ接続に対応します。

10. KLダイバージェンスと計量の関係

ここで第7節の問いに戻ります。実際の分布を P に固定したまま、予測だけを Q に変えたとき、平均損失の差 C_P(Q)-C_P(P) はどれだけになるでしょうか。第8・9節のように2点を結ぶ道を選ぶ必要はなく、両端の分布を指定すれば計算できます。

この差に付いた名前がKLダイバージェンスです。第7節の平均対数損失の式を使うと次のように書けます。

D_{\rm KL}(P\Vert Q)=\sum_i P(A_i)\log\frac{P(A_i)}{Q(A_i)}.

事象ごとの寄与は負にもなりますが、和は必ず0以上です。実際、x>0 に対して -\log x\ge 1-x です。差 x-1-\log x の導関数は 1-1/x で、最小値は x=1 のときの0です。x=Q(A_i)/P(A_i) を入れて両辺に P(A_i) を掛け、足し合わせると

D_{\rm KL}(P\Vert Q)\ge\sum_{i=1}^3\bigl(P(A_i)-Q(A_i)\bigr)=1-1=0.

第7節の L(s) は、ここで予測モデルを Q_s にした値です。スライダーの例では Q_s=\gamma_1(s) とし、KLの値を D(s)=D_{\rm KL}(P\Vert Q_s) と書きます。出発点の確率 (0.20,0.30,0.50) と、\gamma_1(s) での確率 (0.20+s,0.30,0.50-s) を、3項それぞれに代入します。

\begin{aligned}D(s)&=0.20\log\frac{0.20}{0.20+s}\\&\quad+0.30\log\frac{0.30}{0.30}\\&\quad+0.50\log\frac{0.50}{0.50-s}.\end{aligned}

中央の項は \log(0.30/0.30)=\log 1=0 なので、計算には両端の2項が残ります。

s=0 ではすべての確率比が1なので D(0)=0 です。残った2項を微分します。第1項の分母の変化率は +1、第3項の分母の変化率は -1 です。

\begin{aligned}D'(s)&=-\frac{0.20}{0.20+s}+\frac{0.50}{0.50-s},\\D'(0)&=-1+1=0.\end{aligned}

いま動かしている曲線は、第6節の \gamma_1 です。P=\gamma_1(0) での速度を基底付きで書くと、第2座標は固定されているので

U=\dot\gamma_1(0)=1\left.\frac{\partial}{\partial\rho_1}\right|_P+0\left.\frac{\partial}{\partial\rho_2}\right|_P.

この方向では U(\rho_1)=1,\ U(\rho_2)=0,\ U(\rho_3)=-1 でした。これを第7節の内積に代入した値と、以下の二階微分を比べます。

さらに微分すると両方の項が正になり、s=0 を代入すると第7節の g_P(e_1,e_1) が得られます。

\begin{aligned}D''(s)&=\frac{0.20}{(0.20+s)^2}+\frac{0.50}{(0.50-s)^2},\\D''(0)&=\frac{1}{0.20}+\frac{1}{0.50}=7.\end{aligned}

したがって図の破線は、テイラー展開の二次の項 \frac12D^{\prime\prime}(0)s^2=\frac72s^2 です。

スライダーを0に近づけると2つの値が近づきます。離れた2点のKLは順序にも依存し、一般に D_{\rm KL}(P\Vert Q)\ne D_{\rm KL}(Q\Vert P) です。

11. 三角形でKLを最小にする

三角形で、線分上の最小点を探す

目標を P=(0.20,0.30,0.50) とします。制約は Q(A_1)=r。残りを Q(A_2)=q,\ Q(A_3)=1-r-q と書くと、線分の内部では 0<q<1-r です。今回は動かす分布 Q をKLの第1引数に入れ、D_{\rm KL}(Q\Vert P) を最小にします。

\begin{aligned}D_{\rm KL}(Q\Vert P)&=r\log\frac r{0.20}+q\log\frac q{0.30}\\&\quad+(1-r-q)\log\frac{1-r-q}{0.50}.\end{aligned}

第1項は q に対して定数。第2項の微分は \log(q/0.30)+1、第3項の微分は -\log((1-r-q)/0.50)-1 です。足した式を0とすると、

\log\frac q{0.30}-\log\frac{1-r-q}{0.50}=0\quad\Longleftrightarrow\quad\frac q{0.30}=\frac{1-r-q}{0.50}.

二階微分は 1/q+1/(1-r-q)>0 なので、解が線分上で唯一の最小点です。上の等式は残りの確率の比を 0.30:0.50 に保つことを表します。残りの和が 1-r なので、

Q_*=(r,\,0.375(1-r),\,0.625(1-r)).

図では D_{\rm KL}(Q\Vert P) と、右辺の二つの値を表示します。たとえば初期値 r=0.45 なら Q_*=(0.45,0.20625,0.34375) です。制約を動かすつまみと、同じ制約内で候補 Q を動かすつまみを分けています。

三角形の例では、Q_*(A_2)/P(A_2)=Q_*(A_3)/P(A_3)=(1-r)/0.80 でした。この二つの対数比が等しいため、第2事象の確率を増やして第3事象の確率を同じだけ減らす方向では、一階微分が打ち消し合います。図で Q を動かしても、D_{\rm KL}(Q_*\Vert P) は同じ値のままです。

1. 正規分布の座標・計量・距離

正規分布 P_{\mu,\sigma}=\mathcal N(\mu,\sigma^2) の族を考えます。座標は平均 \mu\in\mathbb R と標準偏差 \sigma>0 です。両方を指定すると密度が決まります。

p_{\mu,\sigma}(x)=\frac{1}{\sqrt{2\pi}\,\sigma}\exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right).

基底を内積に入れる

e_\mu=\left.\frac{\partial}{\partial\mu}\right|_P は \sigma を固定し、e_\sigma=\left.\frac{\partial}{\partial\sigma}\right|_P は \mu を固定する方向です。密度の対数を取ると -\tfrac12\log(2\pi)-\log\sigma-(x-\mu)^2/(2\sigma^2) です。この式をそれぞれの座標で微分し、z=(x-\mu)/\sigma と置きます。

\begin{aligned}S_\mu(x)&=\frac{x-\mu}{\sigma^2}=\frac{z}{\sigma},\\S_\sigma(x)&=-\frac1\sigma+\frac{(x-\mu)^2}{\sigma^3}=\frac{z^2-1}{\sigma}.\end{aligned}

観測値 X が P_{\mu,\sigma} に従うとき、Z=(X-\mu)/\sigma は標準正規分布に従います。対称性から \mathbb E[Z]=\mathbb E[Z^3]=0。\mathbb E[Z^2]=1 で、標準正規密度 \varphi'(z)=-z\varphi(z) を使って部分積分すると \mathbb E[Z^4]=3\mathbb E[Z^2]=3 です。これをスコアの積に代入します。

\begin{aligned}g_P(e_\mu,e_\mu)&=\frac{\mathbb E[Z^2]}{\sigma^2}=\frac1{\sigma^2},\\g_P(e_\mu,e_\sigma)&=\frac{\mathbb E[Z^3-Z]}{\sigma^2}=0,\\g_P(e_\sigma,e_\sigma)&=\frac{\mathbb E[Z^4-2Z^2+1]}{\sigma^2}=\frac2{\sigma^2}.\end{aligned}

したがって基底の長さは 1/\sigma,\sqrt2/\sigma です。図で \sigma を上げると、密度が広がり、同時に基底の長さがどちらも短くなります。たとえば平均を0.1だけ動かすとき、密度が広いほど、そのずれによる平均対数損失の二次の増加は小さくなります。

モデルの中で長さを最小にする

曲線 c(t)=P_{\mu(t),\sigma(t)} の速度は \dot\mu(t)\left.\frac{\partial}{\partial\mu}\right|_{c(t)}+\dot\sigma(t)\left.\frac{\partial}{\partial\sigma}\right|_{c(t)} です。上の内積を使えば、

\begin{aligned}\ell_g(c)&=\int_0^1\frac{\sqrt{\dot\mu^2+2\dot\sigma^2}}{\sigma}\,\mathrm dt\\&\ge\sqrt{2}\int_0^1\frac{|\dot\sigma|}{\sigma}\,\mathrm dt\\&\ge\sqrt{2}\left|\log\frac{\sigma(1)}{\sigma(0)}\right|.\end{aligned}

第1の不等号は平方根の中から \dot\mu^2 を外したものです。第2の不等号では、絶対値を付ける前の被積分関数 \dot\sigma/\sigma が \log\sigma の微分であることを使いました。平均が同じ端点なら、\mu を固定し、\log\sigma(t)=(1-t)\log\sigma(0)+t\log\sigma(1) と置くと両方で等号が成り立ちます。これで正規分布の族の中での最短経路が一本求まりました。

球面上の距離と比べる

P=\mathcal N(0,1)、Q=\mathcal N(0,2^2) とします。直前の計算でモデル内の距離は \sqrt2\log 2 と決まりました。一方、平方根写像で移した2点の角度を計算するには、密度の幾何平均を積分します。

\begin{aligned}\sqrt{p_P(x)p_Q(x)}&=\frac{1}{2\sqrt\pi}e^{-5x^2/16},\\\int_{\mathbb R}\sqrt{p_Pp_Q}\,\mathrm dx&=\frac{1}{2\sqrt\pi}\sqrt{\frac{16\pi}{5}}=\frac2{\sqrt5}.\end{aligned}

2行目にはガウス積分 \int_{\mathbb R}e^{-ax^2}\,\mathrm dx=\sqrt{\pi/a}（a>0）を使いました。

球面の短い大円弧を正規分布だけでたどれたなら、正規分布の族でもその長さで両端を結べるはずです。この例では距離に差があるので、短い大円弧は途中で F(\mathcal M) から外れます。

\Gamma^k_{ij}=\frac12\sum_\ell g^{k\ell}(\partial_i g_{j\ell}+\partial_j g_{i\ell}-\partial_\ell g_{ij}).

1. 統計モデルを多様体として見る

確率分布の族を滑らかな多様体として扱い、ここではそのモデルを統計多様体と呼びます。点は分布です。そこにフィッシャー計量と接続を入れ、分布の変化を幾何学として調べます。

3カテゴリの第5節で扱った三角形では、点 P を選ぶと3つの確率が決まりました。今度は、観測できる値の集合を \Omega とし、その上の分布を集めます。たとえば身長を正規分布でモデル化するなら、観測値は実数で、分布を指定する座標は平均と標準偏差です。

観測値・分布・座標を区別する

観測値の種類に応じて、分布の書き方を二通り用意します。結果が有限個または数え上げられる場合、p_P(x) は結果 x の確率です。観測値が実数で密度を持つ場合、p_P(x) は密度で、区間 [a,b] に入る確率は \int_a^b p_P(x)\,\mathrm dx です。以下で同じ計算を両方に使えるよう、関数 h を観測範囲全体で足す操作を \mathcal I[h] と書きます。

\begin{aligned}\mathcal I[h]&=\sum_{x\in\Omega}h(x) &\quad&\text{（離散分布）},\\\mathcal I[h]&=\int_\Omega h(x)\,\mathrm dx &\quad&\text{（連続分布）}.\end{aligned}

たとえば3結果なら \mathcal I[p_P]=P(A_1)+P(A_2)+P(A_3)=1、実数全体の密度なら \mathcal I[p_P]=\int_{-\infty}^{\infty}p_P(x)\,\mathrm dx=1 です。本文の \mathcal I はこのどちらかを表す略記です。

d 個の実数を並べた \vartheta=(\vartheta^1,\ldots,\vartheta^d) を使って、分布の族を指定します。\Theta\subset\mathbb R^d を開集合として、

\begin{aligned}\Theta&\longrightarrow \mathcal M,\\\vartheta&\longmapsto P_\vartheta,\\\mathcal M&=\{P_\vartheta\mid\vartheta\in\Theta\}.\end{aligned}

ここでは二つの異なる \vartheta が同じ分布を表さないと仮定します。このとき逆写像 \theta:\mathcal M\to\Theta を座標に取れます。\theta^a は第 a 座標を返す関数で、\theta^a(P_\vartheta)=\vartheta^a です。この座標で \mathcal M に滑らかな構造を入れます。一つの座標で全体を覆えない場合は、座標を局所的に取り、重なりでの座標変換が滑らかだとします。

これからの計算に使う仮定

以下では、どの分布でも結果の範囲を同じ \Omega に取り、その範囲で確率または密度が正だとします。p_\vartheta(x)=p_{P_\vartheta}(x) は座標について滑らかとします。ここで扱うKLは有限とします。和や積分を微分するときは、その中に微分を入れてよい場合を扱います。有限個の結果では、各項を微分してから足せます。無限の和や積分では追加の条件がいります。たとえば、座標を少し動かしても各導関数の絶対値を一つの関数で上から抑えられ、その関数の和や積分が有限なら、交換できます。フィッシャー行列が有限かつ正定値で、座標に滑らかに依存することも仮定し、これらの条件を満たす正則なモデルを扱います。

異なる座標値が異なる分布を表すという条件は、有限のずれを区別する条件です。正定値性は、どの非零方向にも一次の密度変化があるという、各点での条件です。この意味は第3節で計算します。

2. 分布を動かして、接ベクトルを取る

滑らかな曲線 \gamma:(-\varepsilon,\varepsilon)\to\mathcal M を取り、P=\gamma(0) とします。曲線に沿う座標値を \vartheta^a(s)=\theta^a(\gamma(s))、その初速度を u^a=(\vartheta^a)'(0) と置きます。

\mathcal M 上の滑らかな関数 f を座標空間の関数に直すと、\widetilde f=f\circ\theta^{-1} です。そこで P での座標基底を次のように定義します。

\left(\left.\frac{\partial}{\partial\theta^a}\right|_P\right)(f):=\frac{\partial\widetilde f}{\partial\vartheta^a}(\theta(P)).

曲線の速度 U=\dot\gamma(0) を f に作用させ、実数の関数 s\mapsto\widetilde f(\vartheta(s)) に連鎖律を使います。

\begin{aligned}U(f)&=\left.\frac{\mathrm d}{\mathrm ds}f(\gamma(s))\right|_{0}\\&=\left.\frac{\mathrm d}{\mathrm ds}\widetilde f(\vartheta(s))\right|_0\\&=\sum_{a=1}^{d}u^a\frac{\partial\widetilde f}{\partial\vartheta^a}(\theta(P)).\end{aligned}

これは任意の f で成り立つので、接ベクトルを基底付きで書けます。

U=\sum_{a=1}^{d}u^a\left.\frac{\partial}{\partial\theta^a}\right|_P\in T_P\mathcal M.

密度や対数密度を微分する

ここからの計算では観測値 x を一つ固定します。R\mapsto p_R(x) を関数として U に渡すと、その x での密度が曲線に沿って変わる速さが得られます。これを Up(x) と略します。ここでは、座標を動かしたとき滑らかに変化する式で確率や密度を表します。

Up(x)=\sum_a u^a\frac{\partial p_\vartheta(x)}{\partial\vartheta^a}\bigg|_{\vartheta=\theta(P)}.

\mathcal I\!\left[p_{\gamma(s)}\right]=1 を s で微分すると \mathcal I\!\left[Up\right]=0 です。三角形で3つの確率の変化率を足すと0になることに対応します。

今度は R\mapsto\log p_R(x) を U に渡します。連鎖律を使うと、x での対数密度の変化率は

U\log p(x)=\frac{Up(x)}{p_P(x)}.

座標基底ごとの対数密度の変化率 S_a(x)=\partial_a\log p_\vartheta(x) をスコアと呼びます。以降、\partial_a は座標値 \vartheta^a での偏微分です。したがって U\log p(x)=\sum_a u^a S_a(x) です。

3. KLの二階微分からフィッシャー計量へ

P を実際の分布として固定し、予測に使う分布を Q_s=\gamma(s) とします。q_s(x)=p_{Q_s}(x) と置くと、q_0(x)=p_P(x)、\dot q_0(x)=Up(x) です。3カテゴリの第7節と同様、予測を P から Q_s に変えたときの平均対数損失の差を取ります。

\begin{aligned}L(s)&=D_{\mathrm{KL}}(P\Vert Q_s)\\&=\mathcal I\!\left[p_P(x)\bigl[\log p_P(x)-\log q_s(x)\bigr]\right].\end{aligned}

外側の重み p_P は実際の分布なので固定です。予測の密度だけを微分すると、

\begin{aligned}L'(s)&=-\mathcal I\!\left[p_P\frac{\dot q_s}{q_s}\right],\\L'(0)&=-\mathcal I\!\left[Up\right]=0.\end{aligned}

さらに商を微分し、s=0 を代入します。

\begin{aligned}L''(s)&=\mathcal I\!\left[p_P\left(\frac{\dot q_s^2}{q_s^2}-\frac{\ddot q_s}{q_s}\right)\right],\\L''(0)&=\mathcal I\!\left[\frac{(Up)^2}{p_P}\right]-\mathcal I\!\left[\ddot q_0\right].\end{aligned}

最後の積分は、\mathcal I\!\left[q_s\right]=1 を二度微分すると0です。したがってこの二階微分は、通った道の加速度によらず、点 P と速度 U で決まります。これを g_P(U,U) とします。

同じ点で V=\sum_a v^a\left.\frac{\partial}{\partial\theta^a}\right|_P を取ります。3カテゴリの第7節と同様、U+V の二乗から U,V それぞれの二乗を引けば、2(Up)(Vp) の項が残ります。2で割って

\begin{aligned}g_P(U,V)&=\mathcal I\!\left[\frac{(Up)(Vp)}{p_P}\right]\\&=\mathcal I\!\left[p_P(U\log p)(V\log p)\right].\end{aligned}

P による期待値を \mathbb E_P[h]=\mathcal I\!\left[p_P h\right] と書けば、行列の成分は座標基底を代入して得られます。

\begin{aligned}g_{ab}(P)&=g_P\left(\left.\frac{\partial}{\partial\theta^a}\right|_P,\left.\frac{\partial}{\partial\theta^b}\right|_P\right)\\&=\mathbb E_P[S_aS_b],\\g_P(U,V)&=\sum_{a,b=1}^d u^a g_{ab}(P)v^b.\end{aligned}

\mathbb E_P[S_a]=\mathcal I\!\left[\partial_a p_\vartheta\right]=0 なので、行列はスコアの共分散行列です。内積の候補である g は対称で、各引数について線形です。g_P(U,U)=0 なら、離散の場合すべての結果で変化率が0です。連続の場合は、変化率の二乗を密度で割って積分した値が0です。非零の U についてこれが起きないという正則性の条件のもとで、各点で内積になります。三角形なら積分が3項の和に置き換わり、g_P(U,V)=\sum_i U(\rho_i)V(\rho_i)/P(A_i) が戻ります。

座標を変えても内積は同じ

別の座標値 \xi^i を使うとき、p は合成関数 p_{\vartheta(\xi)} として表されます。連鎖律から、新しい座標でのスコアは S_i^{\mathrm{new}}=\sum_a(\partial\vartheta^a/\partial\xi^i)S_a です。これを成分の定義 g_{ij}^{\mathrm{new}}=\mathbb E_P[S_i^{\mathrm{new}}S_j^{\mathrm{new}}] に代入すると

g_{ij}^{\mathrm{new}}=\sum_{a,b}\frac{\partial\vartheta^a}{\partial\xi^i}\frac{\partial\vartheta^b}{\partial\xi^j}g_{ab}.

これは計量の座標変換則です。基底を取り替えると行列の成分が変わります。接ベクトルそのものを引数とした g_P(U,V) は、最初に得た積分で同じ値を返します。

4. 平方根写像と球面

3カテゴリの第8節では3個の確率の平方根を並べて \mathbb R^3 に移しました。一般の場合は、密度の平方根を関数のまま移します。二乗の和または積分が有限な関数の空間 L^2 では、内積を \langle h,k\rangle=\mathcal I\!\left[hk\right] とします。

\begin{aligned}F(P)&=2\sqrt{p_P}\in L^2,\\\|F(P)\|^2&=\mathcal I\!\left[4p_P\right]=4.\end{aligned}

たとえば三角形なら h は (h(A_1),h(A_2),h(A_3)) で、内積はふつうの3成分の積の和です。連続の場合、\|h-k\|^2=\int(h-k)^2\,\mathrm dx=0 となる関数は、内積で区別できないので同じ点とみなします。その約束で、L^2 はふつうのベクトルのように内積で長さと角度を測れる空間になります。

したがって像は半径2の球面上にあります。ここでは平方根写像を L^2 のノルムで微分でき、曲線に沿う差分商が次式の右辺に L^2 で収束すると仮定します。点ごとの計算では、2\sqrt{q_s(x)} を微分すると 2 と平方根の微分の 1/2 が消えます。

\begin{aligned}\mathrm dF_P(U)&=\frac{Up}{\sqrt{p_P}},\\\langle F(P),\mathrm dF_P(U)\rangle&=2\mathcal I\!\left[Up\right]=0,\\\langle\mathrm dF_P(U),\mathrm dF_P(V)\rangle&=\mathcal I\!\left[\frac{(Up)(Vp)}{p_P}\right]=g_P(U,V).\end{aligned}

中央の式は移した速度が球面に接していることを示し、最後の式は移す前後で速度の長さが同じことを示します。したがって速度の長さを積分して得られる曲線長も同じです。

どの大円弧がモデルの中にあるか

フィッシャー・ラオ距離 d_{\mathcal M}(P,Q) は、モデル内で両端を結ぶ曲線の長さの下限です。球面全体での短い大円弧の長さは、その候補をすべて含む球面上で測るので、モデル内の距離の下界になります。角度の余弦は \langle F(P),F(Q)\rangle/4 です。

d_{\mathcal M}(P,Q)\ \ge\ 2\arccos\!\left(\mathcal I\!\left[\sqrt{p_Pp_Q}\right]\right).

3結果の全分布では、正の座標を持つ球面部分がまるごと像になり、短い大円弧も像に含まれました。一般のモデルで等号を得るには、たとえば、その大円弧の各点が選んだモデルの分布に戻ることを確かめます。

6. 接続を選ぶと測地線が決まる

3カテゴリの第9節では、三角形のどの座標基底を平行に運ぶかで、混合接続と指数接続を区別しました。一般のモデルでは、平行な基底が取れるとは限りません。各点での基底の共変微分を、内積を使って指定します。

e_a=\partial/\partial\theta^a を座標基底のベクトル場とし、\ell=\log p_\vartheta(x) と書きます。ここでは下の積が可積分で、これらの期待値が座標に滑らかに依存すると仮定します。指数接続 \nabla^{(e)}、混合接続 \nabla^{(m)} は次の規則で定義します。

\begin{aligned}g_P(\nabla^{(e)}_{e_a} e_b,e_c)&=\mathbb E_P[(\partial_a\partial_b\ell)S_c],\\g_P(\nabla^{(m)}_{e_a} e_b,e_c)&=\mathbb E_P[(\partial_a\partial_b\ell+S_aS_b)S_c].\end{aligned}

右辺では、共変微分を基底 e_c と内積に入れています。\nabla_{e_a}e_b=\sum_d\Gamma^d_{ab}e_d と置いて左辺を展開すると \sum_d\Gamma^d_{ab}g_{dc} になります。g_{dc} は正定値で逆行列を持つので、これを解けば \Gamma^d_{ab} が決まります。

三角形で平行だった基底を確かめる

混合接続の括弧内は、密度の二階微分を密度で割った量です。\partial_b p_\vartheta=p_\vartheta S_b を \vartheta^a で微分し、積の微分を使うと

\partial_a\partial_b p_\vartheta=p_\vartheta S_aS_b+p_\vartheta\partial_a\partial_b\ell.

三角形の確率座標では3つの確率がすべて座標の一次式なので、この二階微分は0です。これにより混合接続の係数はすべて0になります。一方、対数確率比を \theta^a=\log(P(A_a)/P(A_3))\ (a=1,2) と置くと、\log P(A_i)=\theta^i-\psi(\theta) と書けます。ここで \theta^3=0、\psi=\log(1+e^{\theta^1}+e^{\theta^2}) です。二階微分 -\partial_a\partial_b\psi は事象 A_i によらないので、指数接続の右辺では期待値の外へ出せます。残る \mathbb E_P[S_c] は0です。これで三角形での二通りの平行な基底が戻ります。

一般の接続では曲線に沿った速度の基底も変わります。w^a(t)=\theta^a(c(t)) と書き、\dot c=\sum_a\dot w^a e_a を共変微分します。係数の微分と基底の共変微分を足し、各基底の係数を0にすると、測地線方程式が得られます。

\begin{aligned}\nabla_{\dot c}\dot c&=\sum_d\left(\ddot w^d+\sum_{a,b}\Gamma^d_{ab}\dot w^a\dot w^b\right)e_d,\\\nabla_{\dot c}\dot c&=0\quad\Longleftrightarrow\quad\ddot w^d+\sum_{a,b}\Gamma^d_{ab}\dot w^a\dot w^b=0.\end{aligned}

フィッシャー計量との関係

計量を微分すると、g_{bc}=\mathcal I\!\left[p_\vartheta S_b S_c\right] の3つの因子それぞれから項が出ます。ここでも積分と微分を交換できると仮定します。\partial_a p_\vartheta=p_\vartheta S_a を使えば、

\begin{aligned}\partial_a g_{bc}&=\mathbb E_P[(\partial_a S_b)S_c]+\mathbb E_P[S_b(\partial_a S_c+S_aS_c)]\\&=g_P(\nabla^{(e)}_{e_a}e_b,e_c)+g_P(e_b,\nabla^{(m)}_{e_a}e_c).\end{aligned}

この関係を、二つの接続がフィッシャー計量に関して双対であるといいます。b,c を入れ替えた式と平均すると、接続の平均 (\nabla^{(e)}+\nabla^{(m)})/2 は計量を保ちます。両接続の係数は a,b について対称なので平均も捩率ゼロです。これら二条件で一意に定まるのが計量のレヴィ＝チヴィタ接続です。第4・5節で長さから求めた経路は、弧長に比例するパラメータを取ると、この接続の測地線になります。

7. 指数型分布族

三角形の確率を対数確率比で書く

三角形の分布 P について、\theta^1=\log(P(A_1)/P(A_3))、\theta^2=\log(P(A_2)/P(A_3)) と置きます。指数を取ると P(A_a)=e^{\theta^a}P(A_3)（a=1,2）。これを確率の和が1という条件に代入します。

\begin{aligned}1&=(1+e^{\theta^1}+e^{\theta^2})P(A_3),\\P(A_1)&=\frac{e^{\theta^1}}{1+e^{\theta^1}+e^{\theta^2}},\\P(A_2)&=\frac{e^{\theta^2}}{1+e^{\theta^1}+e^{\theta^2}},\\P(A_3)&=\frac{1}{1+e^{\theta^1}+e^{\theta^2}}.\end{aligned}

3式の分母が共通なので、その対数を \psi(\theta)=\log(1+e^{\theta^1}+e^{\theta^2}) と置きます。分子の指数を一つの式で書くため、観測値から作る2成分の関数 T を T(A_1)=(1,0)、T(A_2)=(0,1)、T(A_3)=(0,0) と定めます。

P(A_i)=\exp\!\bigl[\theta^1T_1(A_i)+\theta^2T_2(A_i)-\psi(\theta)\bigr].

たとえば A_1 なら、指数は \theta^1\cdot1+\theta^2\cdot0-\psi(\theta) です。指数を開けば上の分数に戻ります。

同じ形を一般のモデルで定義する

固定した関数 T_1,\dots,T_d と正の関数 h を使い、観測値 x での確率または密度が次の形になるモデルを指数型分布族と呼びます。以下の第7〜10節で、\theta は自然パラメータの座標値を表し、\theta\cdot T(x)=\sum_a\theta^aT_a(x) とします。

p_\theta(x)=h(x)\exp[\theta\cdot T(x)-\psi(\theta)].

全確率を1にするには、\theta だけで決まる因子 e^{-\psi(\theta)} を、全体の和または積分の外に出してから解きます。

\begin{aligned}1&=\mathcal I[p_\theta]=e^{-\psi(\theta)}\mathcal I[h\,e^{\theta\cdot T}],\\\psi(\theta)&=\log\mathcal I[h\,e^{\theta\cdot T}].\end{aligned}

ここで \mathcal I[\cdot] は第1節で定めた和または積分です。以下では自然パラメータの範囲を開凸集合とし、上の量が有限で、\psi の微分を和や積分の中で計算でき、フィッシャー行列が正定値だとします。

正規分布にも同じ形が現れる

(x-\mu)^2=x^2-2\mu x+\mu^2 を密度の対数に代入し、x にかかる項、x^2 にかかる項、それ以外に分けます。

\log p_{\mu,\sigma}(x)=\frac{\mu}{\sigma^2}x-\frac1{2\sigma^2}x^2-\left(\frac{\mu^2}{2\sigma^2}+\log(\sqrt{2\pi}\,\sigma)\right).

したがって h(x)=1、T(x)=(x,x^2)、\theta=(\mu/\sigma^2,-1/(2\sigma^2)) です。丸括弧の部分が \psi(\theta) です。元の座標へは \sigma^2=-1/(2\theta^2)、\mu=\theta^1\sigma^2 で戻れます。

8. 自然パラメータと期待値座標

三角形で一度微分する

第7節で得た \psi(\theta)=\log(1+e^{\theta^1}+e^{\theta^2}) に、対数の微分を使います。

\begin{aligned}\partial_1\psi&=\frac{e^{\theta^1}}{1+e^{\theta^1}+e^{\theta^2}}=P(A_1),\\\partial_2\psi&=\frac{e^{\theta^2}}{1+e^{\theta^1}+e^{\theta^2}}=P(A_2).\end{aligned}

左辺は自然パラメータでの微分です。右辺には、確率座標そのものが現れました。

一般のモデルでは期待値になる

Z(\theta)=\mathcal I[h\,e^{\theta\cdot T}] と置きます。\psi=\log Z なので \partial_a\psi=(\partial_a Z)/Z。指数を微分したときに T_a が出て、1/Z=e^{-\psi} を掛けると指数型分布の式が戻ります。

\begin{aligned}\eta_a:=\partial_a\psi&=\frac{\mathcal I[T_a h\,e^{\theta\cdot T}]}{Z}\\&=\mathcal I[T_a p_\theta]=\mathbb E_{P_\theta}[T_a].\end{aligned}

三角形では T_a が A_a でだけ1になるため、期待値は P(A_a) です。正規分布では T=(X,X^2) なので、\eta=(\mu,\mu^2+\sigma^2) です。\mathbb E[X^2] は分散の定義 \sigma^2=\mathbb E[X^2]-\mu^2 から求まります。

もう一度微分すると計量が出る

対数密度を微分すると、スコアは S_b=T_b-\partial_b\psi=T_b-\eta_b です。したがって \partial_b p_\theta=p_\theta(T_b-\eta_b)。この式を期待値の微分に代入します。

\begin{aligned}\partial_b\eta_a&=\mathcal I[T_a\,\partial_b p_\theta]\\&=\mathbb E_{P_\theta}[T_aT_b]-\eta_a\eta_b\\&=\mathbb E_{P_\theta}[(T_a-\eta_a)(T_b-\eta_b)]\\&=g_P\!\left(\left.\frac{\partial}{\partial\theta^a}\right|_P,\left.\frac{\partial}{\partial\theta^b}\right|_P\right).\end{aligned}

つまりヤコビ行列 (\partial_b\eta_a) はフィッシャー行列です。正定値で逆行列があるので、逆関数定理により \eta も局所座標になります。自然パラメータの範囲を凸としたので、離れた2点でも \eta の値が同じにはなりません。実際、2点の差を v とすると、線分に沿った v\cdot\eta の微分は v^{\mathsf T}gv>0 です。そのため \theta を \eta の関数として書けます。

三角形で同じ接ベクトルを確かめる

\partial P(A_1)/\partial\theta^1 は P(A_1)(1-P(A_1))、\partial P(A_2)/\partial\theta^1 は -P(A_1)P(A_2) です。たとえば三角形の確率が (0.20,0.30,0.50) の点では、自然座標の第1基底は

\left.\frac{\partial}{\partial\theta^1}\right|_P=0.16\left.\frac{\partial}{\partial\rho_1}\right|_P-0.06\left.\frac{\partial}{\partial\rho_2}\right|_P.

確率座標で求めたフィッシャー行列は g_{11}=7,\ g_{12}=2,\ g_{22}=16/3 でした。上の係数を両方の引数に入れると 7(0.16)^2+2\cdot2(0.16)(-0.06)+(16/3)(-0.06)^2=0.16。自然座標での \partial_1^2\psi=0.20(1-0.20)=0.16 と一致します。

9. 同じ2点を結ぶ3本の測地線

どの座標が各接続で平行になるか

指数型分布では \partial_a\partial_b\log p_\theta=-\partial_a\partial_b\psi で、観測値に依存しません。第6節の指数接続の式に入れると、その定数に \mathbb E_P[S_c]=0 が掛かるので \nabla^{(e)}_{e_a}e_b=0 です。したがって e 測地線では自然座標 \theta が一次式になります。

期待値座標の基底を m^b=\partial/\partial\eta_b と書くと、連鎖律で m^b=\sum_c(\partial\theta^c/\partial\eta_b)e_c です。\partial\eta/\partial\theta=g なので、内積は g(e_a,m^b)=\delta_a^b（同じ添字で1、異なれば0）になります。この定数を e_c 方向に微分して、接続の双対性を使います。

0=e_c[g(e_a,m^b)]=g(\nabla^{(e)}_{e_c}e_a,m^b)+g(e_a,\nabla^{(m)}_{e_c}m^b).

最初の項は0なので、最後の共変微分はすべての e_a と内積が0です。したがってそのベクトル自体が0になります。e_c はどの方向も張るので、期待値座標の基底は混合接続で平行です。よって m 測地線では \eta が一次式になります。端点をつなぐ座標線分がモデルの座標範囲に収まる場合、この補間で全区間の曲線が求まります。

正規分布タブでは、同じ端点を結ぶ2本の接続の測地線と、計量の測地線を重ねて比べられます。

どの接続の曲率を測るか

第9節の最初に確かめたように、指数型分布族では、指数接続は自然座標で、混合接続は期待値座標で、それぞれクリストッフェル記号がすべて0です。曲率を計算する式には、これらの係数の微分と積しか現れないので、両接続の曲率は0です。

フィッシャー計量のレヴィ＝チヴィタ接続は別の規則で決まります。三角形のモデルでは計量を保つ平方根写像で半径2の球面に移せるので、この接続のガウス曲率は 1/4 です。三角形の同じ点でも、どの接続を使って曲率を計算したかで値が決まります。

10. KLによる射影とピタゴラスの等式

離れた2点のKLを式にする

P=P_\theta、Q=P_\xi とします。対数密度の差では共通の \log h が消えます。KLはその差を P で平均した量なので、

\begin{aligned}\log p_\theta-\log p_\xi&=(\theta-\xi)\cdot T-\psi(\theta)+\psi(\xi),\\D_{\rm KL}(P\Vert Q)&=(\theta-\xi)\cdot\eta(P)-\psi(\theta)+\psi(\xi)\\&=\psi(\xi)-\psi(\theta)-\eta(P)\cdot(\xi-\theta).\end{aligned}

最後の式は、\xi での \psi の値から、\theta での接平面を \xi まで伸ばした高さを引いた量です。これを \psi のブレグマンダイバージェンスと呼びます。この順番では接平面を取る点が P です。

次の一般式の例として、3カテゴリタブで確率を一つ固定し、KLを最小にする分布を求めます。

一般のモデルで等式が出る条件

第8節で \theta を \eta の関数として書けることを確認しました。\varphi(\eta)=\theta(\eta)\cdot\eta-\psi(\theta(\eta)) と定めます。微分すると、\theta の変化に掛かる \eta-\nabla\psi が0になり、\mathrm d\varphi=\theta\cdot\mathrm d\eta です。上のKLの式を書き替えると、

D_{\rm KL}(Q\Vert P)=\varphi(\eta(Q))-\varphi(\eta(P))-\theta(P)\cdot[\eta(Q)-\eta(P)].

\eta 座標で取りうる候補がアフィン部分空間とモデルの像の共通部分だとします。最小点 Q_* がその制約の中で相対的な内部にあるとき、制約に沿う方向では一階微分が0です。Q_* から同じ制約にある Q への差 \eta(Q)-\eta(Q_*) はその方向の一つなので、

[\theta(Q_*)-\theta(P)]\cdot[\eta(Q)-\eta(Q_*)]=0.

三つのKLを上の \varphi の式で展開し、共通項を消すと、この内積が残ります。

\begin{aligned}&D_{\rm KL}(Q\Vert P)-D_{\rm KL}(Q\Vert Q_*)-D_{\rm KL}(Q_*\Vert P)\\&\qquad=[\theta(Q_*)-\theta(P)]\cdot[\eta(Q)-\eta(Q_*)]=0.\end{aligned}
