曲面と曲率

法線断面

曲面上の点を P とする。点 P に接する単位ベクトルを一本選び、u ∈ TₚM と書く（M は選んだ曲面）。点 P で曲面に垂直な単位ベクトルを n とする。この二本を含む平面で曲面を切ると、点 P を通る交線ができる。これが法線断面である。

凡例
  • 曲面の格子
  • 切断平面
  • 選んだ接方向 u（破線矢印）
  • 切断平面と曲面の交線
  • 点 P の法線
  • 切断の基準点 P

同じ切断平面を正面から見る。右が先ほど選んだ接方向 u、上が法線 n。

凡例
  • 切断平面と曲面の交線
  • 接方向・法線方向の軸
  • 切断の基準点 P

断面に沿って測った弧長を s とし、s = 0 で P、そこから正の向きにたどる曲線を c(s) とする。単位速さでたどるので c′(0) = u。進行方向の変化 c″(0) が法線を向くか、反対を向くかを内積で読む。

法曲率 kₙ(u) = ⟨c″(0), n⟩。

接方向を一周変えたときの法曲率の最大値を k₁、最小値を k₂ と呼ぶ。この二つが主曲率である。球面・円柱の法線は内向き、鞍型の法線は上向きに取る。

点 P での曲率値
第1主曲率 k1（0°）
第2主曲率 k2（90°）
選んだ方向の法曲率 kn(θ)
ガウス曲率 K = k1 × k2
式と曲面の設定

法曲率が最大になる接方向（第1主方向）から測った角度を θ とする。その方向の法曲率は、二つの主曲率から求められる。

kn(θ) = k1 cos²θ + k2 sin²θ

点 P におけるガウス曲率は、二つの主曲率の積である。

K = k1 k2

球面では点 P から中心に向く単位法線を選ぶ。すべての方向の法曲率が等しいので、図では接平面内に 0° の基準方向を一つ決める。この直線を含む平面は、切る向きを変えても球の中心を通る。したがって、断面はどの向きでも同じ半径 1 の大円になる。

k1 = k2 = 1,　K = 1

スライダーを動かすと上の切断平面は回るが、下の断面の形と法曲率は変わらない。

円柱を周方向（0°）に切ると、断面は半径 1 の円になる。軸方向（90°）に切ると、点 P を通る断面の枝は直線になる。法線は円柱の軸に向ける。

k1 = 1,　k2 = 0,　K = 1 × 0 = 0

0° から 90° に動かすと、点 P での法曲率が 1 から 0 に下がる。円柱の側面には周方向の曲がりがあり、ガウス曲率は軸方向の主曲率が 0 なので 0 になる。

次式で定める曲面の原点を点 P とし、法線は上向きにとる。

z = (x² − y²)/2

0° では断面が上向きに、90° では下向きに曲がる。45° では二つの二乗項が等しくなり、断面は直線になる。

k1 = 1,　k2 = −1,　K = −1

45° の方向の法曲率は 0 だが、ガウス曲率は二つの主曲率の積なので −1 のままである。

表の曲率はいずれも点 P における値である。
