点 P での曲率値
第1主曲率 k1（0°）
第2主曲率 k2（90°）
選んだ方向の法曲率 kn(θ)
ガウス曲率 K = k1 × k2
式と曲面の設定

第1主方向から測った角度を θ とする。その方向の法曲率は、二つの主曲率から求められる。

kn(θ) = k1 cos²θ + k2 sin²θ

点 P におけるガウス曲率は、二つの主曲率の積である。

K = k1 k2

点 P と球の中心を結ぶ直線が法線である。この直線を含む平面は、切る向きを変えても球の中心を通る。したがって、断面はどの向きでも同じ半径 1 の大円になる。

k1 = k2 = 1,　K = 1

スライダーを動かすと上の切断平面は回るが、下の断面の形と法曲率は変わらない。

円柱を周方向（0°）に切ると、断面は半径 1 の円になる。軸方向（90°）に切ると、点 P を通る断面の枝は直線になる。法線は円柱の軸に向ける。

k1 = 1,　k2 = 0,　K = 1 × 0 = 0

0° から 90° に動かすと、点 P での法曲率が 1 から 0 に下がる。円柱の側面には周方向の曲がりがあり、ガウス曲率は軸方向の主曲率が 0 なので 0 になる。

次式で定める曲面の原点を点 P とし、法線は上向きにとる。

z = (x² − y²)/2

0° では断面が上向きに、90° では下向きに曲がる。45° では二つの二乗項が等しくなり、断面は直線になる。

k1 = 1,　k2 = −1,　K = −1

45° の方向の法曲率は 0 だが、ガウス曲率は二つの主曲率の積なので −1 のままである。

表の曲率はいずれも点 P における値である。
