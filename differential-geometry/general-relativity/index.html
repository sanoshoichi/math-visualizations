第5部 リーマン幾何学

5.1 共変微分は何を足しているか

座標基底を e_i=\partial_i とし、ベクトルを Y=Y^j e_j と書く。曲線に沿って動くと成分 Y^j と基底 e_j がともに変わる。積の微分を行い、基底の変化を \nabla_i e_j=\Gamma^k_{ij}e_k で表す。

\left(\frac{DY}{Dt}\right)^k=\underbrace{\frac{\mathrm dY^k}{\mathrm dt}}_{\text{成分の変化}}+\underbrace{\Gamma^k_{ij}\dot x^iY^j}_{\text{基底の変化}}.

単位球を三次元に埋め込み、余緯度 \theta を固定して経度 \phi=t に沿う。Y=e_\phi=(-\sin\theta\sin\phi,\sin\theta\cos\phi,0) とすると座標成分は (0,1) で一定。三次元で微分して e_\theta と単位法線 n への成分を取ると、

\frac{\mathrm dY}{\mathrm dt}=\underbrace{-\sin\theta\cos\theta\,e_\theta}_{DY/Dt}+\underbrace{-\sin^2\theta\,n}_{\text{法線成分}}.

e_\theta の係数は \Gamma^\theta_{\phi\phi}=-\sin\theta\cos\theta。ここで接平面への射影を使えるのは、球面の計量が三次元の内積から誘導されているため。一般の計量でも上の成分式で共変微分を計算できる。

他の例も 円・球面の共変微分 で試せる。

5.2 平行移動で成分が変わる理由

平行移動とは、経路に沿って DY/Dt=0 を満たすようにベクトルを運ぶこと。成分の微分と基底の変化が打ち消し合う。計量を保つ接続では \mathrm d[g(Y,Y)]/\mathrm dt=2g(DY/Dt,Y)=0 なので長さも保たれる。

平面の円に沿って、デカルト座標でずっと右向きの単位ベクトル Y=(1,0) を運ぶ。半径方向と円周方向の単位ベクトルを \hat e_r,\hat e_\phi とすると、

Y=\cos\phi\,\hat e_r-\sin\phi\,\hat e_\phi.

動く基底での二成分は変わるが、足し合わせた矢印はどの点でも右を向く。

5.3 測地線は接ベクトル自身を運ぶ

曲線 x(s) の接ベクトルを U=\mathrm dx/\mathrm ds とする。一定の速さで進みながら、接平面の中で方向を変えない条件が測地線の式になる。

\nabla_U U=0\quad\Longleftrightarrow\quad\ddot x^k+\Gamma^k_{ij}\dot x^i\dot x^j=0.

単位球の大円を x(s)=(\cos s,\sin s,0) と書くと、\ddot x=-x は法線方向だけ。従って接平面への射影はゼロ。比較として余緯度 \theta の緯線を弧長で進むと、接成分は -\cot\theta\,e_\theta になる。赤道 \theta=90^\circ でのみゼロになる（極では緯線が点に退化する）。

5.4 接続係数を一点でゼロにする

座標を変えると接続係数には変換の二階微分が入る。元の座標で点 p を原点に移し、そこでの一次微分が単位行列になる変換を選ぶ。接続がねじれを持たない場合、二次の項を次のように取ればその点で二つの項が打ち消し合う。

x'^k=x^k+\tfrac12\Gamma^k_{ij}(p)x^ix^j,\qquad\Gamma'^k_{ij}(p)=0.

例として直線上の距離座標 X を X=x+x^2/2 と書き換える。x>-1 で g_{xx}=(1+x)^2、\Gamma^x_{xx}=1/(1+x)。同じ平坦な直線でも x=0 で接続係数は 1、距離座標 X では 0 になる。曲率のある空間でも一点で接続を消せるが、その近くの曲率は残る。

5.5 テンソルでは添字ごとに補正する

ベクトルと共変ベクトルの縮約 \omega_iV^i はスカラー。その微分に接続の項が残らないよう、下付き添字には上付き添字と逆の符号で接続を入れる。混合テンソル A^i{}_j なら、

\nabla_k A^i{}_j=\partial_k A^i{}_j+\Gamma^i_{k\ell} A^\ell{}_j-\Gamma^\ell_{kj} A^i{}_\ell.

計量に適合する接続では \nabla g=0。極座標で g_{\phi\phi}=r^2 を r 方向に微分して確かめる。下付きの \phi が二つあり、それぞれから -(1/r)r^2 が出る。

\nabla_r g_{\phi\phi}=2r-r-r=0.

5.6 閉じた経路で平行移動を比べる

北極 N から経度 0 の子午線で赤道 A へ下り、赤道を東へ角 \alpha だけ進んで B に着き、子午線で N に戻る。各辺は大円の一部。緑の矢印は出発時に N から A へ向き、金の矢印は同じベクトルが一周した後の向き。比較するのはどちらも北極の接平面。

\text{回転角の大きさ}=\int_{\triangle NAB} K\,\mathrm dA=\alpha\quad(\text{ラジアン}).

単位球では K=1。赤道と二つの子午線で囲む部分の面積は \alpha なので、経度差がそのまま回転角の大きさになる。一般の微小ループでは曲率作用素が面積あたりの変化を与える。ここで [X,Y] はベクトル場の Lie 括弧。

R(X,Y)Z=\nabla_X\nabla_Y Z-\nabla_Y\nabla_X Z-\nabla_{[X,Y]}Z.

面の曲率は 球面・円柱・鞍型の断面図 でも比較できる。

5.7 Ricci は同じ方向を含む断面曲率の和

リーマン曲率の添字を縮約すると R_{ij}=R^k{}_{ikj}。リーマン計量の正規直交基底 (v,e_2,\ldots,e_n) で v が単位ベクトルなら、\operatorname{Ric}(v,v) は v を含む直交断面の曲率の和になる。

\operatorname{Ric}(v,v)=\sum_{a=2}^n K(v,e_a),\qquad R=\sum_{a=1}^n\operatorname{Ric}(e_a,e_a).

具体例は球面と直線を掛け合わせた三次元空間 S^2(a)\times\mathbb R。球面内の断面曲率は 1/a^2。直線方向を含む二つの座標断面は 0。球面に沿う二方向では Ricci がそれぞれ 1/a^2、直線方向では 0、スカラー曲率は 2/a^2 になる。

5.8 ビアンキの恒等式と発散の消える組

第二ビアンキ恒等式は、曲率を三つの方向で微分したときの循環和がゼロになることを述べる。\Gamma(p)=0 の座標ではその点で共変微分が偏微分になり、曲率の二次項を微分したものも消える。残る二階微分は順序を入れ替えると対で打ち消し合う。

\nabla_\lambda R^\rho{}_{\sigma\mu\nu}+\nabla_\mu R^\rho{}_{\sigma\nu\lambda}+\nabla_\nu R^\rho{}_{\sigma\lambda\mu}=0.

これを二回縮約し \nabla g=0 を使うと \nabla^\mu R_{\mu\nu}=\tfrac12\partial_\nu R。従って G_{\mu\nu}=R_{\mu\nu}-\tfrac12Rg_{\mu\nu} は \nabla^\mu G_{\mu\nu}=0 を満たす。係数 1/2 は二つの発散を打ち消す。

5.9 低速・弱い重力で Newton の運動に戻る

静的な弱い重力場で、時間成分を g_{00}\simeq-(1+2\Phi/c^2) と置く。g_{0i} を無視し、空間の逆計量を \delta^{ij} で近似する。計量に時間依存がないため、\Gamma^i_{00} には空間微分だけが残る。

\Gamma^i_{00}\simeq-\tfrac12\delta^{ij}\partial_j g_{00}=\frac{\partial_i\Phi}{c^2}.

低速なら四元速度の時間成分は U^0\simeq c で、空間成分を含む項は小さい。測地線の式に残る -c^2\Gamma^i_{00} が \mathrm d^2 x^i/\mathrm dt^2\simeq-\partial_i\Phi になる。球対称な天体の外なら \Phi=-GM/r なので加速度は内向き。

5.10 Newton の極限で結合定数を決める

場の方程式の候補を G_{\mu\nu}=\kappa T_{\mu\nu} とする。まず宇宙定数をゼロとし、4次元でトレースを取ると -R=\kappa T。元の式に戻して、

R_{\mu\nu}=\kappa\bigl(T_{\mu\nu}-\tfrac12g_{\mu\nu}T\bigr).

弱場・低速・低圧では T_{00}\simeq\rho c^2、T\simeq-\rho c^2、g_{00}\simeq-1 なので右辺の 00 成分は \kappa\rho c^2/2。左辺では R_{00}\simeq\partial_i\Gamma^i_{00}=\nabla^2\Phi/c^2。Newton の Poisson 方程式 \nabla^2\Phi=4\pi G\rho と一致させると \kappa=8\pi G/c^4 が得られる。

\Lambda g_{\mu\nu} も共変発散がゼロなので、宇宙定数を含めた式も組み立てられる。この比較で決めたのは物質項に掛かる係数。
