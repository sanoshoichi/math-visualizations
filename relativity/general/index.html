一般相対性理論

測地線

物体を静かに手放すと、どちらへ動き始めるか。一般の測地線方程式を書いてから、時間 t と位置 x だけの時空で計算する。

1. 一般の測地線方程式

時空の曲線を x^\mu(\lambda) と書く。\lambda は曲線上の点を順に指定するアフィンパラメータで、自由落下する質量のある物体なら固有時 \tau を使える。ドットは \lambda による微分を表す。

2. 二次元時空では、時刻と位置の二本

座標を (t,x) にすると、\mu は t と x のどちらか。足し合わせる組は (t,t),(t,x),(x,t),(x,x) の四つになる。\Gamma^\mu_{tx}=\Gamma^\mu_{xt} なので、真ん中の二項をまとめる。

時刻 t の方程式と、位置 x の方程式

たとえば \lambda=\tau を選ぶと、未知なのは t(\tau) と x(\tau)。物体の時計が \tau を示すとき、時空図のどの点 (t,x) にいるかを二本の式で求める。

3. ある位置で静かに手放す

この例では、時間に依存しない次の計量を与える。N(x)>0 は、位置 x に固定した時計が座標時刻の1秒あたりに刻む秒数。N' は x による微分を表す。

ds² = −N(x)² c² dt² + dx²

4. 時空図で自由落下を読む

ここでは N(x)=\sqrt{1+(x/L)^2} とする。L は長さの基準。図の下端で静かに手放し、時刻とともに上へたどる。縦軸は ct/L、横軸は x/L。スライダーで初期位置を変えると、落下の世界線と手放した瞬間の値が更新される。

手放した瞬間の位置の二階微分は −0.48 c²/L。

二つの線は手放した瞬間に同じ点・同じ向きから始まる。自由落下の線はその後、中央へ曲がる。x_0=0 にすると N'(0)=0 なので、二つの線が重なる。

図の軌道を計算する

時間の式は d(N^2\dot t)/d\tau=0 と書ける。初期値を入れると N^2\dot t=N(x_0)。これを空間の式に代入し、x(0)=x_0,\ \dot x(0)=0 から数値積分する。図の縦座標 t(\tau) は、同時に時間の式から求める。
