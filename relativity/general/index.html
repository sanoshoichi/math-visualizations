一般相対性理論

測地線

一般の測地線方程式から始め、時間1次元・空間1次元では、時刻と位置の二本の式がどう出てくるかをたどる。

1. 一般の測地線方程式

時空の曲線を x^\mu(\lambda) と書く。\lambda は曲線上の点を順に指定するアフィンパラメータで、自由落下する質量のある物体なら固有時 \tau を使える。ドットは \lambda による微分を表す。

座標の二階微分 ＋ 接続による補正 ＝ 0

\mu は「どの座標の式か」を指定する。一方、\alpha,\beta は速度のどの二成分を掛けるかを表し、全ての組について足す。\Gamma^\mu_{\alpha\beta} はその積に掛けるクリストッフェル記号。計量 g_{\mu\nu} とその逆行列 g^{\mu\nu} から、次の式で求める。

2. 二次元時空では、時刻と位置の二本

座標を (t,x) にすると、\mu は t と x のどちらか。足し合わせる組は (t,t),(t,x),(x,t),(x,x) の四つになる。\Gamma^\mu_{tx}=\Gamma^\mu_{xt} なので、真ん中の二項をまとめる。

時刻 t の方程式と、位置 x の方程式

たとえば \lambda=\tau を選ぶと、未知なのは t(\tau) と x(\tau)。物体の時計が \tau を示すとき、時空図のどの点 (t,x) にいるかを二本の式で求める。

3. ミンコフスキー計量を選ぶ

時間1次元・空間1次元の平坦な時空を、慣性座標 (t,x) で表す。ある点での接ベクトル V の成分を (u,w) とすると、計量が定める二次形式は

g(V,V) = −c²u² + w²

c は光速。時間を T = ct で表すと、時間成分も長さの単位になる。(T,x) の順での計量行列を η = diag(−1,1) と書く。

4. 測地線から慣性運動を求める

(t,x) での計量成分はどの点でも同じ。したがって計量成分の偏微分はすべてゼロになり、それを使うクリストッフェル記号もすべてゼロになる。第2節の二本の式に代入すると、

t と x の固有時による二階微分はゼロ

初期の値を t₀, x₀, ṫ₀, ẋ₀ とし、固有時の原点をそこで合わせる。二回積分すると、

t(τ) = t₀ + ṫ₀τ, x(τ) = x₀ + ẋ₀τ

未来向きの物体では ṫ₀ > 0。最初の式で τ を消去すると、

x(t) = x₀ + (ẋ₀/ṫ₀)(t − t₀)

座標時刻で測った速度 dx/dt = ẋ₀/ṫ₀ が一定なので、自由粒子は等速直線運動をする。光の進む方向では接ベクトルの二次形式がゼロになる。そこで −c²u² + w² = 0 を解けば、w/u = ±c。光速の大きさは c となる。

5. 計量を保つ座標変換からブーストを求める

慣性系 S′ が S に対して x 方向に符号付き速度 v で動く。原点がすれ違う時刻を両系でゼロにし、未来と空間軸の正の向きをそろえる。β = v/c とおく。慣性座標間の変換は、原点をそろえれば線形になる。これを行列 Λ で表す。

(T′, x′) は Λ による成分変換。Λ は η を保存する。

ΛᵀηΛ = η は、変換した成分で計算しても、もとの成分で計算しても、二次形式が同じ値になるという条件。S′ の原点は S では x = βT を進む。そこで x′ = 0 となるように、行列の二行目を (−kβ,k) と置く。k は正の係数とする。

一行目を (p,q) と置く。計量を保つ条件は、同値な ΛηΛᵀ = η を使うと、行ごとに読める。

二行目の自己内積は1、二行の内積は0、一行目の自己内積は−1。

最初の式から k = γ。次の式から q = −βp。最後の式に入れ、未来向きを保つよう p > 0 を選べば p = γ になる。したがって S から S′ へのローレンツ・ブーストは

Λ = γ × 行列 (1, −β; −β, 1)
