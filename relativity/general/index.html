一般相対性理論

測地線

一般の測地線方程式から始め、時間1次元・空間1次元では、時刻と位置の二本の式がどう出てくるかをたどる。

1. 一般の測地線方程式

時空の曲線を x^\mu(\lambda) と書く。\lambda は曲線上の点を順に指定するアフィンパラメータで、自由落下する質量のある物体なら固有時 \tau を使える。ドットは \lambda による微分を表す。

座標の二階微分 ＋ 接続による補正 ＝ 0

自由落下では、世界線の速度ベクトル W を世界線に沿って共変微分した結果がゼロになる。積の微分則を使うと、上の式の第一項は速度の係数を微分したもの、第二項は座標基底を共変微分したものから出る。クリストッフェル記号は、各点 p でこの基底の共変微分を表す係数。

座標基底の共変微分を、同じ点の座標基底で展開する。

2. 二次元時空では、時刻と位置の二本

座標を (t,x) にすると、\mu は t と x のどちらか。足し合わせる組は (t,t),(t,x),(x,t),(x,x) の四つになる。\Gamma^\mu_{tx}=\Gamma^\mu_{xt} なので、真ん中の二項をまとめる。

時刻 t の方程式と、位置 x の方程式

たとえば \lambda=\tau を選ぶと、未知なのは t(\tau) と x(\tau)。物体の時計が \tau を示すとき、時空図のどの点 (t,x) にいるかを二本の式で求める。

3. 接ベクトルをミンコフスキー計量に入れる

同じ点にいる二人と、二本の接ベクトル

地上に立つ人と、右へ v=3\,\mathrm{m/s} で進む人が、地上の時刻 5\,\mathrm{s}、位置 10\,\mathrm m ですれ違う。その出来事を p とすると、t(p)=5\,\mathrm s、x(p)=10\,\mathrm m。この二つの数は、時空上の点 p の座標。

すれ違いからの地上時刻の差を h とする。地上に立つ人の世界線を \gamma_U、右へ進む人の世界線を \gamma_V と書く。時刻はどちらも t(\gamma_U(h))=t(\gamma_V(h))=5\,\mathrm s+h。位置は x(\gamma_U(h))=10\,\mathrm m、x(\gamma_V(h))=10\,\mathrm m+vh。h=0 では二人とも p を通る。

点 p の近くの任意の滑らかな関数 f を取り、世界線に沿って読んだ値を h で微分する。h=0 でのこの操作が、点 p での接ベクトルになる。

\begin{aligned} U(f)&=\left.\frac{d}{dh}(f\circ\gamma_U)(h)\right|_{h=0},\\ V(f)&=\left.\frac{d}{dh}(f\circ\gamma_V)(h)\right|_{h=0}. \end{aligned}

座標基底 \left.\dfrac{\partial}{\partial t}\right|_p は、x を固定して f を t で偏微分し、点 p で評価する操作。\left.\dfrac{\partial}{\partial x}\right|_p は、t を固定して f を x で偏微分し、点 p で評価する操作。進む人の世界線に沿っては t と x がともに変わるので、連鎖律を使う。

\begin{aligned} V(f) &=\left.\frac{d(t\circ\gamma_V)}{dh}\right|_{h=0} \left.\frac{\partial f}{\partial t}\right|_p\\ &\quad+\left.\frac{d(x\circ\gamma_V)}{dh}\right|_{h=0} \left.\frac{\partial f}{\partial x}\right|_p\\ &=\left.\frac{\partial f}{\partial t}\right|_p +v\left.\frac{\partial f}{\partial x}\right|_p. \end{aligned}

地上に立つ人では位置の微分がゼロ。これらの関係はどの f にも成り立つので、微分する操作そのものについて次の等式が成り立つ。

\begin{aligned} U&=\left.\frac{\partial}{\partial t}\right|_p,\\ V&=\left.\frac{\partial}{\partial t}\right|_p +v\left.\frac{\partial}{\partial x}\right|_p. \end{aligned}

二人は同じ点 p を通る。それぞれの世界線をそこで微分すると、同じ接空間 T_pM に属する二本の異なる接ベクトルが得られる。

計量の二つの引数に何を入れるか

計量 g_p:T_pM\times T_pM\to\mathbb R は、同じ点の接ベクトルを二本受け取り、実数を返す対称な双線形形式。p が計量を評価する点を指定し、括弧の中がその点で測る接ベクトルを指定する。

地上の慣性座標 (t,x) で、ミンコフスキー計量が基底に返す値は次のとおり。c は光速。時間の単位を秒、位置の単位をメートルに取る。

\begin{aligned} g_p\!\left(\left.\frac{\partial}{\partial t}\right|_p, \left.\frac{\partial}{\partial t}\right|_p\right)&=-c^2,\\ g_p\!\left(\left.\frac{\partial}{\partial t}\right|_p, \left.\frac{\partial}{\partial x}\right|_p\right)&=0,\\ g_p\!\left(\left.\frac{\partial}{\partial x}\right|_p, \left.\frac{\partial}{\partial x}\right|_p\right)&=1. \end{aligned}

引数を逆にした混合項も対称性からゼロ。g_p(V,V) の両方に右へ進む人の接ベクトルを入れ、第一引数と第二引数の足し算を順に開くと四項になる。

\begin{aligned} g_p(V,V) ={}&g_p\!\left(\left.\frac{\partial}{\partial t}\right|_p, \left.\frac{\partial}{\partial t}\right|_p\right)\\ &+v\,g_p\!\left(\left.\frac{\partial}{\partial t}\right|_p, \left.\frac{\partial}{\partial x}\right|_p\right)\\ &+v\,g_p\!\left(\left.\frac{\partial}{\partial x}\right|_p, \left.\frac{\partial}{\partial t}\right|_p\right)\\ &+v^2 g_p\!\left(\left.\frac{\partial}{\partial x}\right|_p, \left.\frac{\partial}{\partial x}\right|_p\right)\\ ={}&-c^2+v\cdot0+v\cdot0+v^2\cdot1\\ ={}&-c^2+(3\,\mathrm{m/s})^2. \end{aligned}

地上に立つ人の U には時間方向の基底だけが入るので、g_p(U,U)=-c^2。時刻 5\,\mathrm s と位置 10\,\mathrm m は点 p を決める。この慣性座標でのミンコフスキー計量は、どの点でも基底に同じ値を返すので、最後の答えにはこの二つの数が現れない。

地上の時刻で微分した接ベクトルと、固有時で微分した接ベクトル

上の V は h で微分して作った。世界線上では dt/dh=1 なので、これは地上の時刻 t による微分に当たる。物体自身の時計の読み \tau で微分した接ベクトルを W=\dfrac{dt}{d\tau}V とすると、固有時による規格化は g_p(W,W)=-c^2。双線形性を使うと、

\begin{aligned} -c^2&=\left(\frac{dt}{d\tau}\right)^2 g_p(V,V),\\ \frac{d\tau}{dt}&=\frac{\sqrt{-g_p(V,V)}}{c} =\sqrt{1-\frac{v^2}{c^2}}. \end{aligned}

未来向きに進む時計なので正の平方根を取った。地上に立つ人では v=0 で d\tau/dt=1。ここまでのすれ違いの例では地上時刻を使い、測地線方程式では物体の固有時で微分する。

座標変換を計算するときは、基底に計量を入れた値を行列に並べる。時間を T = ct で表すと、時間成分も長さの単位になる。(T,x) の順での計量行列を η = diag(−1,1) と書く。

4. 測地線から慣性運動を求める

(t,x) での計量成分はどの点でも同じ。したがって計量成分の偏微分はすべてゼロになり、それを使うクリストッフェル記号もすべてゼロになる。第2節の二本の式に代入すると、

t と x の固有時による二階微分はゼロ

初期の値を t₀, x₀, ṫ₀, ẋ₀ とし、固有時の原点をそこで合わせる。一回積分すると速度の二成分が一定になり、もう一回積分すると、

t(τ) = t₀ + ṫ₀τ, x(τ) = x₀ + ẋ₀τ

未来向きの物体では ṫ₀ > 0。時間の式から τ = (t − t₀)/ṫ₀ を求め、位置の式に代入すると、

x(t) = x₀ + (ẋ₀/ṫ₀)(t − t₀)

座標時刻で測った速度 dx/dt = ẋ₀/ṫ₀ が一定なので、自由粒子は等速直線運動をする。光の進む方向では接ベクトルの二次形式がゼロになる。地上の時刻でパラメータ付けし、位置の変化率を v とすると、3節と同じ計算で −c² + v² = 0 となる。光速の大きさは c となる。

5. 計量を保つ座標変換からブーストを求める

慣性系 S′ が S に対して x 方向に符号付き速度 v で動く。原点がすれ違う時刻を両系でゼロにし、未来と空間軸の正の向きをそろえる。β = v/c とおく。慣性座標間の変換は、原点をそろえれば線形になる。これを行列 Λ で表す。

(T′, x′) は Λ による成分変換。Λ は η を保存する。

ΛᵀηΛ = η は、変換した成分で計算しても、もとの成分で計算しても、二次形式が同じ値になるという条件。S′ の原点は S では x = βT を進む。そこで x′ = 0 となるように、行列の二行目を (−kβ,k) と置く。k は正の係数とする。

一行目を (p,q) と置く。計量を保つ条件は、同値な ΛηΛᵀ = η を使うと、行ごとに読める。

二行目の自己内積は1、二行の内積は0、一行目の自己内積は−1。

最初の式から k = γ。次の式から q = −βp。最後の式に入れ、未来向きを保つよう p > 0 を選べば p = γ になる。したがって S から S′ へのローレンツ・ブーストは

Λ = γ × 行列 (1, −β; −β, 1)
