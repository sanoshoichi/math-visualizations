特殊相対性理論

線路の左右に置いたランプが、線路に静止した時計では同時に光った。走る列車に固定した時計でも、二つの発光は同時になるだろうか。この問いから、時刻の付け方、時計が実際に刻む時間、粒子のエネルギーと運動量へ進む。

対象は、微積分・ベクトル・Newton 力学を学んだ物理学科2年生。新しく覚えるのは「出来事の座標」「同じ時計が刻む固有時」「四元ベクトル」の区別。時間の遅れを暗記する前に、誰が、どの二つの出来事を測っているかを決める。

  • 時計の遅れと長さの収縮を、測定条件から導く。
  • 固有時と四元運動量で、再会・衝突を計算する。

1. 出来事と四次元座標

ランプが光る瞬間を一つの「出来事」と呼ぶ。線路に沿って物差しと同期した時計を並べれば、発光した場所と、その場所の時計が示した時刻を記録できる。列車にも同じように物差しと時計を並べる。どちらも等速運動する座標系なので、慣性系として扱える。

xμ = (ct, x, y, z)。Δs² = −(cΔt)² + Δx² + Δy² + Δz²。
離れた時計をどう同期するか

A の時計で時刻 t₁ に光を送り、B で反射した光が A に時刻 t₂ に戻るとする。A と B が同じ慣性系で静止し、光の一方向の速さを両向きで同じ c とする同期規約を採れば、B の反射時刻を往復の中点 (t₁ + t₂)/2 に合わせる。以下で使う「同時」は、この手順で同期した時計の読みが一致することを指す。

時刻に光速を掛けた ct は長さの単位を持つ。μ は四つの座標のうちどれを指すかを示す添字。上の間隔は二つの出来事の座標差から作る量で、次節で慣性系を変えても値が保たれることを示す。

一つの時計や粒子について、時々刻々の位置をつないだ線が世界線。以下の図では、縦が時刻、横が線路方向の位置。光速を 1 とする単位を使うので、光は傾き ±1 の直線になる。

2. ローレンツ変換と同時性

線路の慣性系を S、列車の慣性系を S′ とする。β は列車の速度を光速で割った値で、右向きを正とする。t′ 軸は列車の原点がたどる線。x′ 軸は、列車の各場所にある同期時計が一斉にゼロを示す出来事を結んだ線。

公準から変換を求める

相対性原理によれば、すべての慣性系で物理法則は同じ形をとる。真空中の光速はどの慣性系でも c である。両系で原点がすれ違う出来事を時刻ゼロとする。空間と時間の一様性を仮定し、座標差の変換が原点の選び方に依存しない線形変換を使う。以下の導出では c = 1 とする。

S で見ると、動く系の原点は x = βt をたどる。この世界線で x′ = 0 になるように空間座標を置き、時間座標も t と x の一次式で表す。

x′ = a(x−βt)、t′ = bt+dx。

右向きの光では x = t と x′ = t′、左向きの光では x = −t と x′ = −t′ が成り立つ。両方を代入すると、時間座標の係数 b と d が決まる。ここで a,b,d は導出用の未知係数で、図の出来事 A・B・C とは無関係。

b+d = a(1−β)、b−d = a(1+β)。よって b = a、d = −aβ。

逆変換では速度を −β に変える。空間の向きを反転しても尺度係数は同じなので、逆変換にも同じ a が現れる。往復の変換で元の座標に戻ることから、正の係数 a が決まる。

x = a(x′+βt′) = a²(1−β²)x。よって a = 1/√(1−β²) = γ。

係数を最初の二式に代入する。速度がゼロなら両系の座標は一致する。

γ = 1/√(1−β²),　 t′ = γ(t−βx),　 x′ = γ(x−βt)

点 C は、線路の時計が t = 1 を示すときに列車の原点が通る出来事。青い t′ 軸上の O から C までを、第3節で列車の時計の固有時を計算する例に使う。

二つのランプの時刻を比べる

赤い A と B が左と右のランプの発光。線路の時刻は図の縦軸 t で読む。A と B を結ぶ水平の破線が t = 0.6 の高さで、線路の時計では二つのランプが同時に光る。表の時刻は、発光した場所に対応する同期時計の読みを示す。図の灰色は線路の軸、青は列車の軸、緑の破線は光の軌跡。

B の座標から A の座標を引く。線路では時間差がゼロなので、列車での時間差には位置差の項だけが残る。

Δt′ = γ(Δt−βΔx) = −1.6γβ。

t′ = γ(t−βx)。t′ を一定にすると、t = βx+t′/γ。

β を 0 にすると A と B は同時。β の符号を反転すると Δt′ の符号も反転し、順序が入れ替わる。

P=(x,t)=(\gamma x^\prime,\gamma\beta x^\prime)+(\gamma\beta t^\prime,\gamma t^\prime).

これは斜めの二本の基底への分解。時刻 t′ は x′ 軸に平行にたどって t′ 軸で読み、位置 x′ は t′ 軸に平行にたどって x′ 軸で読む。紙面上の線分の長さを、そのまま t′ の数値にすることもできない。

t^\prime=1,\ x^\prime=0\quad\Longrightarrow\quad (t,x)=(\gamma,\gamma\beta).

この点が t′ 軸の「1」の目盛り。β=0.6 なら γ=1.25 なので (t,x)=(1.25,0.75) に置く。上のスライダーと独立した、目盛りの校正の数値例である。

確認問題　β=0.5 で A と B のどちらが S′ で先に発光する？
t_A^\prime=1.155,\quad t_B^\prime=0.231,\quad\Delta t^\prime=-0.924.

B のほうが早い。この二つの発光は空間的に離れており、光速以下の信号で互いを引き起こせない。

3. 不変間隔と固有時

変換しても間隔が保たれる理由

ランプの時刻差と位置差は慣性系によって変わる。その二つから作る間隔はどうか。座標差をローレンツ変換し、平方を展開すると、時間差と位置差の積を含む二項が相殺される。

変換後の間隔は γ²(1−β²)(−Δt²+Δx²)。γ²(1−β²) = 1 なので変換前の値に等しい。

時計の読みを間隔から求める

質量を持つ粒子の一瞬の静止系では、粒子の位置の微小変化がゼロになる。その瞬間の時間差を固有時 dτ と呼ぶ。これは粒子と一緒に動く時計が刻む時間である。間隔はどの慣性系でも同じなので、任意の系での座標時間と速度から dτ を計算できる。ここでは光速 c を式に戻す。

−c²dτ² = −c²dt²+|dx|²。よって dτ = √(1−|v|²/c²) dt。

速度が一定なら、平方根を積分の外に出せる。青い世界線の時計が刻む時間は、S の座標時間を γ で割った値になる。

−Δt′²+Δx′² = −Δt²+Δx²。慣性運動の固有時 Δτ = √(Δt²−Δx²)。

ランプ A と B の間隔は正で、光でも片方の発光からもう片方に間に合わない。下の二行目では別の二つの出来事を比べる。出発点 O と、線路の時刻 1 に列車の原点が通る点 C である。O から C までに列車の原点の時計が刻む時間が固有時になる。

A → B の間隔の二乗（S / S′）
O → C で S′ の時計が測る固有時

O から C まで、S の座標時間は 1。β を 0 から離すほど、S′ の時計が刻む時間は短くなる。

同時性が変わっても、原因と結果は逆転しない

間隔 Δs²二つの出来事の関係慣性系を変えると
負（時間的）光より遅い物体が結べる未来向きの順序は同じ
0（光的、異なる二点）光が結べる未来向きの順序は同じ
正（空間的）光速以下の信号では結べない順序が変わる場合がある
\Delta t>0,\quad c\Delta t\geq|\Delta x|\quad\Longrightarrow\quad\Delta t^\prime=\gamma\left(\Delta t-\frac{v\Delta x}{c^2}\right)>0\quad(|v|<c).

ここで比べるのは時間の向きを保つ慣性系。空間的な A→B の間隔に √(−Δs²)/c を使って「時計の経過時間」を割り当てることはできない。

4. 長さの収縮 — 同時に両端を測る

棒の長さを測るには、ある慣性系で同じ時刻に両端の位置を記録する。両端から届いた光を写真で見る方法とは測定条件が異なる。棒は S′ に静止し、静止長を L₀ とする。

\Delta x^\prime=L_0,\qquad\Delta t=0\quad\Longrightarrow\quad L_0=\gamma(\Delta x-v\Delta t)=\gamma L.
L=\frac{L_0}{\gamma}=L_0\sqrt{1-v^2/c^2}.

β=0.6 なら γ=1.25。S で長さ 1.6 と測った二点を S′ へ変換すると、時刻差は −1.2 になる。S′ では同時の測定ではないが、棒の両端は静止しているので位置差は常に L₀=2。

\Delta t^\prime=\gamma\left(0-\frac{vL}{c^2}\right)=-\frac{vL_0}{c^2}.

離れていく光源から届く波

地球から遠ざかる光源が、自分の時計で周期 Δτ ごとにパルスを出す。地球の系では発光の間隔が γΔτ。その間に光源は vγΔτ 遠ざかるので、二発目の光はさらに vγΔτ/c の時間を要する。

\Delta t_{\rm 到着}=\gamma(1+\beta)\Delta\tau,\qquad\frac{f_{\rm 受信}}{f_{\rm 放射}}=\frac1{\gamma(1+\beta)}=\sqrt{\frac{1-\beta}{1+\beta}}.
確認問題　β=0.6 で受信する周波数は？
f_{\rm 受信}/f_{\rm 放射}=\sqrt{0.4/1.6}=0.5.

周期は2倍、周波数は半分。これは受信の間隔であり、座標時刻による時間の遅れだけとは異なる。

6. 往復した時計は何を測るか

今度は二つの時計を同じ場所で出発させ、同じ場所で読みを比べる。青は出発地点に留まり、赤は線路の時計で 5 秒進んだところで折り返し、同じ速さで戻る。折り返しにかかる時間を無視し、往路と復路で固有時をそれぞれ計算して足す。

dτ = √(1−|v|²/c²) dt。静止時計は 10 秒、往復時計は 10√(1−β²) 秒。
時計再会までに刻む時間（秒）
青：静止10.000
赤：往復

β を 0.6 にすると、赤は往路と復路で各 4 秒、合計 8 秒を刻む。同じ出発点と再会点を結んでも、固有時は途中の世界線に沿って積分する量なので、時計の読みは経路に依存する。

互いに相手の時計が遅れるのに、なぜ再会で差が出る？

一つの慣性系のまま出発から再会まで静止しているのは青。赤は折り返しで慣性系を変える。各区間で「遠くの青の時計の今」を割り当て直すと、同時性の基準も変わる。

\beta=0.6:\quad (t_{\rm 折返し},x_{\rm 折返し})=(5,3)\quad(c=1).

折り返し点を通る同時刻線を地球 x=0 まで延ばす。往路では t−0.6x=一定、復路では t+0.6x=一定。

t_{\rm 地球,往路}=5-0.6\times3=3.2,\qquad t_{\rm 地球,復路}=5+0.6\times3=6.8.

赤が地球に割り当てる「今」は 3.2 から 6.8 に変わる。地球の時計が実際に飛び進むという意味ではない。瞬間的な折り返しは理想化で、滑らかに加速する場合も固有時の積分で計算できる。

7. 四元速度・四元運動量

ニュートン力学では、位置を時刻で微分して速度を作り、質量を掛けて運動量を求める。相対論では、微分する対象を四次元座標に広げ、分母に粒子自身の時計が測る固有時を使う。固有時は慣性系によらないので、この微分で作った四元速度は座標差と同じローレンツ変換に従う。

固有時で微分する

前節で求めた dτ を使うと、dt/dτ は γ になる。連鎖律を使えば、四元速度の時間成分と空間成分が同時に得られる。

dt/dτ = γ。連鎖律から dxμ/dτ = (dxμ/dt)γ = γ(c,v)。

四元速度に質量 m を掛ける。空間成分は運動量で、時間成分に光速を掛けた量が全エネルギーになる。速さが光速より十分小さいときに展開し、古典力学で見慣れた式がどこに現れるかを確かめる。

低速では E ≈ mc² + ½m|v|²、p ≈ mv。

四元運動量の計量による二乗は、静止系で計算できる。静止系では空間成分がゼロ、時間成分が mc。同じ二乗を任意の慣性系で計算し、両式を等置する。

PμPμ = −m²c² = −(E/c)² + |p|²。よって E² = |p|²c² + m²c⁴。
U = γ(c,v)、P = mU = (E/c,p)。E = γmc²、p = γmv、E² = |p|²c² + m²c⁴。

棒図は E/(mc²)、|p|/(mc)、K/(mc²) という無次元量を比較する。数値計算では c=1、m=1。青は全エネルギー、緑は運動量、赤は運動エネルギー K=E−mc²。灰色の基準線は 1。

ローレンツ因子 γ
不変量 E² − |p|²

速度を上げると E と |p| はともに増えるが、E² − |p|² は 1 のまま。静止すると運動量と運動エネルギーはゼロで、全エネルギーには静止エネルギー mc² が残る。

光と衝突に使う

光子では質量がゼロで、E = |p|c。光子の世界線では固有時が進まないため、四元速度に質量を掛ける定義は質量を持つ粒子に使う。孤立した系の衝突では、全エネルギーと三方向の全運動量を合わせた四元運動量が保存する。

衝突前後の全四元運動量は等しい。光子では E = c|p|。

たとえば等しいエネルギー E の光子が互いに逆向きに進むと、全運動量はゼロで全エネルギーは 2E。二光子を一つの系として見た不変質量は 2E/c² になる。

8. 衝突と「系の質量」

孤立系の衝突では、全エネルギーと全運動量を同時に保存する。粒子の質量 m と、複数の粒子をまとめた系の不変質量 M を区別する。

P_{\rm 全}^\mu=\sum_a P_a^\mu,\qquad M^2c^4=E_{\rm 全}^2-c^2|\mathbf p_{\rm 全}|^2.

等しい質量 m の粒子が速度 ±v で衝突して一体化する。全運動量はゼロ。エネルギー保存から、合体後の静止エネルギーは衝突前の全エネルギーになる。

\mathbf p_{\rm 全}=0,\qquad Mc^2=2\gamma mc^2,\qquad M=2\gamma m.

v=0.6c なら γ=1.25 なので M=2.5m。増えた 0.5mc² は衝突前の運動エネルギーで、合体後の内部エネルギーとして残る。外へ光や熱を逃がすなら、その四元運動量も保存式に含める。

確認問題　二つの光子は、それぞれ質量ゼロなら系の質量もゼロ？
M^2c^4=2E_1E_2(1-\cos\theta).

θ は二つの運動量のなす角。逆向きで E₁=E₂=E なら M=2E/c²、同じ向きなら M=0。系の質量は各質量の単純な和ではない。

9. 加速度計の読みと、次の問い

加速する運動も、平坦な時空で扱える。四元加速度を定義し、四元速度のノルムが一定であることを微分する。

A^\mu=\frac{\mathrm dU^\mu}{\mathrm d\tau},\qquad U_\mu U^\mu=-c^2\quad\Longrightarrow\quad U_\mu A^\mu=0.

一次元で固有加速度 α が一定なら、静止から出発する世界線は双曲線になる。固有加速度は本人が持つ加速度計の読み。

ct=\frac{c^2}{\alpha}\sinh\!\left(\frac{\alpha\tau}{c}\right),\qquad x=\frac{c^2}{\alpha}\left[\cosh\!\left(\frac{\alpha\tau}{c}\right)-1\right].
v=c\tanh(\alpha\tau/c),\qquad \frac{\mathrm dv}{\mathrm dt}=\frac{\alpha}{\gamma^3}.

加速度計の値が一定でも、慣性系での dv/dt は小さくなり、速度は c に近づく。加速しているから時空に曲率がある、とは言えない。一般相対論では、自由落下する粒子どうしの相対運動を使って曲率を調べる。

確認問題　光子の四元速度 U=dx/dτ は定義できる？

光の経路では dτ=0 なので、この定義は使えない。光の四元運動量は P=(E/c,p)、P·P=0 として扱い、経路には別のアフィンパラメータを使う。

続きは 一般相対性理論。計量の符号は微分幾何学の第6項目でも操作できる。
