第1部 特殊相対論

1.1 電磁気学から生まれた問い

真空の Maxwell 方程式から、電磁場には速さ c = 1/√(μ₀ε₀) で伝わる波があると分かる。この速さは、光を追う観測者にとっても同じだろうか。

ガリレイ変換では u′ = u − v。

従来の時間のまま光を追うと、位置の差を同じ時間で割るので u′ = c − v になる。一方、光速を両系で同じとするなら、時刻の変換も見直す必要がある。

1.2 エーテルを仮定すると何が測れるはずか

光を伝える媒質に対して、長さ L が等しい二本の腕を持つ装置が速度 v で進むと仮定する。平行な腕では光と鏡の相対速度が行きと帰りで異なる。垂直な腕では、光は横に動く鏡を目指して斜めに進む。腕の長さはこの古典モデルでは一定とする。

平行腕の往復時間は L/(c−v)+L/(c+v)。垂直腕は 2L/√(c²−v²)。

干渉計を回せば、この往復時間差に対応する縞の移動が予測される。マイケルソンとモーリーの実験では、単純な静止エーテル模型が予測する大きさの移動は見つからなかった。

1.3 相対性原理と光速一定

慣性系を取り替えても物理法則は同じ形をとる。真空中の光の速さも、それぞれの慣性系で同期した時計と物差しを使って測ると c になる。光源が動いている場合も同じ条件を使う。

時空図では、横軸が位置 x、縦軸が ct。原点で光を放つと、その光は x = ±ct に沿う。光源の速度を変えると光源の世界線が傾く。

1.4 離れた時計を同期する

二か所の時計を比べるには、同時刻をどう決めるかが要る。固定した時計 A から光を送り、時計 B の位置で反射させて A で受け取る。A の送信時刻を t₁、受信時刻を t₂ とする。

B の反射時刻は A の送受信時刻の中点。

この系で光の往路と復路が同じ速さなら、反射点は往復の途中の時刻に当たる。その瞬間に B が上の時刻を示すように合わせる。別の慣性系でも、自分の系に固定した時計に同じ手順を行う。二つの系でどの出来事が同時になるかは、次の変換で計算する。

1.5 ローレンツ変換を導く

ローレンツ変換の導出 ― 原点 O から出す光

慣性系 S に対し、右向きを正とする速度 v で動く慣性系を S′ とする。β = v/c と置く。変換を求めるために、二つの原点が重なる出来事 O で光を左右に出すと考える。

相対性原理によれば、すべての慣性系で物理法則は同じ形をとる。真空中の光速はどちらの系でも c。以下では c=1 となる単位を使い、両系の原点が重なる出来事 O を両方で位置 0、時刻 0 とする。

1. まず一般の一次式を書く

空間と時間の一様性から、同じ座標差を変換した結果は、どの場所・時刻からその差を測るかに依らないとする。変換が連続なら、この条件から変換は一次式になる。座標を一つの定数分だけずらす自由もあるが、ここでは O を両系で原点に選んだので定数項は 0。よって位置と時刻を、それぞれ次の一次式で置ける。

x′ = ax + kt、t′ = bt + dx。

a,k,b,d は、相対速度を決めると定まる係数。出来事ごとに変わるのは座標 x,t のほう。ここで dx は係数 d と位置 x の積を表す。

座標差が場所や時刻に依らないと、なぜ一次式になるか

ある出来事の座標の組を z=(x,t)、座標のずれを h、変換を F と書く。一様性とは、F(z+h)-F(z) が z に依らないという条件。z=0 で同じ差を取ると、F(0)=0 なので次の式が得られる。

F(z+h) − F(z) = F(h)。よって F(z+h) = F(z) + F(h)。

この式を繰り返すと、座標を整数倍したとき変換結果も同じ整数倍になる。整数で割れば有理数倍でも成り立ち、連続性を使えば実数倍にも広がる。そこで (x,t)=x(1,0)+t(0,1) と分けると、F(x,t)=xF(1,0)+tF(0,1)。これが上の二つの一次式に当たる。

2. 動く原点の位置から、位置の式を絞る

S で見ると、S′ の原点は時刻 0 に位置 0 を出て、一定の速度 β で動く。その位置は x=βt。同じ原点を自分の座標系 S′ で測れば、どの時刻でも位置は x′=0。したがって、位置の一次式に x=βt を入れた結果が、すべての t で 0 になる。

0 = a(βt) + kt = (aβ + k)t。すべての t で成り立つので k = −aβ。よって x′ = a(x−βt)。

括弧の中の x−βt は、時刻 t の位置 x から、同じ時刻に動く原点がいる位置 βt を引いた量。a は、その差を S′ の位置座標に直す尺度を表す。この条件は位置 x′ についての条件なので、時刻の式は t′=bt+dx の形のまま。次に光の速さを使って、b と d を絞る。

3. 左右の光を代入して、時刻の式を絞る

右向きの光は S で x=t。これを二つの式に代入すると、x′=a(1−β)t、t′=(b+d)t になる。S′ でも右向きの光の速さは 1 なので、x′=t′。時刻 0 以外の光の点で両辺を t で割ると、最初の条件が出る。

b + d = a(1−β)。

左向きの光は S で x=−t。同じように代入すると、x′=−a(1+β)t、t′=(b−d)t。今度は x′=−t′ を使う。

b − d = a(1+β)。

二つの条件を足すと 2b=2a、最初の式から二番目を引くと 2d=−2aβ。したがって、ここまでの変換は次の形になる。

x′ = a(x−βt)、t′ = a(t−βx)。

4. 逆変換で、残った係数を求める

S から見て S′ が速度 β で動くなら、S′ から見た S の速度は −β。実際、S の原点では x=0 なので、直前の式に代入すると x′=−aβt、t′=at。したがって x′/t′=−β となる。ここまで求めた変換の式で、入力と出力の座標を入れ替え、相対速度の符号を反転すれば逆変換になる。両方の空間軸を反転しても長さの尺度は同じなので、係数 a は β と −β で同じ値を取る。よって逆変換の位置の式は次のとおり。

x = a(x′ + βt′)。

この右辺に、直前の式で得た x′ と t′ を代入する。変換してから逆変換すれば、元の x に戻る。

x = a[a(x−βt) + βa(t−βx)] = a²(1−β²)x。

任意の位置でこの等式が成り立つので a²(1−β²)=1。両系の空間軸を同じ向きに取るので a>0 を選ぶ。この正の値を γ と書く。

γ = 1/√(1−β²)。x′ = γ(x−βt)、t′ = γ(t−βx)。

相対速度が 0 なら γ=1 となり、両系で座標は一致する。

同じ発光 A・B に、二つの座標系で時刻を付ける

発光 A・B は、どちらも線路脇で起きる。線路の同期時計は、二つの発光を同じ t = 0.6 と記録する。列車と同じ速度で動く同期時計を考える。発光した瞬間にその場所を通る時計の読みが、列車の座標での発光時刻 t′。車体の外にも、この座標系の時計を置けると考える。乗客が後から光を受け取る時刻は、光が発光地点から乗客まで進む時間も含む。

発光 B の時刻から発光 A の時刻を引く。線路では Δt = 0、位置の差は Δx = 0.8 − (−0.8) = 1.6。これをローレンツ変換に代入すると、列車の座標での発光時刻の差 Δt′ が出る。

Δt′ = γ(Δt−βΔx) = −1.6γβ。

P=(x,t)=(\gamma x^\prime,\gamma\beta x^\prime)+(\gamma\beta t^\prime,\gamma t^\prime).

これは斜めの二本の基底への分解。時刻 t′ は x′ 軸に平行にたどって t′ 軸で読み、位置 x′ は t′ 軸に平行にたどって x′ 軸で読む。紙面上の線分の長さを、そのまま t′ の数値にすることもできない。

第2部 座標変換の理論

2.1 反変成分と共変成分

同じ変位でも、座標の目盛りを変えると数値が変わる。x′ = ax とするとベクトルの成分は Vˣ′ = aVˣ。一方、スカラー場の微分は連鎖律で逆向きに変換される。

共変成分は 1/a 倍。ベクトルと掛けた値は一定。

例えば ω = df なら、積はその変位に沿う f の一次の変化。上付きと下付きが逆に変わるので、測る値は目盛りの付け方に依らない。

2.4 偏微分を四次元でまとめる

スカラー場を変換してから微分すると、連鎖律で下付き添字の変換が現れる。ミンコフスキー計量で添字を上げて縮約すると、座標の取り方によらない波動演算子になる。

波動演算子 □ = −c⁻²∂²ₜ + ∇²。

第3部 相対性原理の実践

3.1 固有時で運動量を微分する

三次元の力を F = dp/dt とする。四元運動量を固有時で微分すれば、座標を変えても四元ベクトルとして変換する力になる。

四元力の時間成分は γ F·v/c、空間成分は γF。

時間成分は仕事率から来る。E²=m²c⁴+c²|p|² を時刻で微分して c²p/E=v を使うと、dE/dt=F·v になる。さらに dt/dτ=γ を掛ける。

3.2 エネルギー密度と流れを一つにする

粒子の集団について「どれだけエネルギーがあるか」と「面を通ってどちらへ流れるか」を同時に記述する。圧力がない粒子の流れで、各粒子と同じ速度の系で測った質量密度を ρ₀ とする。

圧力なしの流れでは T = ρ₀ U⊗U。密度の時間変化と流束の発散の和はゼロ。

密度に γ が二回入る理由は、同じ粒子数が占める体積が縮むことと、一粒子あたりのエネルギーが増えること。一様な流れでは、境界から出入りする量がつり合う。

3.3 応力は運動量の流束

面を横切るのがエネルギーならエネルギー流束、運動量なら応力の成分になる。Tⁱʲ の第一添字は面の法線方向、第二添字は運ばれる運動量の方向。斜めの成分は、面に平行な運動量が面を横切るせん断に対応する。

運動方向の成分はブーストで混ざる。横方向の圧力成分は p。

3.4 ポテンシャルで Maxwell 方程式をまとめる

電位とベクトルポテンシャルを Aμ = (φ/c,A)、電荷密度と電流密度を Jμ = (cρ,J) にまとめる。電場と磁場は E=−∇φ−∂ₜA、B=∇×A で求める。

ローレンツゲージでポテンシャルの波動方程式が成り立つ。四元電流は保存する。

ポテンシャルを \mathbf A\mapsto\mathbf A+\nabla\chi、\phi\mapsto\phi-\partial_t\chi と変えても、電場では混合偏微分が打ち消し合い、磁場では勾配の回転がゼロになる。これがゲージ変換。ローレンツゲージを保つには \Box\chi=0 を使う。

3.5 波動方程式から座標変換を求め直す

参照記事では Maxwell 方程式の形をそろえて座標と電磁場の変換を求める。ここでは座標の部分を真空の波動演算子で確かめる。c=1 とし、x'=a(x-\beta t),\ t'=bt+dx を使う。y'=y,\ z'=z として横方向の演算子はそのままにする。

連鎖律で旧座標の偏微分を新座標の偏微分に分ける。

この二式を \partial_x^2-\partial_t^2 に入れると、混合微分の係数は 2a(d+\beta b)。元の演算子と同じ形にするには d=-\beta b。横方向の係数を 1 に固定したので、残る係数もそれぞれ 1 と −1 に合わせる。

空間と時間の向きを保つ正の係数を選ぶと a = b = γ。

3.6 電場と磁場を同じテンソルで変換する

共変ポテンシャルから、反対称なテンソル F_{\mu\nu}=\partial_\mu A_\nu-\partial_\nu A_\mu を作る。このページの符号規約では F_{0i}=-E_i/c,\ F_{ij}=\epsilon_{ijk}B_k。添字が二つあるので、ブーストでは行と列の両方が変わる。

電荷と電流のある方程式と、ポテンシャルの定義から従う方程式。

例えば \mathbf E=0、磁場が +z 方向のとき、+x へ動く系では E'_y=-\gamma vB_z と B'_z=\gamma B_z が得られる。場が物質とエネルギーや運動量を交換する場合は、場と物質のエネルギー運動量テンソルを足したものが保存する。

電磁場と物質のエネルギー運動量の和が保存する。
