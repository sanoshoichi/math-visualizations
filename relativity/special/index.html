特殊相対性理論

地上と列車で、二つのランプが光る順番を比べる。

地上を慣性系 S、右へ走る列車を慣性系 S′ とする。両系の原点がすれ違う点を O とし、そのとき両方の原点の時計をゼロに合わせる。各系では、離れた場所に置いた時計も、その系の中で同期してある。

  • F：地上の原点で、地上時刻 2.00 秒 に発光。
  • E：地上の原点から右へ 2.75 光秒 の地点で、地上時刻 3.25 秒 に発光。

発光時刻は、光った場所に居合わせた時計の読み。原点にいる人が光を受け取る時刻は、光が届いたときの別の出来事になる。

地上と列車の軸を一枚に重ねる

横軸は地上での位置 x、縦軸は地上での時刻に光速を掛けた ct。どちらも光秒で描く。列車の速さ β = v/c を変えると、青い軸と補助線が動く。二つの発光点は同じ場所に残る。

列車では E が F より 0.50 秒先に光る。

地上の破線は F から右に 2.75 光秒、次に上へ 1.25 秒進んで E に着く。列車の青い矢印は、まず x′ 軸と平行に進み、次に ct′ 軸と平行に進む。初期値 β = 0.60 では、最後の青い矢印は左下を向く。列車の時刻では、E が F より 0.50 秒早い。

ct′ 軸は列車の原点 x′ = 0 の世界線。x′ 軸は列車で t′ = 0 の出来事を結んだ線。x′ 軸と平行な線の上では、列車の時刻が同じになる。矢印は二点の座標差を分けて示している。

二つの発光が同時になる速さ

「同時になる速さに合わせる」を押すと、F と E を結ぶ青い矢印が x′ 軸と平行になり、時間方向の矢印が消える。地上の座標で見た線 FE の傾きに、x′ 軸の傾きが一致した状態だ。

β = 1.25 / 2.75 = 5/11 ≈ 0.4545

この速さより遅い列車では F が先、速い列車では E が先。図の F,E は同じ発光なので、変わっているのは、離れた場所の二つの出来事にどの時刻を付けるかだ。

図の数値をローレンツ変換で求める

F から E への差を、時間成分から並べる。γ = 1 / √(1−β²) とすると、地上 S から列車 S′ への変換は次の式になる。

(cΔt′, Δx′) = γ(cΔt − βΔx, Δx − βcΔt)

β = 0.60 なら γ = 1.25。光秒を単位に、行列の各行を計算すると、

cΔt′ = −0.50 光秒、Δx′ = +2.50 光秒

時刻差の式で cΔt′ = 0 と置くと、図で使った同時の条件が出る。空間が1次元なら、この条件を満たす慣性系があるのは |Δx| > c|Δt| の場合だ。そうすれば求めた β が |β| < 1 に収まる。

どちらの系でも同じ値

位置差と時刻差は変わるが、時空間隔の二乗は同じ。光秒を単位に計算すると、

S: 2.75² − 1.25² = 6。S′: 2.50² − (−0.50)² = 6。

地上では、光でも1.25秒で2.75光秒は進めない。二つの発光は空間的に隔たっているので、発光の順番が変わる慣性系がある。同時になる系では時間の差がゼロになり、二点の距離は √6 光秒になる。
