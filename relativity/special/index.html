特殊相対性理論

慣性系で出来事を座標化し、光の伝わり方から座標変換を求める。その変換が保つ間隔から、時計の読みと粒子の運動量を導く。

四次元座標ローレンツ変換固有時往復する時計四元運動量

1. 出来事と四次元座標

時計が鳴る瞬間や粒子が衝突する瞬間を、時空の一点（出来事）として扱う。慣性系を一つ選ぶと、出来事に時刻と三つの位置座標を付けられる。時間に光速を掛けるのは、四成分を長さの単位でそろえるため。

xμ = (ct, x, y, z)。Δs² = −(cΔt)² + Δx² + Δy² + Δz²。

同じ粒子の出来事を順に結ぶと世界線になる。光では隣り合う出来事の間隔はゼロ。質量を持つ粒子では間隔は負になり、その世界線に沿って固有時が進む。以下の時空図では運動を x 方向に限り、光速を 1 とする。

2. ローレンツ変換と同時性

系 S′ は S に対して x 軸に沿う速度 β で動く。γ はローレンツ因子。S′ の原点が描く世界線が t′ 軸で、S′ で時刻ゼロの出来事を結ぶ線が x′ 軸になる。

公準から変換を求める

相対性原理によれば、すべての慣性系で物理法則は同じ形をとる。真空中の光速はどの慣性系でも c である。原点がすれ違うとき両系で時刻をゼロにし、慣性運動を保つ線形な変換を考える。以下の導出では c = 1 とする。

S で見ると、動く系の原点は x = βt をたどる。この世界線で x′ = 0 になるように空間座標を置き、時間座標も t と x の一次式で表す。

x′ = A(x−βt)、t′ = Bt+Cx。

右向きの光では x = t と x′ = t′、左向きの光では x = −t と x′ = −t′ が成り立つ。両方を代入すると、B と C が決まる。

B+C = A(1−β)、B−C = A(1+β)。よって B = A、C = −Aβ。

逆変換では速度を −β に変える。空間の向きを反転しても尺度係数は同じなので、逆変換にも同じ A が現れる。往復の変換で元の座標に戻ることから、正の係数 A が決まる。

x = A(x′+βt′) = A²(1−β²)x。よって A = 1/√(1−β²) = γ。

これを最初の二式に戻すと、ローレンツ変換になる。

γ = 1/√(1−β²),　 t′ = γ(t−βx),　 x′ = γ(x−βt)

灰色は S の軸、青は S′ の軸、緑の破線は光の軌跡。赤い A と B は S では同時刻。図上の点を固定したまま、表で S′ の時刻を比べる。

3. 不変間隔と固有時

変換しても間隔が保たれる理由

二つの出来事の座標差にも同じ線形変換が成り立つ。平方を展開すると、時間差と位置差の積を含む項が相殺される。

変換後の間隔は γ²(1−β²)(−Δt²+Δx²)。γ²(1−β²) = 1 なので変換前の値に等しい。

時計の読みを間隔から求める

質量を持つ粒子の一瞬の静止系では、粒子の位置の微小変化がゼロになる。その系の時間差を固有時 dτ と呼ぶ。間隔はどの慣性系でも同じなので、任意の系での座標時間と速度から dτ を計算できる。ここでは光速 c を式に戻す。

−c²dτ² = −c²dt²+|dx|²。よって dτ = √(1−|v|²/c²) dt。

速度が一定なら、平方根を積分の外に出せる。青い世界線の時計が刻む時間は、S の座標時間を γ で割った値になる。

−Δt′²+Δx′² = −Δt²+Δx²。慣性運動の固有時 Δτ = √(Δt²−Δx²)。

A と B の間隔は正で空間的。時刻の順序は変えられる。原点 O と、S′ の原点が S で時刻 1 にいる出来事 C は時間的に隔たる。青い t′ 軸上の点 C が、その時計の読みを表す。

A → B の間隔の二乗（S / S′）
O → C で S′ の時計が測る固有時

O から C まで、S の座標時間は 1。β を 0 から離すほど、S′ の時計が刻む時間は短くなる。

4. 往復した時計は何を測るか

出発と再会は両者に共通する出来事。青い時計は出発地点で静止し、赤い時計は一定の速さで遠ざかり、中間時刻で反転して戻る。反転にかかる時間を無視したモデルで、静止系では出発から再会まで 10 秒とする。

dτ = √(1−|v|²/c²) dt。静止時計は 10 秒、往復時計は 10√(1−β²) 秒。

β を 0.6 にすると、赤は往路と復路で各 4 秒、合計 8 秒を刻む。同じ出発点と再会点を結んでも、固有時は途中の世界線に沿って積分する量なので、時計の読みは経路に依存する。

5. 四元速度・四元運動量

質量 m の粒子について、四次元座標を粒子自身の時計の読み τ で微分すると四元速度になる。それに質量を掛けた四元運動量の時間成分が E/c、空間成分が運動量 p。

固有時で微分する

前節で求めた dτ を使うと、dt/dτ は γ になる。連鎖律を使えば、四元速度の時間成分と空間成分が同時に得られる。

dt/dτ = γ。連鎖律から dxμ/dτ = (dxμ/dt)γ = γ(c,v)。

質量 m を掛けて四元運動量を作る。時間成分を E/c と書くと、低速での展開から、全エネルギーのうち静止時にも残る項と、ニュートン力学の運動エネルギーに一致する項が分かる。

低速では E ≈ mc² + ½m|v|²、p ≈ mv。

四元運動量の計量による二乗は、静止系で計算できる。静止系では空間成分がゼロ、時間成分が mc。同じ二乗を任意の慣性系で計算し、両式を等置する。

PμPμ = −m²c² = −(E/c)² + |p|²。よって E² = |p|²c² + m²c⁴。
U = γ(c,v)、P = mU = (E/c,p)。E = γmc²、p = γmv、E² = |p|²c² + m²c⁴。

図では c = 1、m = 1 とする。青は全エネルギー、緑は運動量の大きさ、赤は運動エネルギー。灰色の基準線は静止エネルギー 1 を示す。

ローレンツ因子 γ
不変量 E² − |p|²

速度を上げると E と |p| はともに増えるが、E² − |p|² は 1 のまま。静止すると運動量と運動エネルギーはゼロで、全エネルギーには静止エネルギー mc² が残る。

光と衝突に使う

光子では質量がゼロで、E = |p|c。光子の世界線では固有時が進まないため、四元速度に質量を掛ける定義は質量を持つ粒子に使う。孤立した系の衝突では、全エネルギーと三方向の全運動量を合わせた四元運動量が保存する。

衝突前後の全四元運動量は等しい。光子では E = c|p|。

たとえば等しいエネルギー E の光子が互いに逆向きに進むと、全運動量はゼロで全エネルギーは 2E。二光子を一つの系として見た不変質量は 2E/c² になる。

続きは 一般相対性理論。計量の符号は微分幾何学の第6項目でも操作できる。
