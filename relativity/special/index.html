特殊相対性理論

慣性系を変えると、同じ出来事の時刻と位置は変わる。ここでは光速を 1 とし、空間は一次元とする。縦軸は時間、横軸は空間。

1. ローレンツ変換と同時性

系 S′ は S に対して右向きに速度 β で動く。γ はローレンツ因子。S′ の原点が描く世界線が t′ 軸で、S′ で時刻ゼロの出来事を結ぶ線が x′ 軸になる。

γ = 1/√(1−β²),　 t′ = γ(t−βx),　 x′ = γ(x−βt)

灰色は S の軸、青は S′ の軸、緑の破線は光の軌跡。赤い A と B は S では同時刻。図上の点を固定したまま、表で S′ の時刻を比べる。

2. 不変間隔と固有時

二つの出来事の座標差に同じ変換を施すと、混合項が消える。負の間隔を持つ二点を結ぶ慣性運動では、その時計が測る時間が固有時になる。

−Δt′²+Δx′² = −Δt²+Δx²。慣性運動の固有時 Δτ = √(Δt²−Δx²)。

A と B の間隔は正で空間的。時刻の順序は変えられる。原点 O と、S′ の原点が S で時刻 1 にいる出来事 C は時間的に隔たる。青い t′ 軸上の点 C が、その時計の読みを表す。

A → B の間隔の二乗（S / S′）
O → C で S′ の時計が測る固有時

O から C まで、S の座標時間は 1。β を 0 から離すほど、S′ の時計が刻む時間は短くなる。
