特殊相対性理論

線路の左右に置いたランプが、線路に静止した時計では同時に光った。走る列車に固定した時計でも、二つの発光は同時になるだろうか。この問いから、時刻の付け方、時計が実際に刻む時間、粒子のエネルギーと運動量へ進む。

1. 出来事と四次元座標

ランプが光る瞬間を一つの「出来事」と呼ぶ。線路に沿って物差しと同期した時計を並べれば、発光した場所と、その場所の時計が示した時刻を記録できる。列車にも同じように物差しと時計を並べる。どちらも等速運動する座標系なので、慣性系として扱える。

xμ = (ct, x, y, z)。Δs² = −(cΔt)² + Δx² + Δy² + Δz²。
離れた時計をどう同期するか

A の時計で時刻 t₁ に光を送り、B で反射した光が A に時刻 t₂ に戻るとする。A と B が同じ慣性系で静止し、光の往復の速さが同じなら、B の反射時刻を往復の中点 (t₁ + t₂)/2 に合わせる。以下で使う「同時」は、この手順で同期した時計の読みが一致することを指す。

時刻に光速を掛けた ct は長さの単位を持つ。μ は四つの座標のうちどれを指すかを示す添字。上の間隔は二つの出来事の座標差から作る量で、次節で慣性系を変えても値が保たれることを示す。

2. ローレンツ変換と同時性

線路の慣性系を S、列車の慣性系を S′ とする。β は列車の速度を光速で割った値で、右向きを正とする。t′ 軸は列車の原点がたどる線。x′ 軸は、列車の各場所にある同期時計が一斉にゼロを示す出来事を結んだ線。

公準から変換を求める

相対性原理によれば、すべての慣性系で物理法則は同じ形をとる。真空中の光速はどの慣性系でも c である。両系で原点がすれ違う出来事を時刻ゼロとする。空間と時間の一様性を仮定し、座標差の変換が原点の選び方に依存しない線形変換を使う。以下の導出では c = 1 とする。

S で見ると、動く系の原点は x = βt をたどる。この世界線で x′ = 0 になるように空間座標を置き、時間座標も t と x の一次式で表す。

x′ = a(x−βt)、t′ = Bt+Cx。

右向きの光では x = t と x′ = t′、左向きの光では x = −t と x′ = −t′ が成り立つ。両方を代入すると、b と d が決まる。

b+d = a(1−β)、b−d = a(1+β)。よって b = a、d = −aβ。

逆変換では速度を −β に変える。空間の向きを反転しても尺度係数は同じなので、逆変換にも同じ a が現れる。往復の変換で元の座標に戻ることから、正の係数 a が決まる。

x = a(x′+βt′) = a²(1−β²)x。よって a = 1/√(1−β²) = γ。

係数を最初の二式に代入する。速度がゼロなら両系の座標は一致する。

γ = 1/√(1−β²),　 t′ = γ(t−βx),　 x′ = γ(x−βt)

点 C は、線路の時計が t = 1 を示すときに列車の原点が通る出来事。青い t′ 軸上の O から C までを、第3節で列車の時計の固有時を計算する例に使う。

二つのランプの時刻を比べる

赤い A と B が左と右のランプの発光。線路では両方が時刻 0.6 に光る。表の時刻は、発光した場所に対応する同期時計の読みを示す。図の灰色は線路の軸、青は列車の軸、緑の破線は光の軌跡。

B の座標から A の座標を引く。線路では時間差がゼロなので、列車での時間差には位置差の項だけが残る。

Δt′ = γ(Δt−βΔx) = −1.6γβ。

3. 不変間隔と固有時

変換しても間隔が保たれる理由

ランプの時刻差と位置差は慣性系によって変わる。その二つから作る間隔はどうか。座標差をローレンツ変換し、平方を展開すると、時間差と位置差の積を含む二項が相殺される。

変換後の間隔は γ²(1−β²)(−Δt²+Δx²)。γ²(1−β²) = 1 なので変換前の値に等しい。

時計の読みを間隔から求める

質量を持つ粒子の一瞬の静止系では、粒子の位置の微小変化がゼロになる。その瞬間の時間差を固有時 dτ と呼ぶ。これは粒子と一緒に動く時計が刻む時間である。間隔はどの慣性系でも同じなので、任意の系での座標時間と速度から dτ を計算できる。ここでは光速 c を式に戻す。

−c²dτ² = −c²dt²+|dx|²。よって dτ = √(1−|v|²/c²) dt。

速度が一定なら、平方根を積分の外に出せる。青い世界線の時計が刻む時間は、S の座標時間を γ で割った値になる。

−Δt′²+Δx′² = −Δt²+Δx²。慣性運動の固有時 Δτ = √(Δt²−Δx²)。

ランプ A と B の間隔は正で、光でも片方の発光からもう片方に間に合わない。下の二行目では別の二つの出来事を比べる。出発点 O と、線路の時刻 1 に列車の原点が通る点 C である。O から C までに列車の原点の時計が刻む時間が固有時になる。

A → B の間隔の二乗（S / S′）
O → C で S′ の時計が測る固有時

O から C まで、S の座標時間は 1。β を 0 から離すほど、S′ の時計が刻む時間は短くなる。

4. 往復した時計は何を測るか

今度は二つの時計を同じ場所で出発させ、同じ場所で読みを比べる。青は出発地点に留まり、赤は線路の時計で 5 秒進んだところで折り返し、同じ速さで戻る。折り返しにかかる時間を無視し、往路と復路で固有時をそれぞれ計算して足す。

dτ = √(1−|v|²/c²) dt。静止時計は 10 秒、往復時計は 10√(1−β²) 秒。

5. 四元速度・四元運動量

ニュートン力学では、位置を時刻で微分して速度を作り、質量を掛けて運動量を求める。相対論では、微分する対象を四次元座標に広げ、分母に粒子自身の時計が測る固有時を使う。固有時は慣性系によらないので、この微分で作った四元速度は座標差と同じローレンツ変換に従う。

固有時で微分する

前節で求めた dτ を使うと、dt/dτ は γ になる。連鎖律を使えば、四元速度の時間成分と空間成分が同時に得られる。

dt/dτ = γ。連鎖律から dxμ/dτ = (dxμ/dt)γ = γ(c,v)。

四元速度に質量 m を掛ける。空間成分は運動量で、時間成分に光速を掛けた量が全エネルギーになる。速さが光速より十分小さいときに展開し、古典力学で見慣れた式がどこに現れるかを確かめる。

低速では E ≈ mc² + ½m|v|²、p ≈ mv。

四元運動量の計量による二乗は、静止系で計算できる。静止系では空間成分がゼロ、時間成分が mc。同じ二乗を任意の慣性系で計算し、両式を等置する。

PμPμ = −m²c² = −(E/c)² + |p|²。よって E² = |p|²c² + m²c⁴。
U = γ(c,v)、P = mU = (E/c,p)。E = γmc²、p = γmv、E² = |p|²c² + m²c⁴。

図では c = 1、m = 1 とする。青は全エネルギー、緑は運動量の大きさ、赤は運動エネルギー。灰色の基準線は静止エネルギー 1 を示す。

ローレンツ因子 γ
不変量 E² − |p|²

速度を上げると E と |p| はともに増えるが、E² − |p|² は 1 のまま。静止すると運動量と運動エネルギーはゼロで、全エネルギーには静止エネルギー mc² が残る。

光と衝突に使う

光子では質量がゼロで、E = |p|c。光子の世界線では固有時が進まないため、四元速度に質量を掛ける定義は質量を持つ粒子に使う。孤立した系の衝突では、全エネルギーと三方向の全運動量を合わせた四元運動量が保存する。

衝突前後の全四元運動量は等しい。光子では E = c|p|。

たとえば等しいエネルギー E の光子が互いに逆向きに進むと、全運動量はゼロで全エネルギーは 2E。二光子を一つの系として見た不変質量は 2E/c² になる。

続きは 一般相対性理論。計量の符号は微分幾何学の第6項目でも操作できる。
